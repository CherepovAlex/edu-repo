### 📚 Теория: Как работает зигзаг?

Давайте визуализируем процесс. Когда мы записываем строку зигзагом, символы двигаются:
1.  **Вниз** по колонкам (от строки 0 до строки `numRows - 1`).
2.  **Вверх по диагонали** (от строки `numRows - 2` до строки 1).
3.  Затем снова **вниз** и так далее.

Главная идея для решения: **нам не нужно создавать матрицу (двумерный массив) и заполнять её пустыми клетками**. Это тратит много памяти. Вместо этого мы можем сразу определить, в какой строке находится каждый символ, и записывать его в правильную строку результата.

### 🚀 Оптимальное решение

Мы можем решить эту задачу за **O(n)** по времени и **O(n)** по пространству (где n — длина строки), используя один массив строк (или `StringBuilder` для каждой строки) для хранения символов каждой строки зигзага.

#### Алгоритм:
1.  Если `numRows == 1`, возвращаем исходную строку (зигзаг не имеет смысла).
2.  Создаем массив из `numRows` объектов `StringBuilder`. Каждый `StringBuilder` будет хранить символы для своей строки.
3.  Идем по исходной строке `s` символ за символом.
4.  Определяем текущую строку (`rowIndex`), в которую нужно положить символ.
    *   Мы движемся вниз: `rowIndex` увеличивается.
    *   Когда доходим до нижней границы (`numRows - 1`), меняем направление на вверх.
    *   Когда доходим до верхней границы (1), меняем направление на вниз.
5.  Добавляем символ в соответствующий `StringBuilder`.
6.  В конце объединяем все `StringBuilder` в одну строку.

### 💻 Код решения с подробными комментариями

```java
class Solution {
    public String convert(String s, int numRows) {
        // Если количество строк равно 1, зигзаг не формируется, возвращаем исходную строку.
        // Это базовый случай, который ускоряет выполнение.
        if (numRows == 1) {
            return s;
        }

        // Создаем массив StringBuilder для каждой строки зигзага.
        // Каждый элемент массива будет хранить символы, принадлежащие одной строке.
        StringBuilder[] rows = new StringBuilder[numRows];
        
        // Инициализируем каждый StringBuilder в массиве.
        for (int i = 0; i < numRows; i++) {
            rows[i] = new StringBuilder();
        }

        // Текущий индекс строки, в которую мы записываем символ.
        int currentRow = 0;
        
        // Флаг направления движения: true - движемся вниз, false - вверх.
        boolean goingDown = false;

        // Проходим по каждому символу входной строки s.
        for (char c : s.toCharArray()) {
            // Добавляем текущий символ в соответствующую строку зигзага.
            rows[currentRow].append(c);

            // Если мы находимся в первой строке (0) или в последней строке (numRows - 1),
            // нужно сменить направление движения.
            if (currentRow == 0 || currentRow == numRows - 1) {
                goingDown = !goingDown; // Меняем направление на противоположное
            }

            // Обновляем текущую строку в зависимости от направления.
            // Если идем вниз, увеличиваем индекс строки.
            // Если идем вверх, уменьшаем индекс строки.
            currentRow += goingDown ? 1 : -1;
        }

        // Создаем итоговый StringBuilder для объединения всех строк.
        StringBuilder result = new StringBuilder();
        
        // Проходим по всем строкам зигзага и добавляем их содержимое к результату.
        for (StringBuilder row : rows) {
            result.append(row);
        }

        // Преобразуем итоговый StringBuilder в строку и возвращаем.
        return result.toString();
    }
}
```

### 📊 Анализ сложности

*   **Время выполнения:** O(n), где n — длина строки `s`. Мы проходим по строке ровно один раз, и каждый символ добавляется в `StringBuilder` за O(1).
*   **Пространственная сложность:** O(n). Мы создаем массив `StringBuilder`, который в сумме содержит все символы исходной строки. Это оптимально, так как нам нужно хранить результат.

### 💡 Советы для собеседований
1.  **Не используйте матрицу.** Создание `char[numRows][s.length()]` приведет к O(numRows * n) памяти, что плохо, если `numRows` велико.
2.  **Обратите внимание на граничные случаи.** `numRows == 1` — самый важный.
3.  **Используйте `StringBuilder` вместо `+` в цикле.** Конкатенация строк в цикле создает много временных объектов и замедляет работу.
