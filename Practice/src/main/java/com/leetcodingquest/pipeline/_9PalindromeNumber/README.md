## 1. Условие задачи

**LeetCode:** [9. Palindrome Number](https://leetcode.com/problems/palindrome-number/)

Дано целое число `x`. Необходимо вернуть:

- `true`, если число читается одинаково слева направо и справа налево;
- `false` в противном случае.

Число, которое читается одинаково в обоих направлениях, называется **палиндромом**.

### Ограничения

```text
-2^31 <= x <= 2^31 - 1
```

### Дополнительное условие

Можно ли решить задачу, **не преобразуя число в строку**?

В этом решении мы будем работать непосредственно с цифрами числа.

## 2. Примеры

### Пример 1

**Входные данные:**

```text
x = 121
```

**Выходные данные:**

```text
true
```

**Объяснение:** число `121` читается одинаково слева направо и справа налево.

### Пример 2

**Входные данные:**

```text
x = -121
```

**Выходные данные:**

```text
false
```

**Объяснение:** при чтении справа налево знак минус оказался бы в конце: `121-`. Это не совпадает с исходным числом.

### Пример 3

**Входные данные:**

```text
x = 10
```

**Выходные данные:**

```text
false
```

**Объяснение:** справа налево цифры образуют `01`, то есть число `1`. Оно не совпадает с `10`.

## 3. Идея решения

Можно преобразовать число в строку и сравнивать символы с двух концов. Однако условие предлагает обойтись без строк.

Оптимальный подход — **перевернуть только вторую половину числа** и сравнить её с первой. Так мы не создаём строку и не рискуем переполнить `int` при переворачивании всего числа.

### Алгоритм

1. Если `x < 0`, вернуть `false`: отрицательное число не является палиндромом.
2. Если число заканчивается на `0`, но само не равно `0`, вернуть `false`. Например, `10` не может быть палиндромом, поскольку число с нулём в конце при перевороте теряет этот ведущий ноль.
3. Создать переменную `reversedHalf = 0`. В ней будем собирать цифры второй половины в обратном порядке.
4. Пока `x > reversedHalf`:
   - получить последнюю цифру: `lastDigit = x % 10`;
   - добавить её в перевёрнутую половину: `reversedHalf = reversedHalf * 10 + lastDigit`;
   - удалить последнюю цифру из `x`: `x /= 10`.
5. Когда цикл закончится:
   - для чётного количества цифр проверить `x == reversedHalf`;
   - для нечётного количества цифр проверить `x == reversedHalf / 10`, потому что центральная цифра не влияет на результат.

### Пример идеи для числа `1221`

Исходное число состоит из цифр `1 2 2 1`.

- Сначала последняя `1` переносится в `reversedHalf`: получаем `x = 122`, `reversedHalf = 1`.
- Затем переносится `2`: получаем `x = 12`, `reversedHalf = 12`.
- Цикл завершается, потому что `x` больше не превышает `reversedHalf`.
- Сравниваем `12 == 12` и получаем `true`.

## 4. Решение на Java

Код соответствует сигнатуре метода, которую ожидает LeetCode.

**Файл `Solution.java`:**

```java
class Solution { // Объявляем класс, который ожидает LeetCode.

    public boolean isPalindrome(int x) { // Проверяем, является ли число палиндромом.

        if (x < 0 || (x % 10 == 0 && x != 0)) { // Отрицательные числа и числа с последним нулём (кроме 0) не подходят.
            return false; // Сразу возвращаем false, поскольку число не может быть палиндромом.
        } // Завершаем проверку особых случаев.

        int reversedHalf = 0; // Создаём переменную для перевёрнутой половины числа.

        while (x > reversedHalf) { // Продолжаем, пока исходная часть больше перевёрнутой половины.
            int lastDigit = x % 10; // Получаем последнюю цифру исходного числа.
            reversedHalf = reversedHalf * 10 + lastDigit; // Добавляем последнюю цифру в перевёрнутую половину.
            x /= 10; // Удаляем последнюю цифру из исходного числа.
        } // Завершаем цикл, когда обработана примерно половина цифр.

        return x == reversedHalf || x == reversedHalf / 10; // Сравниваем половины с учётом возможной центральной цифры.
    } // Завершаем метод проверки числа.

} // Завершаем класс Solution.
```

## 5. Подробное объяснение кода

### 5.1. Проверка отрицательного числа и последнего нуля

```java
if (x < 0 || (x % 10 == 0 && x != 0)) {
    return false;
}
```

Условие состоит из двух частей:

- `x < 0` — проверяет, является ли число отрицательным.
- `x % 10 == 0 && x != 0` — проверяет, заканчивается ли число нулём и не равно ли оно само нулю.

Оператор `||` означает логическое «ИЛИ», а `&&` — логическое «И».

Если любая из двух основных проверок истинна, метод сразу возвращает `false`.

Число `0` — палиндром, поэтому вторая часть обязательно содержит `x != 0`.

### 5.2. Получение последней цифры: `% 10`

Оператор `%` возвращает остаток от деления.

```java
int lastDigit = 123 % 10; // lastDigit = 3.
```

Примеры:

| Выражение | Результат |
|---|---:|
| `121 % 10` | `1` |
| `12 % 10` | `2` |
| `1234 % 10` | `4` |
| `7 % 10` | `7` |

### 5.3. Удаление последней цифры: `/ 10`

При целочисленном делении Java отбрасывает дробную часть результата.

```java
int x = 121; // Исходное число.
x /= 10;     // Теперь x = 12.
x /= 10;     // Теперь x = 1.
```

Это позволяет последовательно обрабатывать цифры справа налево.

### 5.4. Построение перевёрнутой половины

```java
reversedHalf = reversedHalf * 10 + lastDigit;
```

Чтобы добавить цифру справа, сначала умножаем уже собранное число на `10`, а затем прибавляем новую цифру.

Например, для цифр `1`, `2`, `1`:

| Шаг | `reversedHalf` до операции | `lastDigit` | `reversedHalf` после операции |
|---|---:|---:|---:|
| 1 | `0` | `1` | `1` |
| 2 | `1` | `2` | `12` |
| 3 | `12` | `1` | `121` |

В нашем алгоритме цикл остановится после обработки примерно половины цифр, поэтому вся последовательность не будет перевёрнута целиком.

### 5.5. Почему цикл использует `x > reversedHalf`

```java
while (x > reversedHalf)
```

На каждой итерации одна цифра удаляется из `x` и добавляется в `reversedHalf`.

Цикл останавливается, когда перевёрнутая половина становится не меньше оставшейся части. Тогда можно сравнить получившиеся половины.

- Для чётного количества цифр половины должны быть равны.
- Для нечётного количества цифр в `reversedHalf` дополнительно находится центральная цифра. Её можно удалить делением на `10`.

### 5.6. Итоговое сравнение

```java
return x == reversedHalf || x == reversedHalf / 10;
```

Первая часть:

```java
x == reversedHalf
```

Проверяет числа с чётным количеством цифр, например `1221`.

Вторая часть:

```java
x == reversedHalf / 10
```

Проверяет числа с нечётным количеством цифр, например `121`. Деление на `10` отбрасывает центральную цифру из перевёрнутой половины.

Если хотя бы одно сравнение истинно, метод возвращает `true`.

## 6. Пошаговый разбор примеров

### 6.1. Пример 1: `x = 121`

**Ожидаемый результат:** `true`.

Начальные значения:

```text
x = 121
reversedHalf = 0
```

#### Итерация 1

Проверяем условие цикла:

```text
121 > 0 → true
```

Получаем последнюю цифру:

```text
lastDigit = 121 % 10 = 1
```

Добавляем цифру в перевёрнутую половину:

```text
reversedHalf = 0 * 10 + 1 = 1
```

Удаляем последнюю цифру из `x`:

```text
x = 121 / 10 = 12
```

Состояние после первой итерации:

| Переменная | Значение |
|---|---:|
| `x` | `12` |
| `reversedHalf` | `1` |

#### Итерация 2

Проверяем условие цикла:

```text
12 > 1 → true
```

Получаем последнюю цифру:

```text
lastDigit = 12 % 10 = 2
```

Добавляем цифру:

```text
reversedHalf = 1 * 10 + 2 = 12
```

Удаляем последнюю цифру из `x`:

```text
x = 12 / 10 = 1
```

Состояние после второй итерации:

| Переменная | Значение |
|---|---:|
| `x` | `1` |
| `reversedHalf` | `12` |

#### Завершение цикла

Проверяем условие:

```text
1 > 12 → false
```

Цикл завершается.

Проверяем итоговое выражение:

```text
x == reversedHalf
1 == 12 → false
```

Затем:

```text
x == reversedHalf / 10
1 == 12 / 10
1 == 1 → true
```

Хотя первая половина не совпала с полной перевёрнутой половиной, после удаления центральной цифры половины совпадают.

**Результат: `true`.**

### 6.2. Пример 2: `x = -121`

**Ожидаемый результат:** `false`.

Начинаем с проверки особых случаев:

```java
if (x < 0 || (x % 10 == 0 && x != 0)) {
    return false;
}
```

Проверяем первое условие:

```text
x < 0
-121 < 0 → true
```

Поскольку первая часть выражения с `||` уже истинна, результат всего условия — `true`. Метод немедленно выполняет:

```java
return false;
```

Цикл не запускается, а исходное число не изменяется.

**Результат: `false`.**

### 6.3. Пример 3: `x = 10`

**Ожидаемый результат:** `false`.

Проверяем особые случаи:

```text
x < 0
10 < 0 → false
```

Теперь проверяем вторую часть:

```text
x % 10 == 0
10 % 10 == 0 → true
```

И:

```text
x != 0
10 != 0 → true
```

Объединяем части через `&&`:

```text
true && true → true
```

Затем объединяем их через `||`:

```text
false || true → true
```

Выполняется:

```java
return false;
```

Цикл не запускается. Такая проверка нужна, потому что при чтении числа `10` справа налево получается `01`, то есть `1`.

**Результат: `false`.**

## 8. Доказательство корректности

Докажем, что алгоритм возвращает `true` тогда и только тогда, когда исходное число является палиндромом.

1. **Предварительные проверки.** Все отрицательные числа корректно отклоняются. Число, оканчивающееся нулём и не равное нулю, также не может быть палиндромом: при чтении в обратном направлении ведущий ноль исчезает. Число `0` при этом обрабатывается правильно.
2. **Обработка цифр.** На каждой итерации последняя цифра `x` добавляется в конец `reversedHalf`, а затем удаляется из `x`. Поэтому `reversedHalf` хранит цифры исходного числа в обратном порядке для уже обработанной части.
3. **Остановка.** Цикл заканчивается после обработки примерно половины цифр. Оставшаяся часть `x` представляет одну половину числа, а `reversedHalf` — обратный порядок другой половины.
4. **Чётное количество цифр.** Для палиндрома обе половины должны совпасть, поэтому проверка `x == reversedHalf` вернёт `true`.
5. **Нечётное количество цифр.** Центральная цифра не влияет на симметрию. Проверка `x == reversedHalf / 10` удаляет эту цифру из сравнения.
6. **Несовпадение цифр.** Если соответствующие цифры различаются, ни одно итоговое сравнение не будет истинным, и алгоритм вернёт `false`.

Следовательно, алгоритм корректно определяет число-палиндром.

## 9. Сложность алгоритма

Пусть `d` — количество цифр в числе `x`.

### Временная сложность

На каждой итерации цикла обрабатывается одна цифра, а всего обрабатывается примерно половина цифр.

Временная сложность:

```text
O(log10(|x|))
```

Поскольку количество цифр числа пропорционально логарифму его абсолютного значения, сложность также можно обозначить как `O(d)`.

### Пространственная сложность

Используется постоянное количество переменных: `x`, `reversedHalf` и `lastDigit`. Дополнительные строки, массивы и коллекции не создаются.

Пространственная сложность:

```text
O(1)
```

**Итог:** решение оптимально по дополнительной памяти и эффективно по времени. Переворачивается только половина числа, поэтому не возникает переполнения `int` из-за переворота всего числа.

## 10. Что важно запомнить

- `% 10` — получить последнюю цифру числа.
- `/ 10` — удалить последнюю цифру при целочисленном делении.
- `reversedHalf * 10 + lastDigit` — добавить цифру справа к перевёрнутой части.
- Отрицательные числа не являются палиндромами.
- Число, заканчивающееся на `0`, не может быть палиндромом, если оно не равно `0`.
- Для чётного количества цифр сравниваем `x == reversedHalf`.
- Для нечётного количества цифр сравниваем `x == reversedHalf / 10`.
- Решение не использует преобразование числа в строку.

### Итоговый ответ

Алгоритм проходит примерно половину цифр числа, использует `O(1)` дополнительной памяти и решает задачу без преобразования числа в строку.
