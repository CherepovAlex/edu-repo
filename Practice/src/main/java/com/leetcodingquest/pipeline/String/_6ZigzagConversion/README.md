LeetCode 6. Преобразование зигзага (Zigzag Conversion)
Разберём задачу как на занятии по Java: сначала поймём принцип преобразования строки, затем напишем оптимальное решение, прокомментируем каждую строку кода и вручную проследим вычисления для всех трёх примеров.
1. Понимаем условие задачи
Нам даны:
- s — строка, которую нужно преобразовать.
- numRows — количество строк, в которых нужно расположить символы зигзагом.
После этого необходимо прочитать символы сверху вниз по строкам, а не по направлению зигзага, и объединить их в одну строку.

Например, для строки PAYPALISHIRING и трёх строк расположение выглядит так:
P
A
H
N

Строка 1

A
P
L
S
I
I
G

Строка 2

Y
I
R

Строка 3



Читаем первую строку, затем вторую, затем третью.
PAHNAPLSIIGYIR

Обрати внимание: мы не сортируем символы и не удаляем их. Мы только меняем порядок, в котором они попадают в итоговую строку.
2. Идея оптимального решения
Самый удобный подход — создать отдельную строку для каждой строки зигзага.

Для этого будем использовать массив StringBuilder:
- rows[0] хранит символы первой строки.
- rows[1] хранит символы второй строки.
- rows[2] хранит символы третьей строки.
- И так далее.
Затем будем проходить по исходной строке слева направо и решать, в какую строку поместить очередной символ.
Как двигаться по зигзагу?
Нам понадобятся две переменные:
- currentRow — номер строки, в которую помещаем текущий символ.
- direction — направление движения: 1 означает вниз, -1 означает вверх.
Правила движения:
1. Начинаем с первой строки (currentRow = 0) и движемся вниз.
2. Добавляем текущий символ в выбранную строку.
3. Если достигли последней строки, меняем направление на движение вверх.
4. Если достигли первой строки, меняем направление на движение вниз.
5. Повторяем, пока не обработаем все символы.
Например, при numRows = 4 номера строк для последовательных символов будут выглядеть так:
0

1

2

3


После строки 3 идём обратно вверх: 2 → 1 → 0


Получается цикл движения: 0 → 1 → 2 → 3 → 2 → 1 → 0 → 1 ...

Важный частный случай: если строка всего одна (numRows = 1), зигзага не получится. Исходная строка уже является ответом, поэтому её можно сразу вернуть.
3. Решение на Java с комментарием к каждой строке

class Solution {
    public String convert(String s, int numRows) {
        // Если строка одна или строк меньше, чем символов в строке,
        // зигзаг не нужен: порядок символов не изменится.
        if (numRows == 1 || numRows >= s.length()) {
            return s;
        }

        // Создаём массив для хранения символов каждой строки зигзага.
        StringBuilder[] rows = new StringBuilder[numRows];

        // Создаём отдельный StringBuilder для каждой строки.
        for (int i = 0; i < numRows; i++) {
            rows[i] = new StringBuilder();
        }

        // Начинаем размещать символы с первой строки (индекс 0).
        int currentRow = 0;

        // Первоначально движемся вниз по строкам.
        int direction = 1;

        // Последовательно обрабатываем каждый символ исходной строки.
        for (int i = 0; i < s.length(); i++) {
            // Добавляем текущий символ в выбранную строку зигзага.
            rows[currentRow].append(s.charAt(i));

            // Если достигли верхней или нижней границы, меняем направление.
            if (currentRow == 0) {
                direction = 1;
            } else if (currentRow == numRows - 1) {
                direction = -1;
            }

            // Переходим к следующей строке с учётом направления движения.
            currentRow += direction;
        }

        // Создаём объект для формирования итоговой строки.
        StringBuilder result = new StringBuilder();

        // Обходим строки зигзага сверху вниз.
        for (int i = 0; i < numRows; i++) {
            // Приписываем содержимое текущей строки к результату.
            result.append(rows[i]);
        }

        // Возвращаем полученную строку без разделителей.
        return result.toString();
    }
}



Этот код можно вставить непосредственно в шаблон LeetCode.
4. Подробно разбираем каждую важную часть
Проверка особых случаев
if (numRows == 1 || numRows >= s.length()) {
    return s;
}


Есть два случая, когда преобразование не требуется:
- numRows == 1: все символы располагаются в одной строке.
- numRows >= s.length(): символов не больше, чем строк, поэтому каждый символ окажется в отдельной строке, и порядок чтения останется прежним.
Это также предотвращает ошибки при работе с границами массива.
Создание строк
StringBuilder[] rows = new StringBuilder[numRows];


Создаём массив ссылок на объекты StringBuilder. Самих объектов пока нет, поэтому каждый элемент нужно инициализировать:
for (int i = 0; i < numRows; i++) {
    rows[i] = new StringBuilder();
}


Почему StringBuilder, а не обычный String? Потому что мы многократно добавляем символы. StringBuilder позволяет эффективно накапливать текст без создания новой строки при каждом добавлении.
Перемещение по строкам
int currentRow = 0;
int direction = 1;


Первая строка имеет индекс 0, а последняя — numRows - 1. Переменная direction определяет, как меняется индекс строки после обработки символа.
if (currentRow == 0) {
    direction = 1;
} else if (currentRow == numRows - 1) {
    direction = -1;
}


Когда достигли верхней границы, начинаем двигаться вниз. Когда достигли нижней — начинаем двигаться вверх.

Наконец:
currentRow += direction;


Если direction = 1, индекс увеличивается на единицу. Если direction = -1, индекс уменьшается на единицу.
Сборка ответа
После размещения всех символов каждая строка уже содержит символы в правильном порядке. Остаётся объединить их сверху вниз:
for (int i = 0; i < numRows; i++) {
    result.append(rows[i]);
}


Метод append() добавляет содержимое каждого StringBuilder к итоговой строке. Метод toString() преобразует накопленный результат в обычный String.

7. Пример 3 — одна строка
Входные данные:
s = "A"
numRows = 1


Ожидаемый результат:
"A"


В начале метода выполняется проверка:
if (numRows == 1 || numRows >= s.length()) {
    return s;
}


Подставляем значения:
- numRows == 1 → true.
- numRows >= s.length() → 1 >= 1, тоже true.
Достаточно, чтобы одно из условий было истинным. Поэтому метод немедленно возвращает исходную строку "A".

Важно: массив rows даже не создаётся. Это позволяет избежать ненужных действий и корректно обработать случай, когда зигзаг невозможен.

8. Сложность алгоритма
Обозначим:
- \(n\) — длина исходной строки s.
- \(r\) — количество строк numRows.
Показатель	Сложность	Объяснение
Время	\(O(n)\)	Каждый символ обрабатывается один раз, а итоговая строка собирается за линейное время.
Дополнительная память	\(O(n+r)\)	Храним все символы в StringBuilder и массив ссылок на строки.
Поскольку по условию \(r \leq 1000\), а строка содержит не более 1000 символов, решение укладывается в ограничения задачи.

Для обычного случая, когда количество строк не превышает длину строки, дополнительная память составляет \(O(n)\), поскольку \(r \leq n\).

Можно ли сделать быстрее по времени? Нет, асимптотически быстрее \(O(n)\) не получится: необходимо как минимум прочитать все символы и сформировать ответ, содержащий те же \(n\) символов.
9. Что важно запомнить для собеседования
1. StringBuilder[] позволяет хранить символы каждой строки отдельно и эффективно добавлять новые символы.
2. currentRow указывает, куда помещать текущий символ.
3. direction позволяет менять направление движения на границах зигзага.
4. Проверка особых случаев предотвращает ненужные вычисления при одной строке или когда строк не меньше, чем символов.
5. Сборка результата выполняется простым объединением строк сверху вниз.
Это решение оптимально по времени и асимптотически оптимально по дополнительной памяти для данного подхода.

Для закрепления попробуй самостоятельно изменить код так, чтобы он выводил не только итоговую строку, но и содержимое каждой строки зигзага перед объединением. Это хороший способ проверить, что ты действительно понимаешь работу currentRow и direction.
