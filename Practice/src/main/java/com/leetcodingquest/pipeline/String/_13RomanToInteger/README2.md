# Roman to Integer (LeetCode #13)

## 📋 Условие задачи

Римские цифры обозначаются семью различными символами: `I`, `V`, `X`, `L`, `C`, `D` и `M`.

| Символ | Значение |
|--------|----------|
| I      | 1        |
| V      | 5        |
| X      | 10       |
| L      | 50       |
| C      | 100      |
| D      | 500      |
| M      | 1000     |

Например, число 2 записывается как `II` — две единицы, сложенные вместе. Число 12 записывается как `XII`, что означает `X + II`. Число 27 — как `XXVII`, что означает `XX + V + II`.

Римские цифры обычно записываются от большего к меньшему слева направо. Однако число 4 записывается не как `IIII`, а как `IV`. Поскольку единица стоит перед пятёркой, мы вычитаем её, получая 4. Тот же принцип применяется к числу 9, которое записывается как `IX`. Существует шесть случаев, когда используется вычитание:

- `I` перед `V` (5) и `X` (10) → 4 и 9
- `X` перед `L` (50) и `C` (100) → 40 и 90
- `C` перед `D` (500) и `M` (1000) → 400 и 900

**Задача:** преобразовать римскую цифру в целое число.

### Примеры

**Пример 1:**
```
Вход:  s = "III"
Выход: 3
Пояснение: III = 3.
```

**Пример 2:**
```
Вход:  s = "LVIII"
Выход: 58
Пояснение: L = 50, V = 5, III = 3.
```

**Пример 3:**
```
Вход:  s = "MCMXCIV"
Выход: 1994
Пояснение: M = 1000, CM = 900, XC = 90, IV = 4.
```

### Ограничения

- `1 <= s.length <= 15`
- `s` содержит только символы `('I', 'V', 'X', 'L', 'C', 'D', 'M')`
- Гарантируется, что `s` — допустимая римская цифра в диапазоне `[1, 3999]`

## 🧠 Разбор задачи

**Ключевое наблюдение:** в римской системе счисления цифры обычно идут от большего к меньшему (слева направо), и мы их **складываем**. Но есть 6 особых случаев (`IV`, `IX`, `XL`, `XC`, `CD`, `CM`), когда меньшая цифра стоит **перед** большей — тогда её нужно **вычитать**.

**Идея оптимального решения:**
Идём по строке слева направо. Для каждого символа:
- Если его значение **меньше** значения следующего символа — вычитаем его из результата.
- Иначе — прибавляем.

Это работает, потому что единственный случай, когда меньшая цифра стоит перед большей — это как раз случаи вычитания. Во всех остальных позициях цифра идёт в порядке невозрастания.

**Сложность:**
- Время: **O(n)**, где `n` — длина строки (проходим один раз).
- Память: **O(1)** — используем только `HashMap` фиксированного размера (7 элементов) и переменную-аккумулятор.

Это оптимально, так как строку нужно прочитать хотя бы один раз.

## 💻 Код решения

```java
class Solution {
    public int romanToInt(String s) {                                    // объявляем метод, принимающий строку s и возвращающий int
        Map<Character, Integer> map = new HashMap<>();                   // создаём HashMap для быстрого доступа к значению символа (O(1))
        map.put('I', 1);                                                 // I = 1
        map.put('V', 5);                                                 // V = 5
        map.put('X', 10);                                                // X = 10
        map.put('L', 50);                                                // L = 50
        map.put('C', 100);                                               // C = 100
        map.put('D', 500);                                               // D = 500
        map.put('M', 1000);                                              // M = 1000

        int result = 0;                                                  // аккумулятор для итогового числа
        int n = s.length();                                              // длина строки (нужна для проверки границы i+1)

        for (int i = 0; i < n; i++) {                                    // проходим по каждому символу строки
            int current = map.get(s.charAt(i));                          // значение текущего символа
            if (i + 1 < n && current < map.get(s.charAt(i + 1))) {       // если есть следующий символ и текущий меньше следующего
                result -= current;                                       // вычитаем (случай IV, IX, XL, XC, CD, CM)
            } else {                                                     // иначе
                result += current;                                       // прибавляем
            }
        }

        return result;                                                   // возвращаем итоговое число
    }
}
```

|---|--------|---------|-----------|------------------|----------|--------|

## 🔄 Альтернативное решение (без `HashMap`, через `switch`)

Если хотите избежать создания `HashMap` (чуть быстрее по константе, тот же O(1) по памяти), можно заменить `map.get(ch)` на вспомогательный метод со `switch`:

```java
class Solution {
    public int romanToInt(String s) {                                    // объявляем метод
        int result = 0;                                                  // аккумулятор
        int n = s.length();                                              // длина строки

        for (int i = 0; i < n; i++) {                                    // проходим по строке
            int current = value(s.charAt(i));                            // значение текущего символа через switch
            if (i + 1 < n && current < value(s.charAt(i + 1))) {         // сравнение со следующим
                result -= current;                                       // вычитаем
            } else {
                result += current;                                       // прибавляем
            }
        }
        return result;                                                   // возвращаем результат
    }

    private int value(char c) {                                          // вспомогательный метод: символ → значение
        return switch (c) {                                              // switch-выражение (Java 14+)
            case 'I' -> 1;
            case 'V' -> 5;
            case 'X' -> 10;
            case 'L' -> 50;
            case 'C' -> 100;
            case 'D' -> 500;
            case 'M' -> 1000;
            default  -> 0;
        };
    }
}
```

`HashMap`-версия читается проще и на собеседовании обычно приветствуется именно такое решение — оно наглядно демонстрирует идею «сравнить с соседом справа».

---

## ✅ Итоги

- **Один проход по строке** — O(n) времени.
- **Константная память** — O(1).
- **Идея**: сравниваем текущий символ со следующим; если он меньше — вычитаем, иначе — прибавляем.
- Это покрывает все 6 случаев вычитания автоматически, без явного перечисления пар вида `"IV"`, `"IX"` и т.д.
