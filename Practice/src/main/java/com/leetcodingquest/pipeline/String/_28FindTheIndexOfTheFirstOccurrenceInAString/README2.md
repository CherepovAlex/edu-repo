# LeetCode 28. Find the Index of the First Occurrence in a String

> Разбор задачи для курса по Java-разработке.
> Оптимальное решение через алгоритм KMP (Knuth–Morris–Pratt): **O(n + m)** по времени, **O(m)** по памяти.

---

## 📋 Условие задачи

Даны две строки `haystack` и `needle`. Верните индекс первого вхождения `needle` в `haystack` или `-1`, если `needle` не является частью `haystack`.

**Пример 1:**
```
Вход:  haystack = "sadbutsad", needle = "sad"
Выход: 0
Пояснение: "sad" встречается в позициях 0 и 6. Первое вхождение — 0.
```

**Пример 2:**
```
Вход:  haystack = "leetcode", needle = "leeto"
Выход: -1
Пояснение: "leeto" не встречается в "leetcode".
```

**Пример 3:**
```
Вход:  haystack = "hello", needle = "ll"
Выход: 2
```

**Ограничения:**
- `1 <= haystack.length, needle.length <= 10^4`
- `haystack` и `needle` состоят только из строчных букв английского алфавита.

---

## 🧠 Анализ подходов

| Подход | Время | Память | Комментарий |
|--------|-------|--------|-------------|
| Наивный перебор | O(n·m) | O(1) | Просто, но на «плохих» данных (например, `"aaaa...a"` + `"aaa...ab"`) работает медленно |
| Встроенный `String.indexOf` | O(n·m) | O(1) | В Java реализован наивно, не считается «решением» |
| **KMP** | **O(n + m)** | **O(m)** | **Оптимально** среди детерминированных алгоритмов |

При ограничениях `n, m ≤ 10^4` наивный алгоритм даёт до ~10^8 операций в худшем случае — на грани допустимого. Поэтому в качестве основного решения используем **KMP**.

---

## 💡 Идея KMP

При наивном поиске, когда происходит несовпадение, мы сдвигаем указатель в `haystack` на 1 и начинаем сравнение `needle` заново с нуля — теряя уже полученную информацию о совпавшем префиксе.

**KMP** использует **LPS-массив** (Longest Proper Prefix which is also Suffix) — для каждой позиции `i` в `needle` хранит длину наибольшего собственного префикса, который одновременно является суффиксом подстроки `needle[0..i]`.

При несовпадении мы не откатываемся в `haystack`, а «прыгаем» по `needle` согласно LPS — сохраняя всю полезную информацию о совпадениях.

---

## 💻 Решение на Java

```java
public class Solution1 {

    public int strStr(String haystack, String needle) {
        if (needle.isEmpty()) return 0;

        int n = haystack.length();
        int m = needle.length();

        // Шаг 1: строим LPS-массив
        int[] lps = new int[m];
        buildLps(needle, lps);

        // Шаг 2: проходим по haystack с двумя указателями
        int i = 0; // указатель по haystack
        int j = 0; // указатель по needle

        while (i < n) {
            if (haystack.charAt(i) == needle.charAt(j)) {
                i++;
                j++;
                if (j == m) {
                    return i - m;
                }
            } else {
                if (j > 0) {
                    j = lps[j - 1];
                } else {
                    i++;
                }
            }
        }

        return -1;
    }

    private void buildLps(String needle, int[] lps) {
        int m = needle.length();
        int len = 0; // длина текущего совпавшего префикса
        int i = 1;   // начинаем со второго символа
        lps[0] = 0;

        while (i < m) {
            if (needle.charAt(i) == needle.charAt(len)) {
                len++;
                lps[i] = len;
                i++;
            } else {
                if (len != 0) {
                    len = lps[len - 1];
                } else {
                    lps[i] = 0;
                    i++;
                }
            }
        }
    }

    public static void main(String[] args) {
        Solution1 sol = new Solution1();
        System.out.println(sol.strStr("sadbutsad", "sad"));  // 0
        System.out.println(sol.strStr("leetcode", "leeto")); // -1
        System.out.println(sol.strStr("hello", "ll"));       // 2
    }
}
```

| № | Строка | Что делает |
|---|--------|-----------|
| 1 | `if (needle.isEmpty()) return 0;` | Защита от пустой `needle` (по условию не встречается) |
| 2 | `int n = haystack.length();` | Длина основной строки |
| 3 | `int m = needle.length();` | Длина подстроки |
| 4 | `int[] lps = new int[m];` | Создаём LPS-массив размера `m` |
| 5 | `buildLps(needle, lps);` | Заполняем его для `needle` |
| 6 | `int i = 0;` | Указатель по `haystack` |
| 7 | `int j = 0;` | Указатель по `needle` |
| 8 | `while (i < n) {` | Пока не дошли до конца `haystack` |
| 9 | `if (haystack.charAt(i) == needle.charAt(j)) {` | Текущие символы совпали |
| 10 | `i++;` | Сдвигаем `i` |
| 11 | `j++;` | Сдвигаем `j` |
| 12 | `if (j == m) {` | Дошли до конца `needle` — нашли вхождение |
| 13 | `return i - m;` | Возвращаем начальный индекс вхождения |
| 14 | `} else {` | Символы не совпали |
| 15 | `if (j > 0) {` | Часть `needle` уже совпала |
| 16 | `j = lps[j - 1];` | «Прыжок» по LPS — не теряем прогресс |
| 17 | `} else {` | `j == 0` |
| 18 | `i++;` | Первый символ `needle` не совпал — двигаемся дальше по `haystack` |
| 19 | `return -1;` | Вхождений нет |

### Метод `buildLps`

| № | Строка | Что делает |
|---|--------|-----------|
| 20 | `int m = needle.length();` | Длина `needle` |
| 21 | `int len = 0;` | Текущая длина совпавшего префикса-суффикса |
| 22 | `int i = 1;` | Начинаем со второго символа |
| 23 | `lps[0] = 0;` | У первого символа LPS всегда 0 |
| 24 | `while (i < m) {` | Проходим по всем символам |
| 25 | `if (needle.charAt(i) == needle.charAt(len)) {` | Текущий символ продолжает префикс |
| 26 | `len++;` | Увеличиваем длину |
| 27 | `lps[i] = len;` | Записываем в LPS |
| 28 | `i++;` | Идём дальше |
| 29 | `} else {` | Символы не совпали |
| 30 | `if (len != 0) {` | Есть с чем откатываться |
| 31 | `len = lps[len - 1];` | Пробуем меньший префикс |
| 32 | `} else {` | Откатываться некуда |
| 33 | `lps[i] = 0;` | LPS = 0 |
| 34 | `i++;` | Идём дальше |

## 🔍 Пошаговый разбор Примеров

### Пример 1: `haystack = "sadbutsad"`, `needle = "sad"`

**Построение LPS для `"sad"` (m = 3):**

| i | needle[i] | Сравнение с needle[len] | len | lps[i] |
|---|-----------|--------------------------|-----|--------|
| 0 | s | — | 0 | **0** |
| 1 | a | 'a' ≠ 's', len = 0 → lps[1] = 0, i = 2 | 0 | **0** |
| 2 | d | 'd' ≠ 's', len = 0 → lps[2] = 0, i = 3 | 0 | **0** |

`lps = [0, 0, 0]`

**Поиск:**

| Шаг | i | j | haystack[i] | needle[j] | Действие |
|-----|---|---|-------------|-----------|----------|
| 1 | 0 | 0 | s | s | совпало → i = 1, j = 1 |
| 2 | 1 | 1 | a | a | совпало → i = 2, j = 2 |
| 3 | 2 | 2 | d | d | совпало → i = 3, j = 3 → **j == m** → return `3 - 3 = 0` |

**Ответ: 0** ✅

Цикл завершён (i == n). **Ответ: -1** ✅

## ⚖️ Альтернатива: наивное решение

Для сравнения — та же задача без KMP:

```java
public int strStr(String haystack, String needle) {
    int n = haystack.length(), m = needle.length();
    for (int i = 0; i + m <= n; i++) {
        int j = 0;
        while (j < m && haystack.charAt(i + j) == needle.charAt(j)) {
            j++;
        }
        if (j == m) return i;
    }
    return -1;
}
```

- **Время:** O(n · m) в худшем случае.
- **Память:** O(1).
- Проходит по ограничениям задачи, но на «плохих» данных (например, `"aaaa...a"` + `"aaa...ab"`) работает заметно медленнее KMP.
