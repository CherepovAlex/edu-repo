# LeetCode № 28 — Найти индекс первого вхождения в строку (Find the Index of the First Occurrence in a String)

## 1. Условие задачи

**Номер задачи:** 28  
**Название на LeetCode:** Find the Index of the First Occurrence in a String  
**Язык программирования:** Java  
**Уровень сложности:** Easy  
**Алгоритм:** Кнут — Моррис — Пратт (Knuth–Morris–Pratt, KMP)

Даны две строки `haystack` и `needle`.

Необходимо вернуть индекс первого вхождения строки `needle` в строку `haystack`.

Если строка `needle` не является частью строки `haystack`, необходимо вернуть `-1`.

### Пример 1

**Входные данные:**

```text
haystack = "sadbutsad"
needle = "sad"
```

**Выходные данные:**

```text
0
```

**Объяснение:**

Строка `"sad"` встречается в строке `"sadbutsad"` два раза:

- Первое вхождение начинается с индекса `0`.
- Второе вхождение начинается с индекса `6`.

Необходимо вернуть индекс первого вхождения, поэтому ответ — `0`.

### Пример 2

**Входные данные:**

```text
haystack = "leetcode"
needle = "leeto"
```

**Выходные данные:**

```text
-1
```

**Объяснение:**

Строка `"leeto"` не встречается в строке `"leetcode"` целиком.

Хотя первые четыре символа совпадают, последний символ искомой строки не совпадает с соответствующим символом основной строки.

Поэтому необходимо вернуть `-1`.

### Пример 3 — дополнительный учебный пример

**Входные данные:**

```text
haystack = "hello"
needle = "ll"
```

**Выходные данные:**

```text
2
```

**Объяснение:**

Строка `"ll"` начинается в строке `"hello"` с индекса `2`.

Этот пример показывает, как найти подстроку, которая начинается не с нулевого индекса.

### Ограничения

```text
1 <= haystack.length <= 10^4
1 <= needle.length <= 10^4
```

Строки `haystack` и `needle` состоят только из строчных букв английского алфавита.

## 2. Что необходимо понять перед решением

Для решения задачи важно понимать несколько понятий.

### 2.1. Что такое строка

В Java строка представлена типом `String`.

Например:

```java
String haystack = "hello";
String needle = "ll";
```

Переменная `haystack` хранит основную строку, в которой мы ищем подстроку.

Переменная `needle` хранит искомую подстроку.

### 2.2. Что такое индекс

Индекс — это позиция символа в строке.

В Java индексация начинается с нуля.

Для строки `"hello"`:

| Символ | Индекс |
|---|---:|
| `h` | 0 |
| `e` | 1 |
| `l` | 2 |
| `l` | 3 |
| `o` | 4 |

Чтобы получить символ по индексу, используется метод `charAt()`.

Например:

```java
String text = "hello";

char first = text.charAt(0);  // 'h'
char third = text.charAt(2);  // 'l'
```

Выражение `text.charAt(2)` возвращает символ `'l'`, расположенный по индексу `2`.

### 2.3. Что такое вхождение подстроки

Подстрока — это последовательность символов, которая полностью присутствует внутри другой строки.

Например:

```text
Основная строка: hello
Искомая строка:  ll
```

Искомая строка `"ll"` встречается в `"hello"` начиная с индекса `2`.

Однако строка `"le"` не встречается в `"hello"` как последовательность соседних символов.

Порядок символов имеет значение. Нельзя пропускать символы между буквами искомой строки.

---

## 3. Выбор алгоритма

Существует несколько способов решения задачи.

### 3.1. Простой перебор

Можно последовательно проверять каждую позицию строки `haystack`.

На каждой позиции алгоритм сравнивает символы `needle` с символами `haystack`, пока не найдёт несовпадение или не проверит всю искомую строку.

Пример:

```text
haystack = "hello"
needle = "ll"
```

Сначала проверяем позицию `0`:

```text
haystack: h e l l o
needle:   l l
          ^
```

Символы `h` и `l` не совпадают.

Затем проверяем позицию `1`:

```text
haystack: h e l l o
needle:     l l
            ^
```

Символы `e` и `l` не совпадают.

Затем проверяем позицию `2`:

```text
haystack: h e l l o
needle:       l l
              ^ ^
```

Оба символа совпадают. Ответ — `2`.

В худшем случае сложность такого алгоритма составляет:

- Время: `O(n * m)`.
- Дополнительная память: `O(1)`.

Здесь `n` — длина `haystack`, а `m` — длина `needle`.

### 3.2. Алгоритм KMP

KMP расшифровывается как Knuth–Morris–Pratt — алгоритм Кнута — Морриса — Пратта.

Он использует информацию о повторяющихся последовательностях символов внутри искомой строки.

Если возникает несовпадение, алгоритм не начинает проверку заново с первого символа `needle` без необходимости.

Вместо этого он использует вспомогательный массив `LPS`, чтобы определить, сколько символов уже можно считать совпавшими.

Сложность KMP:

- Время: `O(n + m)`.
- Дополнительная память: `O(m)`.

В этом решении используется KMP, поскольку он обеспечивает линейную временную сложность в худшем случае.

---

## 4. Идея алгоритма KMP

Алгоритм состоит из двух этапов:

1. Построение массива `LPS` для строки `needle`.
2. Поиск `needle` внутри `haystack` с использованием массива `LPS`.

### 4.1. Что такое LPS

`LPS` означает **Longest Proper Prefix which is also Suffix**.

По-русски: длина самого длинного собственного префикса строки, который одновременно является её суффиксом.

Разберём термины.

**Префикс** — начало строки.

Например, для строки `"abcd"` собственными префиксами являются:

```text
"a"
"ab"
"abc"
```

Полная строка `"abcd"` собственным префиксом не является.

**Суффикс** — конец строки.

Для строки `"abcd"` собственными суффиксами являются:

```text
"d"
"cd"
"bcd"
```

Для каждой позиции массива `LPS` определяется длина самого длинного собственного префикса соответствующей части строки, который одновременно является суффиксом.

### 4.2. Пример построения LPS

Рассмотрим строку:

```text
needle = "abab"
```

Разберём её префиксы.

| Индекс | Подстрока от начала до индекса | Длина LPS | Объяснение |
|---:|---|---:|---|
| 0 | `a` | 0 | Нет собственного непустого префикса |
| 1 | `ab` | 0 | `a` и `b` не совпадают |
| 2 | `aba` | 1 | Префикс `a` совпадает с суффиксом `a` |
| 3 | `abab` | 2 | Префикс `ab` совпадает с суффиксом `ab` |

Итоговый массив:

```text
lps = [0, 0, 1, 2]
```

Что это означает?

Для строки `"abab"` длина подходящего префикса равна `2`.

Если при поиске уже совпали символы `"ab"`, а затем произошло несовпадение, можно использовать это совпадение и продолжить поиск без повторной проверки всех символов с самого начала.

### 4.3. Почему LPS помогает ускорить поиск

Представим, что искомая строка:

```text
needle = "abab"
```

И алгоритм уже сравнил первые три символа:

```text
haystack: a b a x
needle:   a b a b
```

Первые три символа совпали, но затем символ `x` не совпал с `b`.

Простой перебор может начать проверку следующей позиции основной строки.

KMP анализирует структуру строки `needle` и использует LPS, чтобы определить, какая часть уже совпавшей последовательности может быть использована повторно.

Важно: алгоритм не возвращает индекс `i` назад. Он изменяет индекс `j` в искомой строке, используя информацию массива LPS.

## 5. Полный код решения на Java

Создадим класс `Solution1`.

В нём будут три метода:

- `strStr()` — основной метод поиска.
- `buildLps()` — построение массива LPS.
- `main()` — запуск тестовых примеров.

Код не требует дополнительных библиотек и импортов.

```java
public class Solution1 {

    // Метод ищет первое вхождение needle в haystack.
    // Возвращает индекс начала совпадения или -1.
    public int strStr(String haystack, String needle) {

        // Получаем длину основной строки.
        int n = haystack.length();

        // Получаем длину искомой подстроки.
        int m = needle.length();

        // Строим массив LPS для искомой подстроки.
        int[] lps = buildLps(needle);

        // i — индекс текущего символа haystack.
        int i = 0;

        // j — индекс текущего символа needle.
        int j = 0;

        // Продолжаем поиск, пока не закончится haystack.
        while (i < n) {

            // Если текущие символы совпали.
            if (haystack.charAt(i) == needle.charAt(j)) {

                // Переходим к следующему символу haystack.
                i++;

                // Переходим к следующему символу needle.
                j++;

                // Если совпали все символы needle.
                if (j == m) {

                    // Возвращаем индекс начала найденной подстроки.
                    return i - j;
                }

            } else {

                // Если произошло несовпадение.
                if (j > 0) {

                    // Используем информацию массива LPS.
                    // Индекс i не изменяем.
                    j = lps[j - 1];

                } else {

                    // Если совпадений ещё нет,
                    // переходим к следующему символу haystack.
                    i++;
                }
            }
        }

        // Если поиск завершился без совпадения.
        return -1;
    }

    // Метод строит массив LPS для строки needle.
    private int[] buildLps(String needle) {

        // Получаем длину искомой строки.
        int m = needle.length();

        // Создаём массив LPS длиной m.
        int[] lps = new int[m];

        // len хранит длину текущего совпавшего префикса.
        int len = 0;

        // Для первого символа длина LPS всегда равна нулю.
        lps[0] = 0;

        // Начинаем со второго символа строки needle.
        int i = 1;

        // Обрабатываем строку до последнего символа.
        while (i < m) {

            // Если текущий символ совпадает с символом,
            // на который указывает len.
            if (needle.charAt(i) == needle.charAt(len)) {

                // Увеличиваем длину совпавшего префикса.
                len++;

                // Сохраняем длину префикса в массиве LPS.
                lps[i] = len;

                // Переходим к следующему символу.
                i++;

            } else {

                // Если совпадения нет, но len больше нуля.
                if (len > 0) {

                    // Ищем более короткий подходящий префикс.
                    // Индекс i пока не увеличиваем.
                    len = lps[len - 1];

                } else {

                    // Подходящего префикса нет.
                    lps[i] = 0;

                    // Переходим к следующему символу.
                    i++;
                }
            }
        }

        // Возвращаем построенный массив LPS.
        return lps;
    }

    // Точка входа в программу.
    public static void main(String[] args) {

        // Создаём объект класса Solution1.
        Solution1 solution = new Solution1();

        // Пример 1: подстрока находится в начале строки.
        System.out.println(
            solution.strStr("sadbutsad", "sad")
        ); // Ожидаемый результат: 0

        // Пример 2: подстрока отсутствует.
        System.out.println(
            solution.strStr("leetcode", "leeto")
        ); // Ожидаемый результат: -1

        // Пример 3: подстрока находится внутри строки.
        System.out.println(
            solution.strStr("hello", "ll")
        ); // Ожидаемый результат: 2
    }
}
```

### Ожидаемый результат запуска

```text
0
-1
2
```

## 6. Подробное объяснение метода `strStr()`

Теперь рассмотрим каждую часть основного метода.

### 6.1. Объявление метода

```java
public int strStr(String haystack, String needle) {
```

Разберём объявление:

- `public` — метод доступен из других классов.
- `int` — метод возвращает целое число.
- `strStr` — название метода, используемое в условии задачи LeetCode.
- `String haystack` — основная строка.
- `String needle` — искомая подстрока.

### 6.2. Получение длины строк

```java
int n = haystack.length();
int m = needle.length();
```

Метод `length()` возвращает длину строки.

Для примера:

```java
String haystack = "hello";
String needle = "ll";
```

Получаем:

```text
n = 5
m = 2
```

Переменная `n` понадобится для определения момента завершения поиска.

Переменная `m` нужна для проверки, совпали ли все символы искомой строки.

### 6.3. Построение массива LPS

```java
int[] lps = buildLps(needle);
```

Здесь вызывается метод `buildLps()`, который возвращает массив целых чисел.

Например, для:

```text
needle = "ll"
```

получаем:

```text
lps = [0, 1]
```

Для:

```text
needle = "sad"
```

получаем:

```text
lps = [0, 0, 0]
```

Массив позволяет алгоритму эффективнее обрабатывать несовпадения.

### 6.4. Объявление индексов

```java
int i = 0;
int j = 0;
```

`i` указывает на текущий символ `haystack`.

`j` указывает на текущий символ `needle`.

Изначально обе переменные равны нулю, потому что поиск начинается с первого символа обеих строк.

### 6.5. Основной цикл

```java
while (i < n) {
```

Цикл продолжается, пока индекс `i` меньше длины `haystack`.

Когда `i` достигает `n`, все символы основной строки уже обработаны.

### 6.6. Сравнение символов

```java
if (haystack.charAt(i) == needle.charAt(j)) {
```

Метод `charAt()` возвращает символ по указанному индексу.

Например:

```java
haystack.charAt(2)
needle.charAt(0)
```

Если строки равны `"hello"` и `"ll"`, результат сравнения:

```text
'l' == 'l'
```

Условие истинно, поэтому алгоритм продолжает проверять следующие символы.

### 6.7. Переход к следующим символам

```java
i++;
j++;
```

Если символы совпали, обе переменные увеличиваются на единицу.

Это означает, что алгоритм успешно сравнил ещё один символ.

Например:

```text
До сравнения:
i = 2
j = 0

После совпадения:
i = 3
j = 1
```

Теперь проверяется следующий символ каждой строки.

### 6.8. Проверка полного совпадения

```java
if (j == m) {
    return i - j;
}
```

Если `j` равно `m`, это означает, что совпали все символы искомой строки.

Почему возвращается `i - j`?

Предположим:

```text
i = 4
j = 2
```

Это означает, что два символа искомой строки совпали, а `i` уже указывает на позицию сразу после последнего совпавшего символа.

Поэтому индекс начала найденной подстроки равен:

```text
4 - 2 = 2
```

Метод немедленно возвращает результат.

Это гарантирует, что будет возвращено первое вхождение.

### 6.9. Обработка несовпадения

```java
if (j > 0) {
    j = lps[j - 1];
} else {
    i++;
}
```

Если символы не совпали, возможны два случая.

**Случай 1: `j > 0`.**

Ранее несколько символов совпали, поэтому можно использовать информацию из LPS:

```java
j = lps[j - 1];
```

Индекс `i` не изменяется.

Это позволяет продолжить проверку текущего символа `haystack` с другой позиции `needle`, не начиная проверку заново.

**Случай 2: `j == 0`.**

Ни одного символа искомой строки пока не совпало.

В таком случае нет подходящего префикса, который можно использовать повторно, поэтому переходим к следующему символу основной строки:

```java
i++;
```

### 6.10. Завершение поиска

```java
return -1;
```

Если цикл завершился и полного совпадения не найдено, возвращаем `-1`.

Это соответствует условию задачи.

## 7. Подробное объяснение метода `buildLps()`

Метод `buildLps()` строит вспомогательный массив для алгоритма KMP.

```java
private int[] buildLps(String needle) {
```

- `private` означает, что метод доступен только внутри класса `Solution1`.
- `int[]` означает, что метод возвращает массив целых чисел.
- `needle` — строка, для которой строится массив.

### 7.1. Создание массива

```java
int m = needle.length();
int[] lps = new int[m];
```

Сначала определяем длину строки.

Затем создаём массив такой же длины.

Например:

```text
needle = "abab"
m = 4
```

Создаётся массив из четырёх элементов:

```text
lps = [0, 0, 0, 0]
```

В Java элементы массива `int` изначально равны нулю.

### 7.2. Переменная `len`

```java
int len = 0;
```

`len` хранит длину подходящего префикса, который одновременно является суффиксом уже обработанной части строки.

Например, для строки `"aba"` подходящий префикс и суффикс — `"a"`.

В этом случае:

```text
len = 1
```

### 7.3. Начальная позиция

```java
lps[0] = 0;
int i = 1;
```

Для первого символа LPS всегда равен нулю, поскольку у одного символа нет собственного непустого префикса.

Вычисление остальных значений начинается со второго символа, имеющего индекс `1`.

### 7.4. Основной цикл построения

```java
while (i < m) {
```

Цикл обрабатывает каждый оставшийся символ искомой строки.

### 7.5. Если символы совпадают

```java
if (needle.charAt(i) == needle.charAt(len)) {
    len++;
    lps[i] = len;
    i++;
}
```

Если символ в текущей позиции совпадает с символом, на который указывает `len`, длина подходящего префикса увеличивается.

Затем новое значение записывается в `lps[i]`.

После этого переходим к следующей позиции.

### 7.6. Если символы не совпадают

```java
if (len > 0) {
    len = lps[len - 1];
} else {
    lps[i] = 0;
    i++;
}
```

Если совпадения нет, возможны два случая.

Если `len > 0`, пробуем более короткий подходящий префикс, используя уже рассчитанные значения LPS.

Индекс `i` пока не меняется, потому что текущий символ ещё нужно проверить.

Если `len == 0`, подходящего префикса нет. Записываем ноль и переходим к следующему символу.

### 7.7. Возвращение массива

```java
return lps;
```

После обработки всех символов возвращаем готовый массив.

Он используется основным методом `strStr()` для ускорения поиска.


### Шаг 1. Получаем длины строк

```java
int n = haystack.length();
int m = needle.length();
```

Результат:

```text
n = 9
m = 3
```

### Шаг 2. Строим LPS

Для строки `"sad"`:

| Индекс | Символ | LPS |
|---:|:---:|---:|
| 0 | s | 0 |
| 1 | a | 0 |
| 2 | d | 0 |

Итог:

```text
lps = [0, 0, 0]
```

Ни один собственный непустой префикс соответствующих частей строки не совпадает с их суффиксом.

### Шаг 3. Инициализируем индексы

```text
i = 0
j = 0
```

Сравниваем символы `haystack[0]` и `needle[0]`.

```text
haystack[0] = 's'
needle[0] = 's'
```

Символы совпадают.

Увеличиваем индексы:

```text
i = 1
j = 1
```

### Шаг 4. Сравниваем следующие символы

```text
haystack[1] = 'a'
needle[1] = 'a'
```

Символы совпадают.

После увеличения:

```text
i = 2
j = 2
```

### Шаг 5. Сравниваем последние символы needle

```text
haystack[2] = 'd'
needle[2] = 'd'
```

Символы совпадают.

Теперь:

```text
i = 3

```

### Шаг 6. Проверяем завершение совпадения

```java
if (j == m)
```

Подставляем значения:


Условие истинно.

Вычисление:
