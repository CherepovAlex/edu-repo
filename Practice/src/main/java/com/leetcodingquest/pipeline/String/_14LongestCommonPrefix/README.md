# LeetCode №14 — Самый длинный общий префикс (Longest Common Prefix)

## 1. Условие задачи

**Задача:** [14. Longest Common Prefix на LeetCode](https://leetcode.com/problems/longest-common-prefix/)

Напишите функцию, которая находит самую длинную общую префиксную строку в массиве строк.

Если общего префикса нет, верните пустую строку `""`.

### Пример 1

**Входные данные:**

```java
strs = ["flower", "flow", "flight"]
```

**Результат:**

```text
"fl"
```

### Пример 2

**Входные данные:**

```java
strs = ["dog", "racecar", "car"]
```

**Результат:**

```text
""
```

**Пояснение:** у входных строк нет общего префикса.

### Пример 3

В условии LeetCode приведены два примера. Для дополнительной практики разберём ещё один:

**Входные данные:**

```java
strs = ["interspecies", "interstellar", "interstate"]
```

**Результат:**

```text
"inters"
```

### Ограничения

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` состоит только из строчных букв английского алфавита, если строка не пустая.

---

## 2. Что такое общий префикс?

**Префикс** — это последовательность символов в начале строки.

Например, для строки `flower` префиксами являются:

- `f`
- `fl`
- `flo`
- `flow`
- `flowe`
- `flower`

Для массива:

```text
flower
flow
flight
```

первые два символа во всех строках совпадают:

```text
fl
```

На третьем символе возникает различие:

- `flower` содержит `o`;
- `flow` содержит `o`;
- `flight` содержит `i`.

Поэтому самый длинный общий префикс — `"fl"`.

Важно:

- Префикс должен находиться именно в начале каждой строки.
- Нужно вернуть максимально длинный префикс, общий для всех строк.
- Если первый символ различается, результат — `""`.
- Если хотя бы одна строка пустая, результат — `""`.

---

## 3. Идея решения

Используем **горизонтальное сравнение строк**. Первую строку возьмём за образец, а затем будем проверять её символы по порядку во всех остальных строках.

Алгоритм:

1. Сохраняем первую строку в переменную `first`.
2. Перебираем индексы символов первой строки слева направо.
3. Для каждого индекса проверяем все остальные строки.
4. Если очередная строка закончилась раньше текущего индекса, возвращаем уже найденный префикс.
5. Если символы на текущей позиции различаются, также возвращаем уже найденный префикс.
6. Если все символы первой строки совпали во всех строках, возвращаем первую строку целиком.

Проверка длины строки выполняется **до** обращения к символу через `charAt(i)`. Это предотвращает выход за границы строки.

---

## 4. Решение на Java с комментариями к каждой строке

```java
class Solution { // Объявляем класс, который ожидает LeetCode.

    public String longestCommonPrefix(String[] strs) { // Метод принимает массив строк и возвращает общий префикс.

        String first = strs[0]; // Берём первую строку как образец для сравнения.

        for (int i = 0; i < first.length(); i++) { // Перебираем символы первой строки слева направо.

            for (int j = 1; j < strs.length; j++) { // Перебираем остальные строки, начиная со второй.

                if (i >= strs[j].length()) { // Проверяем, не закончилась ли текущая строка до позиции i.

                    return first.substring(0, i); // Возвращаем символы образца от начала до позиции i не включительно.
                } // Завершаем проверку длины строки.

                if (first.charAt(i) != strs[j].charAt(i)) { // Сравниваем символы двух строк на позиции i.

                    return first.substring(0, i); // При несовпадении возвращаем уже найденный общий префикс.
                } // Завершаем проверку совпадения символов.
            } // Завершаем перебор остальных строк.
        } // Завершаем перебор символов первой строки.

        return first; // Если несовпадений нет, первая строка целиком является общим префиксом.
    } // Завершаем метод longestCommonPrefix.
} // Завершаем класс Solution.
```

### Важное замечание о комментариях

Комментарии после `return` описывают действие строки, но сам метод `return` немедленно завершает выполнение метода. Поэтому после найденного несовпадения остальные сравнения уже не выполняются.

## 5. Подробный разбор каждой конструкции

### 5.1. Объявление класса

```java
class Solution {
```

Объявляем класс `Solution`. На LeetCode обычно не нужно писать метод `main()`: платформа самостоятельно вызывает метод решения.

### 5.2. Объявление метода

```java
public String longestCommonPrefix(String[] strs) {
```

- `public` — метод доступен для вызова извне класса.
- `String` — тип значения, которое возвращает метод.
- `longestCommonPrefix` — имя метода.
- `String[] strs` — входной массив строк.

### 5.3. Выбор первой строки

```java
String first = strs[0];
```

Индекс `0` обозначает первый элемент массива. Сохраняем его в переменную `first`, чтобы использовать как образец.

Например, если:

```java
String[] strs = {"flower", "flow", "flight"};
```

то:

```java
first = "flower";
```

### 5.4. Внешний цикл

```java
for (int i = 0; i < first.length(); i++) {
```

Внешний цикл перебирает символы первой строки.

- `int i = 0` — начинаем с индекса `0`.
- `i < first.length()` — продолжаем, пока индекс меньше длины строки.
- `i++` — увеличиваем индекс на единицу после каждой итерации.

Индексы строки `flower`:

| Индекс | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| Символ | `f` | `l` | `o` | `w` | `e` | `r` |

В Java индексация начинается с нуля.

### 5.5. Внутренний цикл

```java
for (int j = 1; j < strs.length; j++) {
```

Внутренний цикл перебирает все строки, кроме первой.

- `j = 1` — начинаем со второй строки.
- `j < strs.length` — идём до последней строки.
- `j++` — переходим к следующей строке.

Первая строка не включена в этот цикл, потому что она уже используется как образец.

### 5.6. Проверка длины строки

```java
if (i >= strs[j].length()) {
    return first.substring(0, i);
}
```

Проверяем, существует ли в текущей строке символ с индексом `i`.

Например, сравним строки `"flower"` и `"fl"`:

- На индексах `0` и `1` символы совпадают.
- При `i = 2` длина строки `"fl"` равна `2`.
- Индекса `2` в строке `"fl"` не существует.

Поэтому возвращаем:

```java
first.substring(0, 2); // "fl"
```

Проверка длины нужна, чтобы не получить исключение `StringIndexOutOfBoundsException`.

### 5.7. Сравнение символов

```java
if (first.charAt(i) != strs[j].charAt(i)) {
    return first.substring(0, i);
}
```

- `first.charAt(i)` — символ образца на позиции `i`.
- `strs[j].charAt(i)` — символ текущей строки на той же позиции.
- `!=` — оператор проверки неравенства.

Если символы различаются, общий префикс заканчивается перед индексом `i`.

Например:

```java
first.charAt(2)       // 'o'
strs[2].charAt(2)     // 'i'
```

Так как `'o' != 'i'`, метод возвращает:

```java
first.substring(0, 2); // "fl"
```

### 5.8. Метод `substring(0, i)`

```java
first.substring(0, i)
```

Метод `substring(beginIndex, endIndex)` возвращает часть строки:

- начальный индекс включается;
- конечный индекс не включается.

Примеры:

```java
"flower".substring(0, 2); // "fl"
"flower".substring(0, 1); // "f"
"flower".substring(0, 0); // ""
```

Именно поэтому при несовпадении на индексе `i` мы используем `substring(0, i)`, а не `substring(0, i + 1)`.

### 5.9. Возврат первой строки

```java
return first;
```

Если внешний цикл завершился, значит, ни одного несовпадения не обнаружено. Все символы первой строки присутствуют в начале остальных строк. Поэтому первая строка целиком является самым длинным общим префиксом.

## 6. Пошаговое выполнение примера №1

Входные данные:

```java
String[] strs = {"flower", "flow", "flight"};
```

Ожидаемый результат:

```text
"fl"
```

Сначала выполняется:

```java
String first = strs[0];
```

Теперь `first` содержит `"flower"`.

### Шаг 1. Индекс `i = 0`

Сравниваем первые символы:

| Сравнение | Результат |
|---|---|
| `flower` и `flow` | `'f' == 'f'` — совпадают |
| `flower` и `flight` | `'f' == 'f'` — совпадают |

Первый символ общего префикса — `f`.

### Шаг 2. Индекс `i = 1`

Сравниваем вторые символы:

| Сравнение | Результат |
|---|---|
| `flower` и `flow` | `'l' == 'l'` — совпадают |
| `flower` и `flight` | `'l' == 'l'` — совпадают |

Теперь общий префикс — `fl`.

### Шаг 3. Индекс `i = 2`

Сравниваем третьи символы:

| Сравнение | Результат |
|---|---|
| `flower` и `flow` | `'o' == 'o'` — совпадают |
| `flower` и `flight` | `'o' != 'i'` — не совпадают |

Выполняется условие:

```java
if (first.charAt(2) != strs[2].charAt(2))
```

Затем:

```java
return first.substring(0, 2);
```

Результат:

```text
"fl"
```

Метод немедленно завершается. Проверять символы с индексами `3`, `4` и `5` больше не нужно.

## 7. Пошаговое выполнение примера №2

Входные данные:

```java
String[] strs = {"dog", "racecar", "car"};
```

Ожидаемый результат:

```text
""
```

Первая строка:

```java
first = "dog";
```

Внешний цикл начинает с `i = 0`.

Внутренний цикл начинает со `j = 1`, поэтому сравниваются строки `"dog"` и `"racecar"`.

| Выражение | Значение |
|---|---|
| `i` | `0` |
| `first.charAt(0)` | `'d'` |
| `strs[1].charAt(0)` | `'r'` |
| `'d' != 'r'` | `true` |

Условие несовпадения выполняется. Метод возвращает:

```java
return first.substring(0, 0);
```

Вызов `substring(0, 0)` возвращает пустую строку, потому что выбранный диапазон не содержит символов.

**Результат:**

```text
""
```

До сравнения с `"car"` программа не доходит: уже доказано, что общего первого символа нет.

## 8. Пошаговое выполнение примера №3

Входные данные:

```java
String[] strs = {
    "interspecies",
    "interstellar",
    "interstate"
};
```

Ожидаемый результат:

```text
"inters"
```

Первая строка:

```java
first = "interspecies";
```

Сравниваем символы с начала строки:

| Индекс `i` | `interspecies` | `interstellar` | `interstate` | Результат |
|---:|:---:|:---:|:---:|---|
| 0 | `i` | `i` | `i` | Совпадение |
| 1 | `n` | `n` | `n` | Совпадение |
| 2 | `t` | `t` | `t` | Совпадение |
| 3 | `e` | `e` | `e` | Совпадение |
| 4 | `r` | `r` | `r` | Совпадение |
| 5 | `s` | `s` | `s` | Совпадение |
| 6 | `p` | `t` | `t` | Несовпадение |

На индексах от `0` до `5` символы совпадают. Общий префикс — `inters`.

На индексе `6` обнаруживается различие: первая строка содержит `p`, а вторая — `t`.

Выполняется:

```java
return first.substring(0, 6);
```

Результат:

```text
"inters"
```

## 9. Временная и пространственная сложность

Обозначения:

- `n` — количество строк;
- `m` — длина первой строки;
- `S` — суммарное количество символов во всех строках.

### Временная сложность

**`O(S)`** в худшем случае.

Алгоритм сравнивает символы строк до первого несовпадения или до конца одной из строк. Каждая позиция проверяется ограниченное количество раз, поэтому суммарное число сравнений пропорционально общему количеству входных символов.

Верхнюю оценку также можно записать как `O(n × m)`, если обозначить через `m` максимальную длину строки.

### Дополнительная пространственная сложность

**`O(1)`** вспомогательной памяти: алгоритм использует только несколько переменных (`first`, `i`, `j`) и не создаёт дополнительные массивы или коллекции.

Возвращаемая строка может содержать до `m` символов. Это память результата, которую обычно рассматривают отдельно от вспомогательной памяти.

### Почему это решение эффективно?

- Не требуется сортировка массива.
- Не создаются дополнительные коллекции.
- Сравнение прекращается сразу после первого несовпадения.
- Не проверяются символы, которые уже не могут войти в общий префикс.

## 11. Краткий итог

В решении используются следующие конструкции Java:

- `for` — перебор индексов символов и строк;
- `length()` — получение длины строки;
- `charAt(i)` — получение символа по индексу;
- `substring(0, i)` — получение уже найденного общего префикса;
- `return` — немедленное завершение метода с результатом.

**Главная идея:** сравнивать строки посимвольно, начиная с начала, и вернуть найденный префикс при первом несовпадении.

Это решение соответствует интерфейсу LeetCode, не требует дополнительных библиотек и не нуждается в методе `main()`.
