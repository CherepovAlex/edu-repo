# LeetCode 14: Longest Common Prefix

> **Курс:** Java Development  
> **Тема:** Работа со строками и алгоритмическая эффективность  
> **Сложность:** Easy

Этот документ содержит подробное решение задачи **Longest Common Prefix** (Самый длинный общий префикс) на языке Java. Решение оптимизировано по времени и пространству, сопровождается пошаговым объяснением логики и разбором примеров.

---

## 📋 Условие задачи

Напишите функцию, которая находит самую длинную общую префиксную строку в массиве строк.

Если общего префикса нет, верните пустую строку `""`.

### Примеры

**Пример 1:**
```text
Входные данные: strs = ["flower","flow","flight"]
Результат: "fl"
```

**Пример 2:**
```text
Входные данные: strs = ["dog","racecar","car"]
Результат: ""
Пояснение: У входных строк нет общего префикса.
```

### Ограничения
- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` состоит только из строчных букв английского алфавита, если она не пустая.

---

## 💡 Логика решения

### Что такое префикс?
Префикс — это подстрока, которая начинается с самого начала строки. Например, для строки `"flower"` префиксами являются: `"f"`, `"fl"`, `"flo"`, `"flow"`, `"flowe"`, `"flower"`.

### Стратегия: Горизонтальное сравнение (Horizontal Scanning)

Самый интуитивный и эффективный подход — использовать первую строку как **эталон** (candidate), а затем последовательно сравнивать её с остальными строками массива, сокращая эталон до тех пор, пока он не станет префиксом текущей строки.

**Алгоритм:**
1. Возьмем первую строку `strs[0]` как текущий предполагаемый префикс (`prefix`).
2. Пройдем по всем остальным строкам массива.
3. Для каждой строки `strs[i]`:
   - Проверяем, начинается ли `strs[i]` с текущего `prefix`.
   - Если **нет**, укорачиваем `prefix` на один символ (убираем последний символ) и повторяем проверку.
   - Если `prefix` становится пустым, значит, общего префикса нет — возвращаем `""`.
4. Если мы успешно прошли через все строки, оставшийся `prefix` является самым длинным общим префиксом.

> **Почему это оптимально?**
> Мы не создаем новых больших структур данных. Мы модифицируем одну переменную `prefix`. В худшем случае мы просматриваем каждый символ массива один раз.

---

## 💻 Решение на Java

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        // 1. Проверка на граничные случаи: пустой массив или null
        if (strs == null || strs.length == 0) {
            return "";
        }

        // 2. Инициализируем префикс первой строкой из массива
        String prefix = strs[0];

        // 3. Проходим по всем остальным строкам в массиве (начиная со второй)
        for (int i = 1; i < strs.length; i++) {
            
            // 4. Пока текущая строка strs[i] НЕ начинается с текущего префикса,
            // мы укорачиваем префикс, убирая последний символ.
            // Метод startsWith проверяет, является ли строка префиксом другой строки.
            while (!strs[i].startsWith(prefix)) {
                
                // 5. Укорачиваем префикс на 1 символ.
                // substring(0, length - 1) берет строку от начала до предпоследнего символа.
                prefix = prefix.substring(0, prefix.length() - 1);
                
                // 6. Если префикс стал пустым, значит общей части нет вообще.
                if (prefix.isEmpty()) {
                    return "";
                }
            }
        }

        // 7. Если цикл завершился успешно, prefix содержит самый длинный общий префикс
        return prefix;
    }
}
```

## 🧪 Разбор примеров (Trace)

### Пример 1: `strs = ["flower", "flow", "flight"]`

1. **Инициализация:**
   - `prefix = "flower"` (первая строка).
   - Цикл начинается с `i = 1` (строка `"flow"`).

2. **Итерация 1 (`i = 1`, строка `"flow"`):**
   - Проверяем: `"flow".startsWith("flower")`? **Нет**.
   - Внутренний `while` запускается:
     - Сокращаем `prefix`: `"flower" -> "flowe"`
     - Проверяем: `"flow".startsWith("flowe")`? **Нет**.
     - Сокращаем `prefix`: `"flowe" -> "flow"`
     - Проверяем: `"flow".startsWith("flow")`? **Да!**
   - Цикл `while` останавливается.
   - Текущий `prefix = "flow"`.

3. **Итерация 2 (`i = 2`, строка `"flight"`):**
   - Проверяем: `"flight".startsWith("flow")`? **Нет**.
   - Внутренний `while` запускается:
     - Сокращаем `prefix`: `"flow" -> "flo"`
     - Проверяем: `"flight".startsWith("flo")`? **Нет**.
     - Сокращаем `prefix`: `"flo" -> "fl"`
     - Проверяем: `"flight".startsWith("fl")`? **Да!**
   - Цикл `while` останавливается.
   - Текущий `prefix = "fl"`.

4. **Конец цикла `for`** (строк больше нет).
5. **Возврат:** `"fl"`. ✅

---

### Пример 2: `strs = ["dog", "racecar", "car"]`

1. **Инициализация:**
   - `prefix = "dog"`.
   - Цикл начинается с `i = 1` (строка `"racecar"`).

2. **Итерация 1 (`i = 1`, строка `"racecar"`):**
   - Проверяем: `"racecar".startsWith("dog")`? **Нет**.
   - Внутренний `while` запускается:
     - Сокращаем `prefix`: `"dog" -> "do"`
     - Проверяем: `"racecar".startsWith("do")`? **Нет**.
     - Сокращаем `prefix`: `"do" -> "d"`
     - Проверяем: `"racecar".startsWith("d")`? **Нет**.
     - Сокращаем `prefix`: `"d" -> ""` (пустая строка)
     - Проверяем `prefix.isEmpty()`? **Да**.
     - **Возвращаем `""`**.

3. **Результат:** `""`. ✅

### Пример 3 (Дополнительный): `strs = ["interspecies", "interstellar", "interstate"]`

1. **Инициализация:**
   - `prefix = "interspecies"`.

2. **Итерация 1 (`i = 1`, строка `"interstellar"`):**

   - Сокращаем `prefix`:
     - `"inters" -> "inter"`
     - `"interstate".startsWith("inter")`? **Да**.
   - `prefix = "inter"`.

5. **Возврат:** `"inter"`. ✅

## 📊 Анализ сложности

### Временная сложность: $O(S)$
Где $S$ — сумма длин всех строк в массиве.
- В худшем случае (все строки совпадают), мы просматриваем каждый символ один раз.
- В лучшем случае (первая буква не совпадает), мы делаем минимум операций, быстро возвращая `""`.
- Метод `startsWith` работает за время, пропорциональное длине префикса, но так как префикс постоянно уменьшается, общая сложность остается линейной относительно общего количества символов.

### Пространственная сложность: $O(1)$
- Мы используем только одну дополнительную переменную `prefix` для хранения результата.
- Не создаем новых массивов или сложных структур данных.
- *Примечание:* В Java строки неизменяемы, поэтому `substring` может создавать новые объекты, но их количество ограничено длиной самой длинной строки, что не зависит от размера входного массива $N$.

## 💡 Советы для собеседований

1. **Граничные случаи:** Всегда проверяй пустой массив (`null` или `length == 0`) и массив с одной строкой.
2. **Эффективность:** Не используй вложенные циклы `for` для посимвольного сравнения вручную, если можно использовать встроенные методы вроде `startsWith`. Они оптимизированы на уровне JVM и читаются лучше.
3. **Читаемость:** Код должен быть понятным. Использование `startsWith` делает логику более декларативной: "пока строка не начинается с префикса, сокращай префикс".
4. **Альтернативы:** Можно также использовать **вертикальное сканирование** (сравнение символов по индексам для всех строк сразу) или **бинарный поиск** по длине префикса, но горизонтальное сканирование часто проще в реализации и достаточно эффективно для большинства случаев.
