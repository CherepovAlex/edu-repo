## Условие задачи

Реализуйте метод `myAtoi(String s)`, который преобразует строку в 32-разрядное целое число со знаком (`int`).

Алгоритм должен выполнять следующие действия:

1. **Пробелы.** Игнорировать все начальные пробелы `' '`.
2. **Знак.** Определить знак числа по следующему символу:
   - `'-'` — отрицательное число;
   - `'+'` — положительное число;
   - если знака нет, считать число положительным.
3. **Преобразование.** Прочитать последовательность цифр до первого нецифрового символа или до конца строки.
4. **Нет цифр.** Если цифры не были прочитаны, вернуть `0`.
5. **Переполнение.** Если значение выходит за пределы 32-разрядного знакового целого числа, ограничить результат допустимой границей.

Диапазон Java `int`:

| Константа | Значение |
|---|---:|
| `Integer.MIN_VALUE` | `-2147483648` |
| `Integer.MAX_VALUE` | `2147483647` |

**Ограничение:** нельзя использовать готовые методы преобразования строки в число, например `Integer.parseInt()`, `Integer.valueOf()` или аналогичные. Преобразование нужно выполнить вручную.

### Ограничения входных данных

- `0 <= s.length() <= 200`
- Строка `s` состоит из английских букв в нижнем и верхнем регистре, цифр `0`–`9`, пробелов `' '`, знаков `'+'`, `'-'` и точек `'.'`.

## Идея решения

Будем читать строку слева направо с помощью индекса `i`. Для накопления числа используем переменную `result`.

Преобразование выполняется в несколько этапов:

1. Пропускаем начальные пробелы.
2. Определяем знак числа.
3. Последовательно читаем цифры.
4. Передаём каждую цифру в накопитель по формуле:

   ```text
   result = result * 10 + digit
   ```

5. Проверяем, не вышло ли накопленное значение за допустимую границу.
6. Возвращаем число с учётом знака.

### Как преобразовать символ в цифру?

В Java можно получить числовое значение символа цифры вычитанием символа `'0'`:

```java
int digit = c - '0';
```

Например, если `c == '7'`, выражение `c - '0'` даст `7`.

Перед преобразованием необходимо убедиться, что символ является цифрой:

```java
c >= '0' && c <= '9'
```

### Почему нельзя просто использовать `int`?

Промежуточное вычисление может выйти за диапазон `int` ещё до того, как программа успеет проверить переполнение. Поэтому в решении для накопления числа используется `long`.

У положительного числа максимально допустимый модуль равен `2147483647`, а у отрицательного — `2147483648`. Эти границы различаются на единицу, поэтому их нужно обрабатывать отдельно.

## Алгоритм

1. Получить длину строки `n`.
2. Установить индекс `i = 0`.
3. Пока текущий символ — пробел, увеличивать `i`.
4. Установить `sign = 1`.
5. Если текущий символ — `'-'`, установить `sign = -1` и сдвинуть индекс.
6. Иначе, если текущий символ — `'+'`, сдвинуть индекс.
7. Установить `result = 0`.
8. Выбрать допустимый модуль числа в зависимости от знака.
9. Пока индекс не вышел за границы строки:
   - получить текущий символ;
   - если это не цифра, прекратить чтение;
   - преобразовать символ в цифру;
   - добавить цифру к `result`;
   - если `result` превышает допустимую границу, вернуть соответствующую границу `int`;
   - увеличить индекс.
10. Вернуть `result * sign`.

## Решение на Java

Класс `Solution` готов для отправки на LeetCode. Комментарии объясняют назначение каждой строки кода.

```java
class Solution { // Объявляем класс с решением задачи LeetCode.

    public int myAtoi(String s) { // Объявляем метод, преобразующий строку в int.
        int n = s.length(); // Сохраняем длину строки, чтобы не вычислять её повторно.
        int i = 0; // Создаём индекс для чтения символов строки.

        while (i < n && s.charAt(i) == ' ') { // Пока не достигнут конец строки и текущий символ — пробел.
            i++; // Пропускаем начальный пробел.
        } // Завершаем цикл пропуска пробелов.

        int sign = 1; // По умолчанию считаем число положительным.

        if (i < n && s.charAt(i) == '-') { // Проверяем, есть ли минус после начальных пробелов.
            sign = -1; // Устанавливаем отрицательный знак.
            i++; // Переходим к символу после минуса.
        } else if (i < n && s.charAt(i) == '+') { // Иначе проверяем, есть ли плюс.
            i++; // Пропускаем плюс, сохраняя положительный знак.
        } // Завершаем определение знака.

        long result = 0; // Создаём накопитель числа типа long для безопасной проверки границ.
        long limit = sign == 1 // Выбираем максимально допустимую абсолютную величину.
                ? Integer.MAX_VALUE // Для положительного числа предел равен 2147483647.
                : -(long) Integer.MIN_VALUE; // Для отрицательного числа предел равен 2147483648.

        while (i < n) { // Продолжаем, пока в строке остаются символы.
            char c = s.charAt(i); // Получаем текущий символ.

            if (c < '0' || c > '9') { // Проверяем, не является ли символ цифрой.
                break; // Прекращаем чтение на первом нецифровом символе.
            } // Завершаем проверку символа.

            int digit = c - '0'; // Преобразуем символ цифры в числовое значение от 0 до 9.
            result = result * 10 + digit; // Добавляем очередную цифру справа к накопленному числу.

            if (result > limit) { // Проверяем, вышло ли накопленное число за допустимую границу.
                return sign == 1 // Если число переполнено, выбираем результат по знаку.
                        ? Integer.MAX_VALUE // Ограничиваем положительное число сверху.
                        : Integer.MIN_VALUE; // Ограничиваем отрицательное число снизу.
            } // Завершаем проверку переполнения.

            i++; // Переходим к следующему символу после успешной обработки цифры.
        } // Завершаем чтение последовательности цифр.

        return (int) (result * sign); // Применяем знак и возвращаем результат типа int.
    } // Завершаем метод myAtoi.
} // Завершаем класс Solution.
```

## Подробное объяснение кода

### 1. Длина строки и индекс

```java
int n = s.length();
int i = 0;
```

`n` хранит количество символов в строке. `i` показывает позицию символа, который обрабатывается в данный момент.

Если строка пустая, `n` равно `0`. Все циклы чтения пропускаются, а метод возвращает `0`.

### 2. Пропуск начальных пробелов

```java
while (i < n && s.charAt(i) == ' ') {
    i++;
}
```

Пока индекс находится в пределах строки и текущий символ — пробел, мы передвигаемся на одну позицию вправо.

Проверка `i < n` стоит первой, чтобы не вызвать `charAt(i)` за пределами строки.

Пропускаются только пробелы в начале. Пробел после цифр завершит чтение числа.

### 3. Определение знака

```java
int sign = 1;

if (i < n && s.charAt(i) == '-') {
    sign = -1;
    i++;
} else if (i < n && s.charAt(i) == '+') {
    i++;
}
```

Изначально число считается положительным.

- Если найден `'-'`, знак становится `-1`.
- Если найден `'+'`, знак остаётся `1`.
- Если знак отсутствует, ничего менять не нужно.

После распознавания знака индекс сдвигается, чтобы далее читать цифры, а не сам знак.

Если строка состоит только из знака, например `"+"` или `"-"`, цикл чтения цифр не выполнится и метод вернёт `0`.

### 4. Накопитель и допустимая граница

```java
long result = 0;
long limit = sign == 1
        ? Integer.MAX_VALUE
        : -(long) Integer.MIN_VALUE;
```

Переменная `result` хранит число без знака. Знак будет применён в конце.

Тернарный оператор выбирает границу:

- положительный знак: `2147483647`;
- отрицательный знак: `2147483648`.

Выражение `-(long) Integer.MIN_VALUE` сначала преобразует минимальное значение `int` в `long`, а затем меняет знак. Это важно, потому что положительное значение `2147483648` невозможно представить типом `int`.

### 5. Чтение цифр

```java
while (i < n) {
    char c = s.charAt(i);

    if (c < '0' || c > '9') {
        break;
    }

    int digit = c - '0';
    result = result * 10 + digit;
}
```

На каждой итерации:

1. Читаем текущий символ.
2. Проверяем, находится ли он в диапазоне цифр.
3. Если это не цифра, прекращаем цикл.
4. Иначе преобразуем символ в число.
5. Добавляем цифру к накопленному значению.

Например, при чтении `"42"`:

- сначала `result = 0 * 10 + 4 = 4`;
- затем `result = 4 * 10 + 2 = 42`.

В полном решении после обработки цифры также выполняется проверка переполнения и увеличивается индекс `i`.

### 6. Проверка переполнения

```java
if (result > limit) {
    return sign == 1
            ? Integer.MAX_VALUE
            : Integer.MIN_VALUE;
}
```

Если модуль накопленного числа превысил допустимую границу, возвращаем максимально допустимое или минимально допустимое значение `int`.

Проверка выполняется после добавления цифры, потому что накопитель имеет тип `long` и может безопасно представить промежуточное значение, которое не помещается в `int`.

### 7. Возврат результата

```java
return (int) (result * sign);
```

Если переполнения не было, умножаем накопленное число на знак и возвращаем результат.

Преобразование к `int` безопасно, поскольку перед возвратом значение уже проверено на соответствие допустимому диапазону.

## Пошаговый разбор примеров

### Пример 1. Обычное положительное число

**Вход:** `s = "42"`  
**Ожидаемый выход:** `42`

#### Шаг 1. Пропуск пробелов

Первый символ — `'4'`, а не пробел. Цикл пропуска пробелов не выполняется.

- `i = 0`
- `sign` пока не определён окончательно.

#### Шаг 2. Определение знака

Символ `'4'` не равен ни `'-'`, ни `'+'`.

- `sign = 1`
- `i = 0`

#### Шаг 3. Чтение цифр

| Символ | Вычисление | `result` после чтения |
|---|---|---:|
| `'4'` | `0 * 10 + 4` | 4 |
| `'2'` | `4 * 10 + 2` | 42 |

Обе цифры обработаны. Индекс достигает конца строки.

#### Шаг 4. Возврат результата

`result * sign = 42 * 1 = 42`.

**Ответ: `42`.**

### Пример 2. Пробел, отрицательный знак и ведущий ноль

**Вход:** `s = " -042"`  
**Ожидаемый выход:** `-42`

#### Шаг 1. Пропуск пробелов

Символ с индексом `0` — пробел. Индекс увеличивается до `1`, где находится `'-'`.

#### Шаг 2. Определение знака

Обнаружен `'-'`.

- `sign = -1`
- индекс увеличивается до `2`, где находится `'0'`.

#### Шаг 3. Чтение цифр

| Символ | Вычисление | `result` после чтения |
|---|---|---:|
| `'0'` | `0 * 10 + 0` | 0 |
| `'4'` | `0 * 10 + 4` | 4 |
| `'2'` | `4 * 10 + 2` | 42 |

Ведущий ноль не меняет числовое значение.

#### Шаг 4. Применение знака

`result * sign = 42 * (-1) = -42`.

**Ответ: `-42`.**

### Пример 3. Число с буквами в конце

**Вход:** `s = "1337c0d3"`  
**Ожидаемый выход:** `1337`

#### Шаг 1. Пропуск пробелов и определение знака

Первый символ — `'1'`. Пробелов и знака нет.

- `sign = 1`
- `i = 0`

#### Шаг 2. Чтение цифр

| Индекс | Символ | `result` после чтения |
|---:|---|---:|
| 0 | `'1'` | 1 |
| 1 | `'3'` | 13 |
| 2 | `'3'` | 133 |
| 3 | `'7'` | 1337 |

#### Шаг 3. Остановка на букве

Следующий символ — `'c'`. Он не входит в диапазон `'0'`–`'9'`, поэтому срабатывает `break`.

Символы `0d3` после буквы больше не обрабатываются.

#### Шаг 4. Возврат результата

`result * sign = 1337 * 1 = 1337`.

**Ответ: `1337`.**

### Пример 4. Минус после первой цифры

**Вход:** `s = "0-1"`  
**Ожидаемый выход:** `0`

#### Шаг 1. Пропуск пробелов и определение знака

Пробелов нет. Первый символ — `'0'`, поэтому `sign = 1`.

#### Шаг 2. Чтение первой цифры

Обрабатываем `'0'`:

`result = 0 * 10 + 0 = 0`.

#### Шаг 3. Остановка на минусе

Индекс переходит к символу `'-'`. Он не является цифрой, поэтому цикл завершается. Символ `'1'` не читается.

**Ответ: `0`.**

Минус может определять знак только до начала чтения цифр. Он не меняет знак уже начатого числа.

### Пример 5. Строка начинается с букв

**Вход:** `s = "words and 987"`  
**Ожидаемый выход:** `0`

#### Шаг 1. Пропуск пробелов

Первый символ — `'w'`, поэтому цикл пропуска пробелов не выполняется.

#### Шаг 2. Определение знака

Символ `'w'` не является знаком. `sign` остаётся равным `1`.

#### Шаг 3. Проверка первой цифры

Символ `'w'` не является цифрой. Цикл чтения завершается сразу, а `result` остаётся равным `0`.

Цифры `987` не рассматриваются, потому что алгоритм не ищет число в произвольном месте строки.

**Ответ: `0`.**

## Проверка переполнения

Рассмотрим строку:

```text
s = "2147483648"
```

До последней цифры накопленное значение равно `214748364`. После чтения последней цифры `8` вычисляется:

```text
214748364 * 10 + 8 = 2147483648
```

Это число больше `Integer.MAX_VALUE`, равного `2147483647`. Метод возвращает `Integer.MAX_VALUE`.

Для отрицательной строки `"-2147483649"` допустимый модуль равен `2147483648`. Как только накопленное значение превышает этот предел, метод возвращает `Integer.MIN_VALUE`.

| Входная строка | Результат | Причина |
|---|---:|---|
| `"2147483647"` | `2147483647` | Максимальный `int`, значение допустимо |
| `"2147483648"` | `2147483647` | Положительное переполнение |
| `"-2147483648"` | `-2147483648` | Минимальный `int`, значение допустимо |
| `"-2147483649"` | `-2147483648` | Отрицательное переполнение |

## Дополнительные тесты

| Входная строка | Ожидаемый результат | Объяснение |
|---|---:|---|
| `"+"` | `0` | После знака нет цифр |
| `"-"` | `0` | После знака нет цифр |
| `"   "` | `0` | После пробелов строка заканчивается |
| `""` | `0` | Пустая строка |
| `"000123"` | `123` | Ведущие нули не влияют на значение |
| `"  +0012abc"` | `12` | Читаем цифры до буквы |
| `"--12"` | `0` | Второй минус не является цифрой |
| `"12.34"` | `12` | Чтение останавливается на точке |
| `"  -0"` | `0` | Отрицательный ноль возвращается как `0` |

## Сложность алгоритма

Обозначим длину строки через `n`.

- **Временная сложность: `O(n)`.** Каждый символ просматривается не более одного раза. В худшем случае алгоритм обрабатывает всю строку.
- **Дополнительная пространственная сложность: `O(1)`.** Используется фиксированное количество переменных (`n`, `i`, `sign`, `result`, `limit`, `c` и `digit`), не зависящее от длины строки.

Такое решение оптимально по времени в худшем случае и использует постоянную дополнительную память.

## Итоги

При решении LeetCode 8 важно соблюдать порядок действий:

1. Пропустить начальные пробелы.
2. Определить необязательный знак.
3. Читать только последовательность цифр.
4. Остановиться на первом нецифровом символе.
5. Контролировать переполнение и ограничивать результат диапазоном `int`.

Решение вручную преобразует символы в цифры, не использует запрещённые библиотечные методы и корректно обрабатывает пустые строки, знаки, ведущие нули, посторонние символы и переполнение.

**Итоговая сложность:** `O(n)` по времени и `O(1)` по дополнительной памяти.
