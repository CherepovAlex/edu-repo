# LeetCode №13 — Римские цифры в целое число (Roman to Integer)

## 1. Условие задачи

Дана строка `s`, содержащая римское число. Необходимо преобразовать её в обычное целое число.

Примеры:

- `III` → `3`
- `LVIII` → `58`
- `MCMXCIV` → `1994`

Римские числа состоят из семи символов:

| Символ | Значение |
|---|---:|
| `I` | 1 |
| `V` | 5 |
| `X` | 10 |
| `L` | 50 |
| `C` | 100 |
| `D` | 500 |
| `M` | 1000 |

Ограничения:

- `1 <= s.length <= 15`
- Строка содержит только символы `I`, `V`, `X`, `L`, `C`, `D`, `M`.
- Гарантируется, что `s` — корректное римское число в диапазоне от 1 до 3999.

## 2. Главное правило римских чисел

Обычно значения римских символов складываются.

Например, `VIII`:

```text
V = 5
I = 1
I = 1
I = 1

5 + 1 + 1 + 1 = 8
```

Но если меньший символ стоит **перед** символом большего значения, его нужно вычесть.

Например, `IV`:

```text
I = 1
V = 5

5 - 1 = 4
```

Есть шесть стандартных случаев вычитания:

| Пара | Вычисление | Результат |
|---|---:|---:|
| `IV` | 5 - 1 | 4 |
| `IX` | 10 - 1 | 9 |
| `XL` | 50 - 10 | 40 |
| `XC` | 100 - 10 | 90 |
| `CD` | 500 - 100 | 400 |
| `CM` | 1000 - 100 | 900 |

Например, `VI` означает `5 + 1 = 6`, потому что меньший символ стоит после большего.

## 3. Идея алгоритма

Будем проходить строку слева направо, по одному символу.

Для каждого символа:

1. Получим его числовое значение.
2. Посмотрим, существует ли следующий символ.
3. Если следующий символ есть и текущее значение меньше следующего — вычтем текущее значение из суммы.
4. В остальных случаях прибавим текущее значение.
5. После обработки всех символов вернём сумму.

Для этого нужны три основных понятия:

- `current` — значение текущего символа.
- `next` — значение следующего символа.
- `sum` — накопленный результат.

Правило можно записать так:

```text
Если current < next:
    sum = sum - current
Иначе:
    sum = sum + current
```

Для последнего символа следующего символа нет, поэтому просто прибавляем его значение.

### Пример: `IV`

Начинаем с `sum = 0`.

1. Текущий символ `I` равен 1, следующий `V` равен 5.
2. `1 < 5`, поэтому вычитаем 1: `sum = 0 - 1 = -1`.
3. Теперь обрабатываем `V`, значение которого равно 5. Это последний символ.
4. Прибавляем 5: `sum = -1 + 5 = 4`.

Ответ — `4`.

Важно: промежуточная сумма может быть отрицательной. Это нормально: в конце итоговое значение будет правильным.

## 4. Полное решение на Java

Код для отправки на LeetCode:

```java
class Solution { // Объявляем класс с решением задачи LeetCode.

    public int romanToInt(String s) { // Принимаем римское число и возвращаем его целочисленное значение.
        int sum = 0; // Создаём переменную для итоговой суммы; сначала она равна нулю.

        for (int i = 0; i < s.length(); i++) { // Перебираем строку слева направо от первого символа до последнего.
            int current = getValue(s.charAt(i)); // Получаем числовое значение текущего символа.

            if (i + 1 < s.length()) { // Проверяем, существует ли следующий символ, чтобы не выйти за границы строки.
                int next = getValue(s.charAt(i + 1)); // Получаем числовое значение следующего символа.

                if (current < next) { // Если текущий символ меньше следующего, нужно вычесть его значение.
                    sum -= current; // Вычитаем значение текущего символа из общей суммы.
                } else { // Иначе значения нужно складывать.
                    sum += current; // Прибавляем значение текущего символа к общей сумме.
                } // Завершаем проверку правила сложения или вычитания.
            } else { // Если следующего символа нет, мы обрабатываем последний символ строки.
                sum += current; // Прибавляем значение последнего символа к общей сумме.
            } // Завершаем проверку наличия следующего символа.
        } // Завершаем цикл после обработки всех символов строки.

        return sum; // Возвращаем полученное целое число.
    } // Завершаем метод romanToInt.

    private int getValue(char symbol) { // Вспомогательный метод преобразует один римский символ в число.
        switch (symbol) { // Выбираем числовое значение в зависимости от символа.
            case 'I': return 1; // Для символа I возвращаем 1.
            case 'V': return 5; // Для символа V возвращаем 5.
            case 'X': return 10; // Для символа X возвращаем 10.
            case 'L': return 50; // Для символа L возвращаем 50.
            case 'C': return 100; // Для символа C возвращаем 100.
            case 'D': return 500; // Для символа D возвращаем 500.
            case 'M': return 1000; // Для символа M возвращаем 1000.
            default: return 0; // Неизвестный символ даёт 0; по условию такие символы не встречаются.
        } // Завершаем оператор switch.
    } // Завершаем метод getValue.
} // Завершаем класс Solution.
```

### Как работает `getValue()`

Метод `getValue(char symbol)` получает один символ и возвращает его числовое значение.

Например:

- `getValue('I')` возвращает `1`.
- `getValue('V')` возвращает `5`.
- `getValue('M')` возвращает `1000`.

Оператор `switch` выбирает нужный вариант. Благодаря отдельному методу основной алгоритм получается понятнее.

## 5. Разбор кода по частям

### Переменная `sum`

```java
int sum = 0;
```

В `sum` хранится результат, который мы постепенно вычисляем. Для каждого символа сумма либо увеличивается, либо уменьшается.

### Цикл `for`

```java
for (int i = 0; i < s.length(); i++)
```

- `int i = 0` — начинаем с индекса `0`, то есть с первого символа.
- `i < s.length()` — продолжаем, пока индекс меньше длины строки.
- `i++` — после каждой итерации увеличиваем индекс на 1.

В Java индексы начинаются с нуля. Например, у строки `III` длиной 3 индексы символов — `0`, `1` и `2`.

### Получение текущего значения

```java
int current = getValue(s.charAt(i));
```

`s.charAt(i)` получает символ по индексу `i`, а `getValue(...)` переводит этот символ в число.

Если текущий символ — `X`, то `current` будет равен `10`.

### Проверка следующего символа

```java
if (i + 1 < s.length())
```

Эта проверка нужна, чтобы не обратиться к символу за пределами строки.

Например, если длина строки равна 3, допустимы индексы `0`, `1` и `2`. Индекса `3` не существует. Поэтому перед обращением к `s.charAt(i + 1)` проверяем, что следующий индекс допустим.

### Сложение или вычитание

```java
if (current < next) {
    sum -= current;
} else {
    sum += current;
}
```

- Если текущий символ меньше следующего, вычитаем его.
- Если текущий символ больше или равен следующему, прибавляем его.

Равные символы тоже складываются: например, `II = 1 + 1 = 2`.

### Последний символ

```java
else {
    sum += current;
}
```

Когда следующего символа нет, прибавляем значение текущего символа. Это необходимо, чтобы последний символ строки не был пропущен.

## 6. Пример №1: `III` → `3`

Вход:

```text
s = "III"
```

Начальное значение: `sum = 0`.

| Шаг | Текущий символ | Следующий символ | Проверка | Действие | `sum` после шага |
|---:|---|---|---|---|---:|
| 1 | `I` = 1 | `I` = 1 | 1 < 1 — ложь | +1 | 1 |
| 2 | `I` = 1 | `I` = 1 | 1 < 1 — ложь | +1 | 2 |
| 3 | `I` = 1 | Нет | Последний символ | +1 | 3 |

Подробно:

1. Первый `I`: следующий символ тоже равен 1. Условие `1 < 1` ложно, поэтому `sum = 0 + 1 = 1`.
2. Второй `I`: условие `1 < 1` снова ложно, поэтому `sum = 1 + 1 = 2`.
3. Третий `I`: следующего символа нет, поэтому `sum = 2 + 1 = 3`.

**Ответ: `3`.**

## 7. Пример №2: `LVIII` → `58`

Вход:

```text
s = "LVIII"
```

Начальное значение: `sum = 0`.

| Шаг | Текущий символ | Следующий символ | Проверка | Действие | `sum` после шага |
|---:|---|---|---|---|---:|
| 1 | `L` = 50 | `V` = 5 | 50 < 5 — ложь | +50 | 50 |
| 2 | `V` = 5 | `I` = 1 | 5 < 1 — ложь | +5 | 55 |
| 3 | `I` = 1 | `I` = 1 | 1 < 1 — ложь | +1 | 56 |
| 4 | `I` = 1 | `I` = 1 | 1 < 1 — ложь | +1 | 57 |
| 5 | `I` = 1 | Нет | Последний символ | +1 | 58 |

Подробно:

1. `L = 50`. Следующий символ `V = 5`. Поскольку `50 < 5` — ложь, прибавляем 50: `sum = 50`.
2. `V = 5`. Следующий символ `I = 1`. Поскольку `5 < 1` — ложь, прибавляем 5: `sum = 55`.
3. Первый `I = 1`. Следующий символ тоже `I = 1`. Условие ложно, прибавляем 1: `sum = 56`.
4. Второй `I = 1`. Следующий символ также `I = 1`. Прибавляем 1: `sum = 57`.
5. Последний `I = 1`. Следующего символа нет. Прибавляем 1: `sum = 58`.

Проверка вручную:

```text
L + V + I + I + I
50 + 5 + 1 + 1 + 1 = 58
```

**Ответ: `58`.**

## 8. Пример №3: `MCMXCIV` → `1994`

Вход:

```text
s = "MCMXCIV"
```

В этом примере встречаются три случая вычитания: `CM`, `XC` и `IV`.

Начальное значение: `sum = 0`.

| Шаг | Текущий символ | Следующий символ | Проверка | Действие | `sum` после шага |
|---:|---|---|---|---|---:|
| 1 | `M` = 1000 | `C` = 100 | 1000 < 100 — ложь | +1000 | 1000 |
| 2 | `C` = 100 | `M` = 1000 | 100 < 1000 — истина | −100 | 900 |
| 3 | `M` = 1000 | `X` = 10 | 1000 < 10 — ложь | +1000 | 1900 |
| 4 | `X` = 10 | `C` = 100 | 10 < 100 — истина | −10 | 1890 |
| 5 | `C` = 100 | `I` = 1 | 100 < 1 — ложь | +100 | 1990 |
| 6 | `I` = 1 | `V` = 5 | 1 < 5 — истина | −1 | 1989 |
| 7 | `V` = 5 | Нет | Последний символ | +5 | 1994 |

Подробно:

1. **`M` = 1000.** Следующий `C` равен 100. `1000 < 100` — ложь. Прибавляем 1000: `sum = 1000`.
2. **`C` = 100.** Следующий `M` равен 1000. `100 < 1000` — истина. Вычитаем 100: `sum = 1000 - 100 = 900`. Пара `CM` означает 900.
3. **`M` = 1000.** Следующий `X` равен 10. `1000 < 10` — ложь. Прибавляем 1000: `sum = 1900`.
4. **`X` = 10.** Следующий `C` равен 100. `10 < 100` — истина. Вычитаем 10: `sum = 1900 - 10 = 1890`. Пара `XC` означает 90.
5. **`C` = 100.** Следующий `I` равен 1. `100 < 1` — ложь. Прибавляем 100: `sum = 1990`.
6. **`I` = 1.** Следующий `V` равен 5. `1 < 5` — истина. Вычитаем 1: `sum = 1990 - 1 = 1989`. Пара `IV` означает 4.
7. **`V` = 5.** Это последний символ. Прибавляем 5: `sum = 1989 + 5 = 1994`.

Проверка по частям:

```text
M    = 1000
CM   =  900
XC   =   90
IV   =    4
----------------
Итого = 1994
```

Или:

```text
1000 + 900 + 90 + 4 = 1994
```

**Ответ: `1994`.**

## 10. Сложность алгоритма

Пусть `n` — длина строки `s`.

### Временная сложность: `O(n)`

Цикл проходит по каждому символу строки ровно один раз. На каждом шаге выполняется постоянное количество операций. Поэтому время работы линейно зависит от длины строки.

### Дополнительная пространственная сложность: `O(1)`

Используется фиксированное количество переменных: `sum`, `i`, `current` и `next`. Дополнительные коллекции или структуры данных, размер которых зависит от длины строки, не создаются.

Итого:

| Показатель | Сложность |
|---|---|
| Время | `O(n)` |
| Дополнительная память | `O(1)` |

Это оптимальное решение по времени: в общем случае необходимо прочитать каждый символ входной строки хотя бы один раз. Алгоритм делает один проход и использует постоянную дополнительную память.

## 11. Частые ошибки

1. **Всегда складывать значения.** Тогда `IV` ошибочно превратится в `6`, хотя правильный ответ — `4`.
2. **Путать направление вычитания.** Если меньший символ стоит перед большим, вычитаем значение меньшего символа.
3. **Не проверять следующий индекс.** Обращение к `s.charAt(i + 1)` без проверки на последнем символе приведёт к `StringIndexOutOfBoundsException`.
4. **Забывать последний символ.** Если следующего символа нет, значение текущего символа всё равно нужно прибавить.
5. **Пытаться вручную обрабатывать все шесть пар.** Для этой задачи достаточно сравнивать значения текущего и следующего символов.

## 12. Итог

Основное правило:

- Если `current < next`, вычитаем `current`.
- Иначе прибавляем `current`.
- Если символ последний, прибавляем его значение.

Для `MCMXCIV` вычисление выглядит так:

```text
1000 - 100 + 1000 - 10 + 100 - 1 + 5 = 1994
```

Решение имеет временную сложность `O(n)` и дополнительную пространственную сложность `O(1)`. Оно соответствует требованиям LeetCode №13.
