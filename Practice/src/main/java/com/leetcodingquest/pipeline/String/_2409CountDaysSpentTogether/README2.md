## 📋 Условие задачи

**2409. Count Days Spent Together**

Элис и Боб едут в Рим на отдельные деловые встречи. Даны 4 строки:

- `arriveAlice`, `leaveAlice` — период пребывания Элис в городе (включительно);
- `arriveBob`, `leaveBob` — период пребывания Боба в городе (включительно).

Каждая строка имеет формат `"MM-DD"` (месяц и день).

Нужно вернуть **общее количество дней**, которые Элис и Боб проведут в Риме **вместе**.

**Допущения:**
- Все даты — в одном и том же календарном году;
- Год **не високосный**;
- Количество дней в месяцах: `[31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]`.

**Сигнатура метода:**

```java
class Solution {
    public int countDaysTogether(String arriveAlice, String leaveAlice, String arriveBob, String leaveBob) {
    }
}
```

---

## 💡 Идея решения

Задача сводится к **пересечению двух отрезков**:

```
Элис: [arriveAlice, leaveAlice]
Боб:  [arriveBob,   leaveBob  ]
```

Пересечение двух интервалов:

```
[start, end] = [max(arriveAlice, arriveBob), min(leaveAlice, leaveBob)]
```

- Если `start > end` — пересечения нет, ответ `0`.
- Иначе — количество дней включительно: `end - start + 1`.

**Ключевой приём:** перевести каждую дату `"MM-DD"` в **номер дня в году** (1..365). Тогда все сравнения и вычитания выполняются над целыми числами — это просто и быстро.

### Формула перевода

```
dayOfYear = (сумма дней всех месяцев до month) + day
```

Например, для `"08-15"` (невисокосный год):

```
дней до августа = 31 + 28 + 31 + 30 + 31 + 30 + 31 = 212
день в году     = 212 + 15 = 227
```

## ⏱️ Анализ сложности

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| **Время**  | `O(1)` | 4 вызова `toDayOfYear`, каждый — цикл до 12 итераций |
| **Память** | `O(1)` | Массив из 12 чисел + несколько `int` |

Оптимально: константное время, константная память.

## ✅ Решение с комментариями к каждой строке

```java
class Solution {
    public int countDaysTogether(String arriveAlice, String leaveAlice, String arriveBob, String leaveBob) {
        // Массив с количеством дней в каждом месяце (невисокосный год), индекс 0 — январь
        int[] daysInMonth = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

        // Переводим все 4 даты в номер дня в году (1..365)
        int a1 = toDayOfYear(arriveAlice, daysInMonth);   // день приезда Элис
        int a2 = toDayOfYear(leaveAlice,  daysInMonth);   // день отъезда Элис
        int b1 = toDayOfYear(arriveBob,   daysInMonth);   // день приезда Боба
        int b2 = toDayOfYear(leaveBob,    daysInMonth);   // день отъезда Боба

        // Левая граница пересечения — более поздний из приездов
        int start = Math.max(a1, b1);

        // Правая граница пересечения — более ранний из отъездов
        int end = Math.min(a2, b2);

        // Если начало позже конца — общих дней нет
        if (start > end) {
            return 0;
        }

        // Количество дней включительно: end - start + 1
        return end - start + 1;
    }

    // Вспомогательный метод: переводит "MM-DD" в номер дня в году (1..365)
    private int toDayOfYear(String date, int[] daysInMonth) {
        // Извлекаем месяц (первые два символа) и день (последние два)
        int month = Integer.parseInt(date.substring(0, 2)); // "08" -> 8
        int day   = Integer.parseInt(date.substring(3, 5)); // "15" -> 15

        // Начинаем счёт: накапливаем дни всех предыдущих месяцев
        int total = 0;
        for (int i = 0; i < month - 1; i++) {
            total += daysInMonth[i]; // добавляем длину i-го месяца
        }

        // Прибавляем текущий день месяца
        total += day;
        return total;
    }
}
```

## 🧪 Пошаговый разбор примеров

### Пример 1 — пересечение внутри одного месяца

```
arriveAlice = "08-15", leaveAlice = "08-18"
arriveBob   = "08-16", leaveBob   = "08-19"
```

**Перевод в номер дня в году**

Сумма дней до августа: `31 + 28 + 31 + 30 + 31 + 30 + 31 = 212`.

| Дата | Расчёт | День в году |
|------|--------|-------------|
| `arriveAlice = 08-15` | 212 + 15 | **227** |
| `leaveAlice  = 08-18` | 212 + 18 | **230** |
| `arriveBob   = 08-16` | 212 + 16 | **228** |
| `leaveBob    = 08-19` | 212 + 19 | **231** |

**Пересечение**

- `start = max(227, 228) = 228`
- `end   = min(230, 231) = 230`
- `start ≤ end` → `230 - 228 + 1 = 3`

**Ответ: `3`** ✅ (16, 17, 18 августа)

---

### Пример 2 — интервалы не пересекаются

```
arriveAlice = "10-01", leaveAlice = "10-31"
arriveBob   = "11-01", leaveBob   = "12-31"
```

**Перевод в номер дня в году**

- Сумма дней до октября: `31+28+31+30+31+30+31+31+30 = 273`
- Сумма дней до ноября: `273 + 31 = 304`
- Сумма дней до декабря: `304 + 30 = 334`

| Дата | Расчёт | День в году |
|------|--------|-------------|
| `arriveAlice = 10-01` | 273 + 1 | **274** |
| `leaveAlice  = 10-31` | 273 + 31 | **304** |
| `arriveBob   = 11-01` | 304 + 1 | **305** |
| `leaveBob    = 12-31` | 334 + 31 | **365** |

**Пересечение**

- `start = max(274, 305) = 305`
- `end   = min(304, 365) = 304`
- `start > end` (305 > 304) → **ответ `0`** ✅

---

### Пример 3 — один интервал полностью внутри другого

```
arriveAlice = "01-01", leaveAlice = "12-31"
arriveBob   = "03-10", leaveBob   = "03-20"
```

**Перевод в номер дня в году**

Сумма дней до марта: `31 + 28 = 59`.

| Дата | Расчёт | День в году |
|------|--------|-------------|
| `arriveAlice = 01-01` | 0 + 1 | **1** |
| `leaveAlice  = 12-31` | 334 + 31 | **365** |
| `arriveBob   = 03-10` | 59 + 10 | **69** |
| `leaveBob    = 03-20` | 59 + 20 | **79** |

**Пересечение**

- `start = max(1, 69) = 69`
- `end   = min(365, 79) = 79`
- `start ≤ end` → `79 - 69 + 1 = 11`

**Ответ: `11`** ✅ (с 10 по 20 марта включительно)

## 🧠 Почему это оптимально

1. **`O(1)` по времени** — фиксированное число операций: 4 перевода дат, 2 сравнения, 1 арифметика. Цикл внутри `toDayOfYear` идёт не более 12 итераций.
2. **`O(1)` по памяти** — массив `daysInMonth` фиксированной длины 12 и несколько `int`-переменных.
3. **Не создаём объекты `LocalDate`** — на интервью часто ценят «ручное» решение: оно демонстрирует понимание работы с датами и арифметикой интервалов.
4. **Единая нормализация** — перевод всех дат в «день года» убирает разветвлённую логику сравнения `"MM-DD"` и делает код читаемым.

### Альтернатива

Можно было бы использовать `java.time.LocalDate.of(2001, MM, DD)` и `ChronoUnit.DAYS.between(...)`, но это:
- тяжелее по константе (создание объектов, парсинг),
- требует учитывать високосность (нужно брать невисокосный год, например `2001`),
- менее показательно на интервью.
