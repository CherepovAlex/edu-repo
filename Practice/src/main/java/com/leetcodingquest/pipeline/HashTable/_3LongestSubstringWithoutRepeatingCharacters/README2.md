Для решения задачи «Самая длинная подстрока без повторяющихся символов» (Longest Substring Without Repeating Characters) оптимальным подходом является использование алгоритма **скользящего окна (Sliding Window)** с хэш-таблицей.

### Почему именно этот подход?

1.  **Ограничения:** Длина строки может достигать $10^5$. Это означает, что решение со сложностью $O(N^2)$ (где мы перебираем все подстроки) не пройдет по времени (TLE — Time Limit Exceeded). Нам нужен алгоритм линейной сложности $O(N)$.
2.  **Скользящее окно:** Мы будем поддерживать «окно» внутри строки, которое содержит только уникальные символы. Будем расширять это окно вправо, пока не встретим повтор, и сдвигать левую границу, чтобы устранить конфликт.
3.  **Хэш-таблица (Map):** Позволяет проверять наличие символа в текущем окне за $O(1)$ и запоминать последнюю позицию каждого символа, чтобы быстро перемещать левую границу окна.

### Код решения на Java

```java
import java.util.HashMap;

public class LongestSubstringNoRepeats {
    public int lengthOfLongestSubstring(String s) {
        // Если строка пустая, длина равна 0
        if (s == null || s.isEmpty()) {
            return 0;
        }

        // Карта для хранения последнего индекса встреченного символа.
        // Ключ: символ, Значение: индекс этого символа в строке.
        HashMap<Character, Integer> charIndexMap = new HashMap<>();

        // Переменная для хранения максимальной длины найденной подстроки
        int maxLength = 0;

        // Левая граница скользящего окна. 
        // Подстрока без повторов всегда находится в диапазоне [left, right]
        int left = 0;

        // Правая граница скользящего окна. 
        // Мы проходим по всей строке этим указателем
        for (int right = 0; right < s.length(); right++) {
            // Текущий символ, который мы рассматриваем
            char currentChar = s.charAt(right);

            // Если символ уже встречался И его предыдущая позиция находится 
            // внутри текущего окна (т.е. >= left), значит мы нашли повтор.
            // Нам нужно сдвинуть левую границу окна сразу после этого повторяющегося символа.
            if (charIndexMap.containsKey(currentChar) && charIndexMap.get(currentChar) >= left) {
                // Сдвигаем левую границу на 1 позицию вправо от предыдущего вхождения
                left = charIndexMap.get(currentChar) + 1;
            }

            // Обновляем последнюю известную позицию текущего символа
            charIndexMap.put(currentChar, right);

            // Вычисляем текущую длину окна: (правая граница - левая граница + 1)
            int currentLength = right - left + 1;

            // Обновляем максимальную длину, если текущее окно длиннее
            if (currentLength > maxLength) {
                maxLength = currentLength;
            }
        }

        // Возвращаем результат
        return maxLength;
    }
}
```

### Подробное объяснение каждой строки кода

1.  `if (s == null || s.isEmpty()) { return 0; }`
    *   **Действие:** Проверка на пустой ввод. Если строки нет или она пуста, подстроки тоже не существует, длина 0. Это базовый случай (edge case).

2.  `HashMap<Character, Integer> charIndexMap = new HashMap<>();`
    *   **Действие:** Создаем ассоциативный массив. Он нужен, чтобы быстро находить: «Где в последний раз встречался этот символ?». Это позволяет нам мгновенно прыгать левую границу окна, а не итерировать назад по строке.

3.  `int maxLength = 0;`
    *   **Действие:** Инициализируем переменную-результат. Пока мы ничего не нашли, максимум равен 0.

4.  `int left = 0;`
    *   **Действие:** Инициализация левого указателя окна. Изначально окно начинается с начала строки (индекс 0).

5.  `for (int right = 0; right < s.length(); right++)`
    *   **Действие:** Цикл по всей строке. `right` — это правый указатель окна. Мы постепенно расширяем окно вправо, добавляя новые символы.

6.  `char currentChar = s.charAt(right);`
    *   **Действие:** Получаем символ по текущему индексу `right`, чтобы работать с ним.

7.  `if (charIndexMap.containsKey(currentChar) && charIndexMap.get(currentChar) >= left)`
    *   **Действие:** Это ключевая логика проверки дубликатов.
        *   `containsKey(currentChar)`: Был ли этот символ вообще в строке ранее?
        *   `get(currentChar) >= left`: Находится ли его предыдущая позиция *внутри* текущего активного окна?
        *   *Пример:* Если у нас окно "abc", и мы встречаем 'a' снова, но позиция старого 'a' была за пределами окна (например, до индекса `left`), то дубликата в *текущем* окне нет. Поэтому проверка `>= left` критически важна.

8.  `left = charIndexMap.get(currentChar) + 1;`
    *   **Действие:** Сдвиг левого края окна. Чтобы устранить повтор, новое окно должно начинаться сразу *после* предыдущего вхождения этого символа.

9.  `charIndexMap.put(currentChar, right);`
    *   **Действие:** Обновляем позицию символа. Теперь мы помним, что символ `currentChar` находится на индексе `right`. Это нужно для будущих итераций.

10. `int currentLength = right - left + 1;`
    *   **Действие:** Математика длины. Если окно от индекса 2 до 5 включительно, то длина равна $5 - 2 + 1 = 4$.

11. `if (currentLength > maxLength) { maxLength = currentLength; }`
    *   **Действие:** Глобальная оптимизация. Если текущее окно стало длиннее всего, что мы видели раньше, запоминаем это новое значение.

12. `return maxLength;`
    *   **Действие:** Возвращаем итоговый ответ после прохода по всей строке.

### Пошаговый разбор на примерах

#### Пример 1: `s = "abcabcbb"`

Инициализация: `maxLength = 0`, `left = 0`, `map = {}`

1.  **right=0, char='a'**:
    *   'a' нет в map.
    *   Map: `{a:0}`.
    *   Длина: $0 - 0 + 1 = 1$.
    *   `maxLength` = 1.
2.  **right=1, char='b'**:
    *   'b' нет в map.
    *   Map: `{a:0, b:1}`.
    *   Длина: $1 - 0 + 1 = 2$.
    *   `maxLength` = 2.
3.  **right=2, char='c'**:
    *   'c' нет в map.
    *   Map: `{a:0, b:1, c:2}`.
    *   Длина: $2 - 0 + 1 = 3$.
    *   `maxLength` = 3.
4.  **right=3, char='a'**:
    *   'a' есть в map. Индекс 0.
    *   Проверяем: $0 >= left$ (0 >= 0)? **Да**.
    *   Сдвигаем `left`: $left = 0 + 1 = 1$.
    *   Map: `{a:3, b:1, c:2}` (обновляем индекс 'a').
    *   Длина: $3 - 1 + 1 = 3$.
    *   `maxLength` остается 3 (так как $3 \ngtr 3$).
5.  **right=4, char='b'**:
    *   'b' есть в map. Индекс 1.
    *   Проверяем: $1 >= left$ (1 >= 1)? **Да**.
    *   Сдвигаем `left`: $left = 1 + 1 = 2$.
    *   Map: `{a:3, b:4, c:2}`.
    *   Длина: $4 - 2 + 1 = 3$.
    *   `maxLength` остается 3.
6.  **right=5, char='c'**:
    *   'c' есть в map. Индекс 2.
    *   Проверяем: $2 >= left$ (2 >= 2)? **Да**.
    *   Сдвигаем `left`: $left = 2 + 1 = 3$.
    *   Map: `{a:3, b:4, c:5}`.
    *   Длина: $5 - 3 + 1 = 3$.
    *   `maxLength` остается 3.
7.  **right=6, char='b'**:
    *   'b' есть в map. Индекс 4.
    *   Проверяем: $4 >= left$ (4 >= 3)? **Да**.
    *   Сдвигаем `left`: $left = 4 + 1 = 5$.
    *   Map: `{a:3, b:6, c:5}`.
    *   Длина: $6 - 5 + 1 = 2$.
    *   `maxLength` остается 3.
8.  **right=7, char='b'**:
    *   'b' есть в map. Индекс 6.
    *   Проверяем: $6 >= left$ (6 >= 5)? **Да**.
    *   Сдвигаем `left`: $left = 6 + 1 = 7$.
    *   Map: `{a:3, b:7, c:5}`.
    *   Длина: $7 - 7 + 1 = 1$.
    *   `maxLength` остается 3.

**Результат:** 3.

#### Пример 3: `s = "pwwkew"`

Инициализация: `maxLength = 0`, `left = 0`, `map = {}`

1.  **right=0, char='p'**:
    *   Нет дублей.
    *   Map: `{p:0}`.
    *   Длина: 1. `maxLength` = 1.
2.  **right=1, char='w'**:
    *   Нет дублей.
    *   Map: `{p:0, w:1}`.
    *   Длина: 2. `maxLength` = 2.

    *   'w' есть (индекс 1). $1 >= left$ (1 >= 0)? **Да**.
    *   `left` = $1 + 1 = 2$.
    *   Map: `{p:0, w:2}`.
    *   Длина: $2 - 2 + 1 = 1$. (Текущее окно стало просто "w").
    *   `maxLength` остается 2.
4.  **right=3, char='k'**:
    *   Нет дублей в текущем окне.
    *   Map: `{p:0, w:2, k:3}`.
    *   Длина: $3 - 2 + 1 = 2$. ("wk").
    *   `maxLength` остается 2.
5.  **right=4, char='e'**:
    *   Нет дублей.
    *   Map: `{p:0, w:2, k:3, e:4}`.
    *   Длина: $4 - 2 + 1 = 3$. ("wke").
    *   `maxLength` обновляется до **3**.
6.  **right=5, char='w'**:
    *   'w' есть (индекс 2).
    *   Проверяем: $2 >= left$ (2 >= 2)? **Да**.
    *   `left` = $2 + 1 = 3$.
    *   Map: `{p:0, w:5, k:3, e:4}`.
    *   Длина: $5 - 3 + 1 = 3$. ("kew").
    *   `maxLength` остается 3.

**Результат:** 3.

### Сложность решения

*   **Временная сложность:** $O(N)$, где $N$ — длина строки `s`. Мы проходим по строке один раз. Операции с `HashMap` (put, get, containsKey) занимают $O(1)$ в среднем.
*   **Пространственная сложность:** $O(M)$, где $M$ — размер алфавита. В худшем случае (все символы разные) в `HashMap` будет храниться $N$ элементов. Однако, учитывая, что алфавит ограничен (английские буквы, цифры и т.д.), пространство можно считать константным $O(1)$ или $O(\min(N, M))$.
