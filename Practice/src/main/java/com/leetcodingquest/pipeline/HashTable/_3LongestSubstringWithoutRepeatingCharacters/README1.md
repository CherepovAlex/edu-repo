LeetCode 3. Самая длинная подстрока без повторяющихся символов — решение на Java
Разберём задачу так, как на полноценном занятии по Java-разработке: от понимания условия до оптимального алгоритма, кода с комментарием к каждой строке и пошагового выполнения всех трёх примеров.
Главная идея решения — алгоритм скользящего окна (Sliding Window). С его помощью мы решим задачу за линейное время \(O(n)\), не перебирая все возможные подстроки.
1. Понимаем условие задачи
Нам дана строка s. Необходимо найти длину самой длинной непрерывной части строки, в которой все символы различны.
Например, для строки:
s = "abcabcbb"


Подходящие подстроки:
- "a" — длина 1.
- "ab" — длина 2.
- "abc" — длина 3.
- "bca" — длина 3.
- "cab" — длина 3.
Подстрока "abca" уже не подходит, потому что символ a встречается дважды.
Ответ — 3.
Важное различие: подстрока и подпоследовательность

Подстрока (substring)
Символы идут подряд, без пропусков.
Пример для "pwwkew": "wke" — корректная подстрока длины 3.




Подпоследовательность (subsequence)
Можно пропускать символы, сохраняя их исходный порядок.
Пример: "pwke" встречается в "pwwkew" как подпоследовательность, но не как подстрока.



Наша задача — найти именно подстроку. При этом возвращать саму подстроку не требуется: нужно вернуть только её длину.
Ограничения
- Длина строки: от 0 до 100 000 символов.
- Допускаются английские буквы, цифры, символы и пробелы.
- Строка может быть пустой.
Это важно для выбора алгоритма: при длине строки до \(10^5\) решение с квадратичной сложностью \(O(n^2)\) может оказаться слишком медленным.
2. Почему простой перебор не подходит?
Можно попробовать:
1. Взять первый символ.
2. Перебирать все подстроки, начинающиеся с него.
3. Проверять, есть ли в каждой повторяющиеся символы.
4. Повторить процесс для каждой следующей позиции.
Но количество рассматриваемых подстрок растёт квадратично. Если ещё и проверять каждую подстроку отдельно, алгоритм может работать ещё медленнее.
Вместо этого будем поддерживать текущее окно — непрерывный участок строки без повторяющихся символов.
3. Оптимальный алгоритм: скользящее окно
Представим два указателя:
- left — начало текущей подстроки.
- right — конец текущей подстроки.
Между ними находится наше окно:
\[
s[left \ldots right]
\]

Мы двигаем right слева направо, добавляя символы в окно. Если встречается повтор, сдвигаем left так, чтобы окно снова содержало только уникальные символы.
Для каждого шага вычисляем длину окна:
\[
length = right - left + 1
\]

И обновляем максимальный ответ:
\[
maxLength = \max(maxLength, length)
\]

Как быстро обнаружить повтор?
Можно хранить последние позиции символов в массиве lastSeen.
Например, пусть строка выглядит так:
Индексы:  0  1  2  3
Строка:   a  b  c  a
          └───────┘


Когда мы доходим до последней a, обнаруживаем, что она уже встречалась на позиции 0.
Поэтому начало окна нужно переместить на позицию 1:
Индексы:  0  1  2  3
Строка:   a  b  c  a
             └────┘
             b  c  a


Теперь окно "bca" снова состоит из уникальных символов, и его длина равна 3.
Обрати внимание: мы не начинаем поиск заново. Мы только перемещаем левую границу окна вперёд.
Почему нужен Math.max?
Предположим, мы нашли повторяющийся символ, который ранее встречался до текущего окна.
В этом случае нельзя двигать left назад. Поэтому используем:
left = Math.max(left, lastSeen[ch]);


Здесь lastSeen[ch] хранит позицию предыдущего символа плюс один. Это позволяет сразу переместить левую границу за повтор.
Например, если left = 5, а предыдущая позиция символа соответствует границе 3, то новое значение left останется равным 5.
Так мы гарантируем, что окно никогда не расширяется назад.
4. Полный код на Java с комментарием к каждой строке
Для данной задачи используем массив из 128 элементов. Он подходит, поскольку по условию используются английские буквы, цифры, стандартные символы и пробелы (ASCII).

class Solution { // Объявляем класс, который ожидает LeetCode

    public int lengthOfLongestSubstring(String s) { // Метод возвращает длину самой длинной подстроки без повторов

        int[] lastSeen = new int[128]; // Для каждого ASCII-символа храним индекс последнего появления плюс один

        int left = 0; // Левая граница текущего окна

        int maxLength = 0; // Максимальная длина подстроки, найденная на данный момент

        for (int right = 0; right < s.length(); right++) { // Перебираем строку слева направо

            char ch = s.charAt(right); // Получаем символ на текущей позиции right

            left = Math.max(left, lastSeen[ch]); // Если символ повторился в окне, сдвигаем left за его прошлое появление

            lastSeen[ch] = right + 1; // Запоминаем новую позицию символа в формате индекс плюс один

            int currentLength = right - left + 1; // Вычисляем длину текущего окна

            maxLength = Math.max(maxLength, currentLength); // Обновляем максимальную длину, если текущее окно длиннее
        }

        return maxLength; // Возвращаем длину самой длинной подстроки без повторяющихся символов
    }
}



Разбор каждой важной части
1. int[] lastSeen = new int[128];
Создаём массив, в котором каждому ASCII-символу соответствует отдельная ячейка.
Например, lastSeen['a'] хранит позицию последнего появления символа a, увеличенную на единицу.
Почему на единицу? Потому что Java автоматически заполняет новый массив нулями. Поэтому:
- 0 означает, что символ ещё не встречался.
- 1 означает, что он встречался на индексе 0.
- 4 означает, что он встречался на индексе 3.
Так нам не нужно отдельно заполнять массив значением -1.
2. int left = 0;
Левая граница окна изначально указывает на первый символ строки.
3. int maxLength = 0;
Храним лучший результат. Ноль — корректный ответ для пустой строки.
4. for (int right = 0; right < s.length(); right++)
Перебираем все символы строки. Переменная right последовательно принимает значения от 0 до s.length() - 1.
5. char ch = s.charAt(right);
Получаем текущий символ. Например, для s = "abc" при right = 1 переменная ch содержит 'b'.
6. left = Math.max(left, lastSeen[ch]);
Если символ уже встречался внутри текущего окна, перемещаем левую границу на позицию сразу после предыдущего вхождения.
Math.max не позволяет left уменьшиться.
7. lastSeen[ch] = right + 1;
Запоминаем новое последнее появление символа. Это нужно для обнаружения повторов в следующих итерациях.
8. int currentLength = right - left + 1;
Вычисляем количество символов в окне. Единица добавляется потому, что учитываются обе границы.
Например, если left = 2, а right = 4, то длина равна:
\[
4 - 2 + 1 = 3
\]

9. maxLength = Math.max(maxLength, currentLength);
Сравниваем длину текущего окна с лучшим результатом и сохраняем большее значение.
10. return maxLength;
После обработки всей строки возвращаем максимальную длину.
5. Пошаговое решение примера № 1
Входные данные:
s = "abcabcbb"


Индексы символов:
Индекс:  0 1 2 3 4 5 6 7
Символ:  a b c a b c b b


Начальное состояние:
left = 0
maxLength = 0


Будем последовательно обрабатывать символы.
Шаг 1 · right = 0
Символ a
Символ ещё не встречался. Оставляем left = 0.
[a] b  c  a  b  c  b  b
Окно: "a"

\[
currentLength = 0 - 0 + 1 = 1
\]

maxLength = max(0, 1) = 1

Шаг 2 · right = 1
Символ b
Символ b ещё не встречался. Окно расширяется.
[a  b] c  a  b  c  b  b
Окно: "ab"

\[
currentLength = 1 - 0 + 1 = 2
\]

maxLength = max(1, 2) = 2

Шаг 3 · right = 2
Символ c
Повторов нет, добавляем c.
[a  b  c] a  b  c  b  b
Окно: "abc"

\[
currentLength = 2 - 0 + 1 = 3
\]

maxLength = max(2, 3) = 3

Шаг 4 · right = 3
Символ a
Символ a уже встречался на индексе 0. Значение lastSeen['a'] равно 1.
\[
left = \max(0, 1) = 1
\]

a  [b  c  a] b  c  b  b
Окно: "bca"

\[
currentLength = 3 - 1 + 1 = 3
\]

maxLength остаётся равным 3.

Шаг 5 · right = 4
Символ b
Предыдущий b находился на индексе 1, поэтому lastSeen['b'] = 2.
\[
left = \max(1, 2) = 2
\]

a  b  [c  a  b] c  b  b
Окно: "cab"

\[
currentLength = 4 - 2 + 1 = 3
\]

maxLength остаётся 3.

Шаг 6 · right = 5
Символ c
Предыдущий c был на индексе 2. Следовательно, lastSeen['c'] = 3.
\[
left = \max(2, 3) = 3
\]

a  b  c  [a  b  c] b  b
Окно: "abc"

\[
currentLength = 5 - 3 + 1 = 3
\]

maxLength остаётся 3.

Шаг 7 · right = 6
Символ b
Последний b находился на индексе 4. Поэтому:
\[
left = \max(3, 5) = 5
\]

a  b  c  a  b  [c  b] b
Окно: "cb"

\[
currentLength = 6 - 5 + 1 = 2
\]

maxLength остаётся 3.

Шаг 8 · right = 7
Символ b
Предыдущий b находился на индексе 6. Значение lastSeen['b'] = 7.
\[
left = \max(5, 7) = 7
\]

a  b  c  a  b  c  b  [b]
Окно: "b"

\[
currentLength = 7 - 7 + 1 = 1
\]

maxLength остаётся 3.

После обработки всех восьми символов метод возвращает:
3


Самые длинные подходящие подстроки здесь — "abc", "bca" и "cab". Все они имеют длину 3.
6. Пошаговое решение примера № 2
Входные данные:
s = "bbbbb"


Все символы одинаковые. Поэтому окно никогда не сможет содержать больше одного символа.
Индексы:
Индекс:  0 1 2 3 4
Символ:  b b b b b


Начальное состояние:
left = 0
maxLength = 0


Разберём каждую итерацию.
Итерация 1 · right = 0
Символ b ещё не встречался. left = 0.
[b] b  b  b  b

\[
currentLength = 0 - 0 + 1 = 1
\]

maxLength = 1

Итерация 2 · right = 1
b уже встречался на индексе 0. В lastSeen['b'] хранится 1.
\[
left = \max(0, 1) = 1
\]

b  [b] b  b  b

\[
currentLength = 1 - 1 + 1 = 1
\]

maxLength = 1

Итерация 3 · right = 2
Последний b был на индексе 1. Значит, left = max(1, 2) = 2.
b  b  [b] b  b

\[
currentLength = 2 - 2 + 1 = 1
\]

maxLength = 1

Итерация 4 · right = 3
Последний b был на индексе 2. Поэтому left = max(2, 3) = 3.
b  b  b  [b] b

\[
currentLength = 3 - 3 + 1 = 1
\]

maxLength = 1

Итерация 5 · right = 4
Последний b был на индексе 3. Поэтому left = max(3, 4) = 4.
b  b  b  b  [b]

\[
currentLength = 4 - 4 + 1 = 1
\]

maxLength = 1

Итог:
Выходные данные: 1


Почему ответ равен 1? Потому что любые две соседние буквы одинаковы. Самая длинная подстрока без повторов может содержать только один символ — "b".
7. Пошаговое решение примера № 3
Входные данные:
s = "pwwkew"


Индексы символов:
Индекс:  0 1 2 3 4 5
Символ:  p w w k e w


Начальное состояние:
left = 0
maxLength = 0


Итерация 1 · right = 0
Символ p
Повторов нет. Окно содержит "p".
[p] w  w  k  e  w

\[
currentLength = 0 - 0 + 1 = 1
\]

maxLength = 1

Итерация 2 · right = 1
Символ w
Символ w встречается впервые. Расширяем окно до "pw".
[p  w] w  k  e  w

\[
currentLength = 1 - 0 + 1 = 2
\]

maxLength = 2

Итерация 3 · right = 2
Символ w
Символ w уже встречался на индексе 1. В lastSeen['w'] хранится 2.
\[
left = \max(0, 2) = 2
\]

p  w  [w] k  e  w

Теперь окно содержит только "w".
\[
currentLength = 2 - 2 + 1 = 1
\]

maxLength остаётся равным 2.

Итерация 4 · right = 3
Символ k
Символ k ранее не встречался. Добавляем его в окно.
p  w  [w  k] e  w

\[
currentLength = 3 - 2 + 1 = 2
\]

Текущее окно — "wk". maxLength = 2.

Итерация 5 · right = 4
Символ e
Символ e ранее не встречался. Окно становится "wke".
p  w  [w  k  e] w

\[
currentLength = 4 - 2 + 1 = 3
\]

maxLength = max(2, 3) = 3.

Итерация 6 · right = 5
Символ w
Последний w находился на индексе 2, поэтому lastSeen['w'] = 3.
\[
left = \max(2, 3) = 3
\]

Левая граница перемещается на индекс 3. Теперь в окне находятся символы k, e, w.
p  w  w  [k  e  w]

\[
currentLength = 5 - 3 + 1 = 3
\]

maxLength = max(3, 3) = 3.

Итог:
Выходные данные: 3


Подходящие ответы — "wke" и "kew", оба длиной 3.
Почему нельзя ответить 4, выбрав "pwke"?
В строке "pwwkew" можно найти символы p, w, k, e в указанном порядке, но для получения "pwke" нужно пропустить второй w между первым w и k.
Поэтому "pwke" — подпоследовательность, а не подстрока. Подстрока должна состоять из символов, расположенных строго подряд.

9. Сложность алгоритма
Обозначим длину строки через \(n\).
Временная сложность: \(O(n)\).
- Цикл for обрабатывает каждый символ ровно один раз.
- Обращение к lastSeen[ch] выполняется за \(O(1)\).
- Math.max тоже выполняется за \(O(1)\).
- Хотя указатель left перемещается внутри строки, он никогда не движется назад и не требует отдельного вложенного цикла.
Итого:
\[
T(n) = O(n)
\]

Пространственная сложность: \(O(1)\).
Массив lastSeen всегда содержит ровно 128 элементов, независимо от длины строки. Других структур данных, размер которых зависит от \(n\), алгоритм не создаёт.
\[
S(n) = O(128) = O(1)
\]

Таким образом, для заданного набора ASCII-символов решение оптимально по времени: необходимо прочитать символы строки, а значит, быстрее \(O(n)\) в общем случае не получится.
10. Что важно запомнить перед собеседованием
Скользящее окно
Используем два указателя left и right, чтобы рассматривать только текущую непрерывную подстроку.


Последние позиции символов
Массив lastSeen позволяет обнаруживать повторы за \(O(1)\) и сразу перемещать левую границу.


Защита от движения назад
left = Math.max(left, lastSeen[ch]) гарантирует, что окно не вернётся к уже обработанным позициям.


Формула длины
right - left + 1 учитывает оба конца окна.


Сложность
Время — \(O(n)\), дополнительная память — \(O(1)\) для ASCII.



Главное, что нужно понять: мы не перебираем все подстроки — мы поддерживаем одно окно без повторов и расширяем его настолько, насколько это возможно. Именно это делает алгоритм быстрым и эффективным.
