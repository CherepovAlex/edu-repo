# LeetCode 2409 — Подсчёт дней, проведённых вместе

## Условие задачи

Элис и Боб едут в Рим на отдельные деловые встречи.

Даны четыре строки:

- `arriveAlice` — дата приезда Элис.
- `leaveAlice` — дата отъезда Элис.
- `arriveBob` — дата приезда Боба.
- `leaveBob` — дата отъезда Боба.

Каждая строка содержит дату в формате `MM-DD`, где:

- `MM` — номер месяца;
- `DD` — номер дня месяца.

Элис находится в Риме с `arriveAlice` по `leaveAlice` включительно. Боб находится в Риме с `arriveBob` по `leaveBob` включительно.

Необходимо вернуть общее количество календарных дней, в течение которых оба находятся в Риме одновременно.

Можно считать, что все даты относятся к одному невисокосному календарному году.

Количество дней в месяцах:

```text
Январь      — 31
Февраль     — 28
Март        — 31
Апрель      — 30
Май         — 31
Июнь        — 30
Июль        — 31
Август      — 31
Сентябрь    — 30
Октябрь     — 31
Ноябрь      — 30
Декабрь     — 31
```

### Ограничения

- Все даты представлены в формате `MM-DD`.
- Даты действительны для невисокосного года.
- Дата приезда каждого путешественника раньше или совпадает с датой его отъезда.
- Даты приезда и отъезда включаются в период пребывания.

---

## Пример 1

**Входные данные:**

```text
arriveAlice = "08-15"
leaveAlice  = "08-18"
arriveBob   = "08-16"
leaveBob    = "08-19"
```

**Выходные данные:**

```text
3
```

**Объяснение:**

Элис находится в Риме с 15 по 18 августа.

Боб находится в Риме с 16 по 19 августа.

Оба путешественника находятся в Риме 16, 17 и 18 августа.

Ответ — `3`.

## Пример 2

**Входные данные:**

```text
arriveAlice = "10-01"
leaveAlice  = "10-31"
arriveBob   = "11-01"
leaveBob    = "12-31"
```

**Выходные данные:**

```text
0
```

**Объяснение:**

Элис уезжает 31 октября, а Боб приезжает только 1 ноября.

Нет ни одного дня, когда оба одновременно находятся в Риме.

Ответ — `0`.

---

# 1. Идея решения

Для решения задачи не нужно проверять каждый день календаря.

Достаточно определить границы периода, в течение которого оба путешественника находятся в Риме одновременно.

Представим два периода пребывания:

```text
Элис:  |----------------------|
Боб:             |----------------------|
```

Совместное пребывание начинается тогда, когда приехал последний из двух путешественников.

Совместное пребывание заканчивается тогда, когда уехал первый из них.

Поэтому нам необходимо найти:

1. Начало общего периода.
2. Конец общего периода.
3. Количество дней между этими датами включительно.

## Шаг 1. Найти начало общего периода

Начало совместного пребывания определяется более поздней датой приезда.

Используем `Math.max()`:

```java
int start = Math.max(aliceStart, bobStart);
```

Например:

```text
Элис приехала: 15 августа
Боб приехал:   16 августа
```

До 16 августа Боб ещё не находился в Риме.

Следовательно, общий период может начаться только 16 августа.

## Шаг 2. Найти конец общего периода

Конец совместного пребывания определяется более ранней датой отъезда.

Используем `Math.min()`:

```java
int end = Math.min(aliceEnd, bobEnd);
```

Например:

```text
Элис уезжает: 18 августа
Боб уезжает:  19 августа
```

После 18 августа Элис уже не будет в Риме.

Следовательно, последним общим днём будет 18 августа.

## Шаг 3. Проверить пересечение периодов

После определения начала и конца необходимо проверить, существует ли общий период.

Если начало находится позже конца, периоды не пересекаются.

```java
if (start > end) {
    return 0;
}
```

Например:

```text
start = 305
end   = 304
```

Поскольку `305 > 304`, общего периода нет.

Возвращаем `0`.

## Шаг 4. Посчитать количество совместных дней

Если начало не позже конца, количество совместных дней вычисляется по формуле:

```java
return end - start + 1;
```

Почему прибавляем единицу?

Потому что обе даты включаются в период пребывания.

Например, совместное пребывание с 16 по 18 августа:

```text
18 - 16 + 1 = 3
```

Это три дня:

```text
16 августа
17 августа
18 августа
```

Однако даты пока представлены строками, поэтому сначала нужно преобразовать их в числа.

# 2. Преобразование даты в номер дня года

Чтобы сравнивать даты и вычислять разницу между ними, преобразуем каждую дату в порядковый номер дня в году.

Например:

| Дата | Номер дня года |
|---|---:|
| `01-01` | 1 |
| `01-31` | 31 |
| `02-01` | 32 |
| `02-28` | 59 |
| `03-01` | 60 |
| `08-15` | 227 |
| `08-16` | 228 |
| `08-18` | 230 |
| `12-31` | 365 |

## Как вычислить номер дня?

Нужно сложить количество дней во всех предыдущих месяцах и прибавить номер дня текущего месяца.

Формула:

```text
Номер дня года =
    количество дней во всех предыдущих месяцах
    + номер дня текущего месяца
```

Рассмотрим дату `08-16`.

Перед августом находятся семь месяцев:

```text
Январь      — 31
Февраль     — 28
Март        — 31
Апрель      — 30
Май         — 31
Июнь        — 30
Июль        — 31
```

Складываем:

```text
31 + 28 + 31 + 30 + 31 + 30 + 31 = 212
```

Прибавляем 16 августа:

```text
212 + 16 = 228
```

Таким образом:

```text
08-16 → 228
```

Теперь даты можно сравнивать как обычные целые числа.

Например:

```text
08-15 → 227
08-16 → 228
08-18 → 230
08-19 → 231
```

Разница между номерами дней равна разнице между соответствующими датами в пределах одного календарного года.

## Массив количества дней в месяцах

В Java удобно хранить количество дней в массиве:

```java
private static final int[] DAYS_IN_MONTH = {
    31, 28, 31, 30, 31, 30,
    31, 31, 30, 31, 30, 31
};
```

Индексы массива начинаются с нуля:

| Индекс | Месяц | Дней |
|---:|---|---:|
| 0 | Январь | 31 |
| 1 | Февраль | 28 |
| 2 | Март | 31 |
| 3 | Апрель | 30 |
| 4 | Май | 31 |
| 5 | Июнь | 30 |
| 6 | Июль | 31 |
| 7 | Август | 31 |
| 8 | Сентябрь | 30 |
| 9 | Октябрь | 31 |
| 10 | Ноябрь | 30 |
| 11 | Декабрь | 31 |

Если дата относится к августу, необходимо сложить значения с индексами от `0` до `6`.

Иными словами, суммируем элементы, пока `i < month - 1`.

# 3. Полное решение на Java

```java
class Solution {

    // Храним количество дней в каждом месяце невисокосного года.
    private static final int[] DAYS_IN_MONTH = {
        31, 28, 31, 30, 31, 30,
        31, 31, 30, 31, 30, 31
    };

    // Преобразуем дату формата MM-DD в порядковый номер дня года.
    private int dayOfYear(String date) {

        // Извлекаем первые два символа и преобразуем их в номер месяца.
        int month = Integer.parseInt(date.substring(0, 2));

        // Извлекаем два последних символа даты и получаем номер дня.
        int day = Integer.parseInt(date.substring(3, 5));

        // Создаём переменную для суммы дней предыдущих месяцев.
        int totalDays = 0;

        // Перебираем все месяцы, которые идут перед указанным месяцем.
        for (int i = 0; i < month - 1; i++) {

            // Прибавляем количество дней текущего месяца к общей сумме.
            totalDays += DAYS_IN_MONTH[i];
        }

        // Прибавляем день текущего месяца и возвращаем номер дня года.
        return totalDays + day;
    }

    // Возвращаем количество дней, в течение которых Элис и Боб
    // одновременно находятся в Риме.
    public int countDaysTogether(
            String arriveAlice,
            String leaveAlice,
            String arriveBob,
            String leaveBob) {

        // Преобразуем дату приезда Элис в номер дня года.
        int aliceStart = dayOfYear(arriveAlice);

        // Преобразуем дату отъезда Элис в номер дня года.
        int aliceEnd = dayOfYear(leaveAlice);

        // Преобразуем дату приезда Боба в номер дня года.
        int bobStart = dayOfYear(arriveBob);

        // Преобразуем дату отъезда Боба в номер дня года.
        int bobEnd = dayOfYear(leaveBob);

        // Начало общего периода — более поздняя дата приезда.
        int start = Math.max(aliceStart, bobStart);

        // Конец общего периода — более ранняя дата отъезда.
        int end = Math.min(aliceEnd, bobEnd);

        // Если начало позже конца, периоды не пересекаются.
        if (start > end) {

            // Возвращаем ноль, так как общих дней нет.
            return 0;
        }

        // Считаем все дни общего периода, включая обе граничные даты.
        return end - start + 1;
    }
}
```

# 4. Подробное объяснение кода

## 4.1. Объявление массива

```java
private static final int[] DAYS_IN_MONTH = {
    31, 28, 31, 30, 31, 30,
    31, 31, 30, 31, 30, 31
};
```

Разберём объявление:

- `private` — поле доступно только внутри класса `Solution`.
- `static` — поле принадлежит классу, а не конкретному объекту.
- `final` — ссылку на массив нельзя переназначить.
- `int[]` — массив целых чисел.
- `DAYS_IN_MONTH` — название массива.

Массив позволяет получать количество дней в каждом месяце по его индексу.

Например:

```java
DAYS_IN_MONTH[0] // 31 — январь
DAYS_IN_MONTH[1] // 28 — февраль
DAYS_IN_MONTH[7] // 31 — август
```

Обратите внимание: `final` не делает содержимое массива неизменяемым. Оно означает, что нельзя присвоить полю ссылку на другой массив. В нашем решении элементы массива не изменяются.

## 4.2. Метод `dayOfYear()`

```java
private int dayOfYear(String date)
```

Метод принимает строку с датой и возвращает номер дня в году.

Например:

```java
dayOfYear("08-16")
```

должен вернуть:

```text
228
```

### Извлечение месяца

```java
int month = Integer.parseInt(date.substring(0, 2));
```

Метод `substring(0, 2)` возвращает часть строки от индекса `0` включительно до индекса `2` исключительно.

Для строки:

```text
08-16
```

индексы выглядят так:

```text
Символ:  0  8  -  1  6
Индекс:  0  1  2  3  4
```

Следовательно:

```java
date.substring(0, 2)
```

возвращает строку `"08"`.

Затем:

```java
Integer.parseInt("08")
```

преобразует строку в целое число `8`.

Итог:

```java
month = 8;
```

### Извлечение дня

```java
int day = Integer.parseInt(date.substring(3, 5));
```

Выражение:

```java
date.substring(3, 5)
```

возвращает `"16"`.

После преобразования:

```java
day = 16;
```

### Подсчёт дней предыдущих месяцев

```java
int totalDays = 0;
```

Создаём переменную и начинаем подсчёт с нуля.

Далее:

```java
for (int i = 0; i < month - 1; i++) {
    totalDays += DAYS_IN_MONTH[i];
}
```

Разберём цикл на примере августа.

```text
month = 8
month - 1 = 7
```

Цикл выполняется, пока `i < 7`.

Последовательно:

| Итерация | `i` | Месяц | Прибавляем | `totalDays` |
|---:|---:|---|---:|---:|
| 1 | 0 | Январь | 31 | 31 |
| 2 | 1 | Февраль | 28 | 59 |
| 3 | 2 | Март | 31 | 90 |
| 4 | 3 | Апрель | 30 | 120 |
| 5 | 4 | Май | 31 | 151 |
| 6 | 5 | Июнь | 30 | 181 |
| 7 | 6 | Июль | 31 | 212 |

После седьмой итерации `i` становится равным `7`.

Проверка:

```text
7 < 7 → false
```

Цикл завершается.

Получаем:

```java
totalDays = 212;
```

Наконец:

```java
return totalDays + day;
```

Подставляем значения:

```text
212 + 16 = 228
```

Метод возвращает `228`.

## 4.3. Преобразование четырёх дат

```java
int aliceStart = dayOfYear(arriveAlice);
int aliceEnd = dayOfYear(leaveAlice);
int bobStart = dayOfYear(arriveBob);
int bobEnd = dayOfYear(leaveBob);
```

Вместо строк получаем четыре целых числа:

- `aliceStart` — день приезда Элис.
- `aliceEnd` — день отъезда Элис.
- `bobStart` — день приезда Боба.
- `bobEnd` — день отъезда Боба.

После этого можно выполнять математические операции.

## 4.4. Определение начала общего периода

```java
int start = Math.max(aliceStart, bobStart);
```

Метод `Math.max(a, b)` возвращает большее из двух чисел.

Например:

```java
Math.max(227, 228)
```

возвращает `228`.

Это означает, что общий период начинается в тот день, когда в Риме уже находятся оба путешественника.

## 4.5. Определение конца общего периода

```java
int end = Math.min(aliceEnd, bobEnd);
```

Метод `Math.min(a, b)` возвращает меньшее из двух чисел.

Например:

```java
Math.min(230, 231)
```

возвращает `230`.

Общий период заканчивается в день отъезда того путешественника, который уезжает раньше.

## 4.6. Проверка отсутствия пересечения

```java
if (start > end) {
    return 0;
}
```

Если начало общего периода позже его конца, общих дней нет.

Например:

```text
start = 305
end   = 304
```

Проверка:

```text
305 > 304 → true
```

Метод возвращает `0`.

Если же `start == end`, пересечение существует и длится один день.

## 4.7. Подсчёт общего количества дней

```java
return end - start + 1;
```

Если начало и конец общего периода совпадают, получаем:

```text
359 - 359 + 1 = 1
```

Если общий период продолжается с 228-го по 230-й день:

```text
230 - 228 + 1 = 3
```

Прибавление единицы обязательно, поскольку даты приезда и отъезда включаются в пребывание.

# 5. Пошаговое выполнение примера 1

```text
arriveAlice = "08-15"

```

Ожидаемый ответ:

## Шаг 1. Переводим даты в номера дней года

Количество дней с января по июль:

```text
31 + 28 + 31 + 30 + 31 + 30 + 31 = 212
```

Теперь вычисляем каждую дату:

```text
08-15 → 212 + 15 = 227

Получаем:

aliceStart = 227;
aliceEnd   = 230;
bobStart   = 228;
bobEnd     = 231;
```

## Шаг 2. Находим начало общего периода

Выполняется:

```java
int start = Math.max(aliceStart, bobStart);
```

Подставляем значения:

```text
start = Math.max(227, 228)
start = 228
```

Более поздняя дата приезда — 16 августа.

## Шаг 3. Находим конец общего периода

Выполняется:

```java
int end = Math.min(aliceEnd, bobEnd);
```

Подставляем значения:

```text
end = Math.min(230, 231)

```

Более ранняя дата отъезда — 18 августа.

```java
if (start > end)
```

Подставляем:

```text
228 > 230 → false
```

Пересечение существует.

## Шаг 5. Вычисляем ответ

```java
return end - start + 1;
```

Подставляем значения:

```text
230 - 228 + 1 = 3
```

Совместные дни:

```text
16 августа
17 августа
18 августа
```

**Ответ: `3`.**

# 6. Пошаговое выполнение примера 2

## Входные данные

```text
arriveAlice = "10-01"
leaveAlice  = "10-31"
arriveBob   = "11-01"
leaveBob    = "12-31"
```

Ожидаемый ответ:

```text
0
```

## Шаг 1. Переводим даты в номера дней года

Перед октябрём прошло 273 дня:

```text
31 + 28 + 31 + 30 + 31 + 30 + 31 + 31 + 30 = 273
```

Перед ноябрём прошло 304 дня.

Поэтому:

```text
10-01 → 273 + 1  = 274
10-31 → 273 + 31 = 304
11-01 → 304 + 1  = 305
12-31 → 334 + 31 = 365
```

Получаем:

```java
aliceStart = 274;
aliceEnd   = 304;
bobStart   = 305;
bobEnd     = 365;
```

## Шаг 2. Находим начало общего периода

```java
int start = Math.max(aliceStart, bobStart);
```

Вычисляем:

```text
start = Math.max(274, 305)
start = 305
```

Начало возможного совместного пребывания — 1 ноября.

## Шаг 3. Находим конец общего периода

```java
int end = Math.min(aliceEnd, bobEnd);
```

Вычисляем:

```text
end = Math.min(304, 365)
end = 304
```

Последний день пребывания Элис — 31 октября.

## Шаг 4. Проверяем пересечение

```java
if (start > end) {
    return 0;
}
```

Подставляем значения:

```text
305 > 304 → true
```

Начало находится позже конца.

Элис уже уехала, когда Боб только приезжает.

Метод возвращает `0`.

**Ответ: `0`.**

Обратите внимание: в этом случае нельзя вычислять количество дней без предварительной проверки. Иначе получилось бы:

```text
304 - 305 + 1 = 0
```

В данном примере результат случайно совпал бы с правильным ответом, но при большем разрыве дат выражение могло бы стать отрицательным. Поэтому проверка обязательна.

# 7. Дополнительный пример: один общий день

В условии приведены два примера. Рассмотрим ещё один, чтобы проверить случай, когда периоды пересекаются ровно на один день.

## Входные данные

```text
arriveAlice = "12-24"
leaveAlice  = "12-25"
arriveBob   = "12-25"
leaveBob    = "12-26"
```

Ожидаемый ответ:

```text
1
```

## Шаг 1. Преобразуем даты

Перед декабрём прошло 334 дня.

```text
12-24 → 334 + 24 = 358
12-25 → 334 + 25 = 359
12-25 → 334 + 25 = 359
12-26 → 334 + 26 = 360
```

Получаем:

```java
aliceStart = 358;
aliceEnd   = 359;
bobStart   = 359;
bobEnd     = 360;
```

## Шаг 2. Находим начало общего периода

```java
start = Math.max(358, 359);
start = 359;
```

## Шаг 3. Находим конец общего периода

```java
end = Math.min(359, 360);
end = 359;
```

Таким образом:

```text
start = 359
end   = 359
```

## Шаг 4. Проверяем пересечение

```text
359 > 359 → false
```

Общий период существует.

## Шаг 5. Считаем дни

```text
359 - 359 + 1 = 1
```

Оба путешественника находятся в Риме 25 декабря.

**Ответ: `1`.**

Этот пример показывает, почему нужно использовать условие `start > end`, а не `start >= end`. Если начало и конец совпадают, это один общий день.

# 8. Анализ сложности алгоритма

## Временная сложность

Для каждой даты метод `dayOfYear()` выполняет цикл максимум по 11 предыдущим месяцам.

Мы обрабатываем ровно четыре даты.

Количество месяцев всегда равно 12, поэтому количество операций ограничено постоянной величиной.

**Временная сложность: `O(1)`.**

## Пространственная сложность

Используются:

- фиксированный массив из 12 элементов;
- несколько целочисленных переменных;
- строки дат, предоставленные на вход.

Дополнительная память алгоритма не зависит от величины входных данных.

**Дополнительная пространственная сложность: `O(1)`.**

Итог:

| Показатель | Сложность |
|---|---|
| Время | `O(1)` |
| Дополнительная память | `O(1)` |

Решение оптимально по асимптотическим времени и дополнительной памяти для задачи с фиксированным форматом дат.

# 9. Типичные ошибки

## Ошибка 1. Забыть прибавить единицу

Неправильно:

```java
return end - start;
```

Если общий период составляет 16, 17 и 18 августа:

```text
230 - 228 = 2
```

Но дней три.

Правильно:

```java
return end - start + 1;
```

## Ошибка 2. Не проверять пересечение периодов

Нельзя безусловно возвращать:

```java
return end - start + 1;
```

Сначала необходимо убедиться, что:

```java
start <= end
```

Иначе результат может оказаться отрицательным.

## Ошибка 3. Использовать `Math.min()` для начала периода

Начало общего периода определяется более поздним приездом, поэтому нужен `Math.max()`:

```java
int start = Math.max(aliceStart, bobStart);
```

## Ошибка 4. Использовать `Math.max()` для конца периода

Конец общего периода определяется более ранним отъездом, поэтому нужен `Math.min()`:

```java
int end = Math.min(aliceEnd, bobEnd);
```

## Ошибка 5. Неправильно обращаться к индексам массива

Номер месяца начинается с `1`, а индексы массива — с `0`.

Поэтому цикл должен обрабатывать предыдущие месяцы:

```java
for (int i = 0; i < month - 1; i++)
```

Для августа это индексы `0–6`, то есть январь — июль.

# 10. Итоговый алгоритм

Запомни последовательность действий:

1. Преобразовать дату приезда Элис в номер дня года.
2. Преобразовать дату отъезда Элис в номер дня года.
3. Преобразовать дату приезда Боба в номер дня года.
4. Преобразовать дату отъезда Боба в номер дня года.
5. Найти начало общего периода с помощью `Math.max()`.
6. Найти конец общего периода с помощью `Math.min()`.
7. Если `start > end`, вернуть `0`.
8. Иначе вернуть `end - start + 1`.

Главная формула:

```java
int start = Math.max(aliceStart, bobStart);
int end = Math.min(aliceEnd, bobEnd);

if (start > end) {
    return 0;
}

return end - start + 1;
```

Именно эта часть отвечает за поиск пересечения двух периодов. Преобразование дат в номера дней позволяет корректно сравнивать даты и вычислять продолжительность общего пребывания.

**Итоговая сложность:**

- Время: `O(1)`.
- Дополнительная память: `O(1)`.
