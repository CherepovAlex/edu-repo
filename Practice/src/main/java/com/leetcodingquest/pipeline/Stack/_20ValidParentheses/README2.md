## Условие задачи

Для строки `s`, содержащей только символы `'('`, `')'`, `'{'`, `'}'`, `'['` и `']'`, определите, является ли входная строка допустимой.

Входная строка является допустимой, если:
1. Открывающие скобки должны закрываться скобками того же типа.
2. Открывающие скобки должны закрываться в правильном порядке.
3. Каждой закрывающей скобке соответствует открывающая скобка того же типа.

### Примеры

| Пример | Входные данные (`s`) | Выходные данные | Описание |
| :--- | :--- | :--- | :--- |
| 1 | `"()"` | `true` | Простая пара |
| 2 | `"()[]{}"` | `true` | Несколько пар подряд |
| 3 | `"(]"` | `false` | Несовпадение типов |
| 4 | `"([])"` | `true` | Вложенные скобки |
| 5 | `"([)]"` | `false` | Неправильный порядок вложенности |

### Ограничения
*   $1 \le s.length \le 10^4$
*   `s` состоит только из символов `'()[]{}'`.

## Анализ и Алгоритм

### Основная идея
Задача требует проверки баланса скобок. Ключевое свойство скобок — это принцип **LIFO** (Last In, First Out — последним вошел, первым вышел).
*   Последняя открытая скобка должна закрыться первой.
*   Это идеально соответствует работе структуры данных **Стек (Stack)**.

### Шаг за шагом
1.  **Инициализация:** Создаем пустой стек для хранения открывающих скобок.
2.  **Итерация:** Проходим по строке символ за символом.
3.  **Открывающая скобка** (`(`, `{`, `[`):
    *   Помещаем её в стек (`push`). Мы "запоминаем", что эта скобка открыта, но еще не закрыта.
4.  **Закрывающая скобка** (`)`, `}`, `]`):
    *   Если стек пуст, значит, закрывающей скобке не соответствует ни одна открытая. Возвращаем `false`.
    *   Если стек не пуст, извлекаем верхний элемент (`pop`).
    *   Проверяем, является ли извлеченный элемент парой для текущей закрывающей скобки.
        *   `(` должен париться с `)`
        *   `{` должен париться с `}`
        *   `[` должен париться с `]`
    *   Если пары не совпадают, возвращаем `false`.
5.  **Финальная проверка:** После прохода всей строки стек должен быть пустым. Если в стеке остались элементы, значит, есть незакрытые открывающие скобки.

## Решение на Java

```java
import java.util.Stack;

public class Solution {
    /**
     * Проверяет, является ли строка с скобками валидной.
     *
     * @param s Входная строка, содержащая скобки
     * @return true, если скобки сбалансированы; false в противном случае
     */
    public boolean isValid(String s) {
        // Создаем стек для хранения открывающих скобок
        // Stack<Character> хранит символы типа char
        Stack<Character> stack = new Stack<>();
        
        // Преобразуем строку в массив символов для эффективной итерации
        // toCharArray() создает копию символов строки
        for (char c : s.toCharArray()) {
            
            // Если текущий символ — открывающая скобка
            if (c == '(' || c == '{' || c == '[') {
                // Добавляем её в стек
                stack.push(c);
            } 
            // Если текущий символ — закрывающая скобка
            else {
                // Проверка 1: Если стек пуст, значит закрывающей скобке нечего "открыть"
                // Пример: s = ")" -> стек пуст, ошибка
                if (stack.isEmpty()) {
                    return false;
                }
                
                // Извлекаем последнюю добавленную открывающую скобку
                // pop() удаляет элемент из вершины стека и возвращает его
                char top = stack.pop();
                
                // Проверка 2: Совпадает ли тип скобки?
                // Проверяем три возможные пары. Если хотя бы одна пара не совпадает,
                // значит, порядок или типы скобок нарушены.
                if ((c == ')' && top != '(') || 
                    (c == '}' && top != '{') || 
                    (c == ']' && top != '[')) {
                    return false;
                }
                
                // Если пара совпадает, цикл продолжается. 
                // Элемент уже был удален из стека методом pop().
            }
        }
        
        // Финальная проверка:
        // Если стек пуст, значит все открывающие скобки были закрыты.
        // Если стек не пуст, значит остались незакрытые скобки (например, s = "(")
        return stack.isEmpty();
    }
}
```

## Построчное объяснение кода

Ниже приведен детальный разбор каждой строки кода для понимания внутренней логики.

```java
import java.util.Stack; // Импортируем класс Stack из java.util для работы со стеком
                        // Stack реализует интерфейс Collection и работает по принципу LIFO

public class Solution { // Объявляем публичный класс Solution
    // Публичный метод, который принимает строку и возвращает булево значение (true/false)
    public boolean isValid(String s) {
        
        // Создаем новый экземпляр стека.
        // Generic type <Character> указывает, что стек будет хранить объекты типа Character (символы)
        Stack<Character> stack = new Stack<>();
        
        // Цикл for-each проходит по каждому символу в массиве, полученном из строки s.
        // Метод s.toCharArray() преобразует строку в массив char[], что позволяет избежать
        // накладных расходов на вызов s.charAt(i) внутри цикла.
        for (char c : s.toCharArray()) {
            
            // Условие: проверяем, является ли текущий символ 'c' открывающей скобкой.
            // Открывающие скобки: '(', '{', '['.
            if (c == '(' || c == '{' || c == '[') {
                
                // Метод push() добавляет символ 'c' в верхнюю часть стека.
                // Теперь эта скобка ждет своей пары.
                stack.push(c);
            } 
            // Если символ не является открывающей скобкой, он обязан быть закрывающей 
            // (так как по условию задачи в строке только скобки).
            else {
                
                // Проверяем, пуст ли стек.
                // Если стек пуст, значит мы встретили закрывающую скобку, 
                // для которой нет соответствующей открывающей скобки в стеке.
                // Пример ошибки: s = ")", стек был пуст сразу.
                if (stack.isEmpty()) {
                    // Возвращаем false, так как валидность строки нарушена.
                    return false;
                }
                
                // Метод pop() извлекает и удаляет элемент из вершины стека.
                // Это должна быть та открывающая скобка, которая была добавлена последней.
                char top = stack.pop();
                
                // Проверяем корректность пары скобок.
                // Логика:
                // 1. Если текущая скобка ')', то верхняя в стеке должна быть '('.
                // 2. Если текущая скобка '}', то верхняя в стеке должна быть '{'.
                // 3. Если текущая скобка ']', то верхняя в стеке должна быть '['.
                // Оператор || (ИЛИ) означает, что если хотя бы одно из условий истинно (т.е.
                // текущая скобка не соответствует верхней в стеке), то пара неверна.
                if ((c == ')' && top != '(') || 
                    (c == '}' && top != '{') || 
                    (c == ']' && top != '[')) {
                    
                    // Если пара не совпадает (например, '(' в стеке, а пришла ']'),
                    // возвращаем false.
                    return false;
                }
                
                // Если пара совпадает, мы ничего не делаем явно, так как pop() уже
                // удалил верхний элемент из стека, эффективно "закрыв" пару.
            }
        }
        
        // Цикл завершен. Проходим всю строку.
        // Теперь нужно проверить, остались ли в стеке незакрытые открывающие скобки.
        // Метод isEmpty() возвращает true, если стек пуст.
        return stack.isEmpty();
    }
}
```

## Трассировка выполнения (Trace)

Рассмотрим, как меняется состояние стека для каждого примера.
Обозначение: `Stack: [элементы снизу -> сверху]`

### Пример 1: `s = "()"`
1.  **Старт:** `Stack: []`
2.  **Символ `(`**:
    *   Это открывающая скобка.
    *   `push('(')`
    *   `Stack: ['(']`
3.  **Символ `)`**:
    *   Это закрывающая скобка.
    *   Стек не пуст.
    *   `pop()` -> `top = '('`.
    *   Проверка: `)` и `(` совпадают? **Да**.
    *   `Stack: []`
4.  **Конец строки**:
    *   `stack.isEmpty()` -> `true`.
    *   **Результат: `true`**

### Пример 2: `s = "()[]{}"`
1.  **Старт:** `Stack: []`
2.  **Символ `(`**: `push('(')` -> `Stack: ['(']`
3.  **Символ `)`**: `pop()` -> `top='('`. Совпадает. -> `Stack: []`
4.  **Символ `[`**: `push('[')` -> `Stack: ['[']`
5.  **Символ `]`**: `pop()` -> `top='['`. Совпадает. -> `Stack: []`
6.  **Символ `{`**: `push('{')` -> `Stack: ['{']`
7.  **Символ `}`**: `pop()` -> `top='{'`. Совпадает. -> `Stack: []`
8.  **Конец строки**:
    *   `stack.isEmpty()` -> `true`.
    *   **Результат: `true`**

### Пример 3: `s = "(]"`
1.  **Старт:** `Stack: []`
2.  **Символ `(`**: `push('(')` -> `Stack: ['(']`
3.  **Символ `]`**:
    *   Это закрывающая скобка.
    *   `pop()` -> `top = '('`.
    *   Проверка: `]` и `(` совпадают? **Нет**.
    *   Условие `(c == ']' && top != '[')` истинно.
    *   **Результат: `false`** (выход из метода)

### Пример 4: `s = "([])"`
1.  **Старт:** `Stack: []`
2.  **Символ `(`**: `push('(')` -> `Stack: ['(']`
3.  **Символ `[`**: `push('[')` -> `Stack: ['(', '[']`
4.  **Символ `]`**:
    *   `pop()` -> `top = '['`.
    *   Проверка: `]` и `[` совпадают? **Да**.
    *   `Stack: ['(']`
5.  **Символ `)`**:
    *   `pop()` -> `top = '('`.
    *   Проверка: `)` и `(` совпадают? **Да**.
    *   `Stack: []`
6.  **Конец строки**:
    *   `stack.isEmpty()` -> `true`.
    *   **Результат: `true`**

### Пример 5: `s = "([)]"`
Это пример нарушения порядка вложенности.
1.  **Старт:** `Stack: []`
2.  **Символ `(`**: `push('(')` -> `Stack: ['(']`
3.  **Символ `[`**: `push('[')` -> `Stack: ['(', '[']`
4.  **Символ `)`**:
    *   Это закрывающая скобка.
    *   `pop()` -> `top = '['` (последний добавленный).
    *   Проверка: `)` и `[` совпадают? **Нет**.
    *   Условие `(c == ')' && top != '(')` истинно.
    *   **Результат: `false`** (выход из метода)

## Сложность алгоритма

### Временная сложность: $O(n)$
*   Мы проходим по строке длиной $n$ ровно один раз.
*   Операции со стеком (`push`, `pop`, `isEmpty`) имеют временную сложность $O(1)$.
*   Общее время работы линейно зависит от длины входной строки.

### Пространственная сложность: $O(n)$
*   В худшем случае (например, строка `"((((...))))"`) в стек помещаются все открывающие скобки.
*   Максимальный размер стека составляет $n/2$ элементов.
*   Таким образом, дополнительная память растет линейно с размером входа.

## Оптимизация и лучшие практики

Хотя решение с `java.util.Stack` является классическим и правильным для учебных целей, в современной Java разработке (и на собеседованиях) рекомендуется использовать `Deque` (Double Ended Queue).

### Почему `ArrayDeque` лучше `Stack`?
1.  **Производительность:** `Stack` наследуется от `Vector`, который синхронизирован (thread-safe), что добавляет накладные расходы. `ArrayDeque` не синхронизирован и работает быстрее.
2.  **Устаревание:** Класс `Stack` считается устаревшим (legacy) в Java API. Рекомендуется использовать `Deque` в качестве интерфейса и `ArrayDeque` в качестве реализации.

### Альтернативная реализация с `ArrayDeque`

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class SolutionOptimized {
    public boolean isValid(String s) {
        // Используем Deque как стек
        Deque<Character> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '{' || c == '[') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) {
                    return false;
                }
                char top = stack.pop();
                if ((c == ')' && top != '(') || 
                    (c == '}' && top != '{') || 
                    (c == ']' && top != '[')) {
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }
}
```

Этот код полностью эквивалентен по логике, но является более "современным" и эффективным решением для production-кода.
