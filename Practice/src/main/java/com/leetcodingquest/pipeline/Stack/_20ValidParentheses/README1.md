# Valid Parentheses (LeetCode 20) — решение на Java

> Разбор задачи «Допустимые скобки» с оптимальным решением, построчными комментариями и пошаговой трассировкой всех примеров.

---

## 📋 Условие задачи

Для строки `s`, содержащей только символы `'('`, `')'`, `'{'`, `'}'`, `'['` и `']'`, определите, является ли входная строка **допустимой**.

Входная строка является допустимой, если:

1. Открывающие скобки должны закрываться скобками **того же типа**.
2. Открывающие скобки должны закрываться в **правильном порядке**.
3. Каждой закрывающей скобке соответствует открывающая скобка того же типа.

### Примеры

| # | Входные данные | Выходные данные |
|---|----------------|-----------------|
| 1 | `s = "()"` | `true` |
| 2 | `s = "()[]{}"` | `true` |
| 3 | `s = "(]"` | `false` |
| 4 | `s = "([])"` | `true` |
| 5 | `s = "([)]"` | `false` |

### Ограничения

- `1 <= s.length <= 10^4`
- `s` состоит только из символов `'()[]{}'`

---

## 💡 Ключевая идея

**Стек — идеальная структура для проверки вложенности скобок**, потому что скобки закрываются в порядке, обратном порядку открытия (**LIFO** — last in, first out).

Каждая закрывающая скобка обязана совпасть именно с **вершиной** стека, а не с любым элементом — иначе нарушается правило правильного порядка.

---

## ✅ Оптимальное решение

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();          // 1
        for (char c : s.toCharArray()) {                      // 2
            if (c == '(' || c == '{' || c == '[') {           // 3
                stack.push(c);                                // 4
            } else {                                          // 5
                if (stack.isEmpty()) return false;            // 6
                char top = stack.pop();                       // 7
                if (c == ')' && top != '(') return false;     // 8
                if (c == '}' && top != '{') return false;     // 9
                if (c == ']' && top != '[') return false;     // 10
            }
        }
        return stack.isEmpty();                               // 11
    }
}
```

---

## 🔍 Комментарий к каждой строке

| Строка | Что делает |
|--------|-----------|
| **1** | Создаём стек (`ArrayDeque` — самая быстрая реализация `Deque` в Java, работает как стек через `push`/`pop`). Стек будет хранить ещё не закрытые открывающие скобки. |
| **2** | Проходим по каждому символу строки за один проход — O(n). |
| **3** | Если символ — открывающая скобка (`(`, `{`, `[`), то... |
| **4** | ...кладём её на вершину стека. Ждём парную закрывающую. |
| **5** | Иначе символ — закрывающая скобка, обрабатываем её. |
| **6** | Если стек пуст, а пришла закрывающая скобка — закрывать нечего, строка недопустима. Возвращаем `false`. |
| **7** | Достаём с вершины последнюю открытую скобку (`pop` удаляет и возвращает). |
| **8** | Если пришла `)`, но на вершине была не `(` — типы не совпали → `false`. |
| **9** | Аналогично для `}` и `{`. |
| **10** | Аналогично для `]` и `[`. |
| **11** | После обработки всей строки стек должен быть пуст. Если остались незакрытые открывающие скобки — `false`, иначе `true`. |

---

## ⚡ Почему решение оптимально

- **Время O(n)** — один проход по строке, каждая операция `push`/`pop` амортизированно O(1).
- **Пространство O(n)** — в худшем случае (например, `"((((((("`) стек хранит все `n` символов. Меньше не получится: нужно помнить порядок открытых скобок.

## 🧪 Пошаговая трассировка примеров

### Пример 1: `s = "()"` → `true`

| Шаг | Символ | Действие | Стек (вершина слева) |
|-----|--------|----------|----------------------|
| 1 | `(` | открывающая → `push('(')` | `['(']` |
| 2 | `)` | закрывающая, стек не пуст; `pop()` → `'('`; `')'` и `'('` совпали | `[]` |

Конец строки. Стек пуст → **`true`** ✅

---

### Пример 2: `s = "()[]{}"` → `true`

| Шаг | Символ | Действие | Стек |
|-----|--------|----------|------|
| 1 | `(` | `push('(')` | `['(']` |
| 2 | `)` | `pop()` → `'('`, пара совпала | `[]` |
| 3 | `[` | `push('[')` | `['[']` |
| 4 | `]` | `pop()` → `'['`, пара совпала | `[]` |
| 5 | `{` | `push('{')` | `['{']` |
| 6 | `}` | `pop()` → `'{'`, пара совпала | `[]` |

Стек пуст → **`true`** ✅

---

### Пример 3: `s = "(]"` → `false`

| Шаг | Символ | Действие | Стек |
|-----|--------|----------|------|
| 1 | `(` | `push('(')` | `['(']` |
| 2 | `]` | закрывающая, стек не пуст; `pop()` → `'('`; проверяем: `']'` требует `'['`, а на вершине `'('` → **несовпадение** | — |

На шаге 2 возвращаем **`false`** ❌

---

### Пример 4: `s = "([])"` → `true`

| Шаг | Символ | Действие | Стек |
|-----|--------|----------|------|
| 1 | `(` | `push('(')` | `['(']` |
| 2 | `[` | `push('[')` | `['[', '(']` |
| 3 | `]` | `pop()` → `'['`, пара совпала | `['(']` |
| 4 | `)` | `pop()` → `'('`, пара совпала | `[]` |

Стек пуст → **`true`** ✅

---

### Пример 5: `s = "([)]"` → `false`

| Шаг | Символ | Действие | Стек |
|-----|--------|----------|------|
| 1 | `(` | `push('(')` | `['(']` |
| 2 | `[` | `push('[')` | `['[', '(']` |
| 3 | `)` | закрывающая, `pop()` → `'['`; проверяем: `')'` требует `'('`, а на вершине `'['` → **несовпадение** | — |

На шаге 3 возвращаем **`false`** ❌

### `Solution.java`

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '{' || c == '[') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false;
                char top = stack.pop();
                if (c == ')' && top != '(') return false;
                if (c == '}' && top != '{') return false;
                if (c == ']' && top != '[') return false;
            }
        }
        return stack.isEmpty();
    }
}
```

### `Main.java` (для локального запуска)

```java
public class Main {
    public static void main(String[] args) {
        Solution solution = new Solution();

        System.out.println(solution.isValid("()"));       // true
        System.out.println(solution.isValid("()[]{}"));   // true
        System.out.println(solution.isValid("(]"));       // false
        System.out.println(solution.isValid("([])"));     // true
        System.out.println(solution.isValid("([)]"));     // false
    }
}
```

## 🧠 Что важно помнить на собеседовании

1. **Стек, а не счётчик.** Считать количество открывающих и закрывающих скобок недостаточно — нарушается правило порядка (`"([)]"` сломает счётчик).
2. **Проверка пустого стека.** Закрывающая скобка при пустом стеке — сразу `false`.
3. **Проверка после цикла.** В конце стек **обязан** быть пустым, иначе есть незакрытые скобки (`"(("` → `false`).
4. **`ArrayDeque` быстрее `Stack`.** Старый класс `Stack` синхронизирован и медленнее — в Java принято использовать `ArrayDeque`.
5. **Краевые случаи:** `""` (по ограничениям не встретится, но решение вернёт `true`), `"("`, `")"`, `"((("`, `")))"`, `"([]"`.
