## 1. Условие задачи

Дан двумерный массив `grid`, состоящий из нулей и единиц:

- `0` — суша.
- `1` — вода.

**Остров** — максимальная группа ячеек суши (`0`), соединённых по горизонтали или вертикали.

**Закрытый остров** — остров, который не касается границы массива. Иными словами, все его ячейки можно окружить водой, не выходя за пределы сетки.

Нужно вернуть количество закрытых островов.

Важно: соседство по диагонали не считается. Две ячейки, которые соприкасаются только углами, не являются соединёнными.

### Ограничения

- `1 <= grid.length, grid[0].length <= 100`
- `grid[i][j]` равно `0` или `1`.

## 3. Идея решения

Используем **DFS (Depth-First Search, поиск в глубину)**. Чтобы не зависеть от глубины рекурсии Java, реализуем DFS итеративно — с помощью собственного стека.

Алгоритм:

1. Перебираем каждую ячейку сетки.
2. Если ячейка содержит `1`, пропускаем её: это вода.
3. Если ячейка содержит `0`, начинаем обход нового острова.
4. Во время обхода проверяем каждую ячейку острова:
   - если хотя бы одна ячейка находится на границе, остров открытый;
   - если ни одна ячейка не находится на границе, остров закрытый.
5. После обхода всего острова увеличиваем счётчик, только если остров закрытый.
6. Продолжаем, пока не проверим всю сетку.

### Как определить границу?

Пусть:

- `rows` — число строк;
- `cols` — число столбцов;
- `r` — индекс строки;
- `c` — индекс столбца.

Ячейка находится на границе, если выполняется хотя бы одно условие:

```java
r == 0          // Верхняя граница.
r == rows - 1   // Нижняя граница.
c == 0          // Левая граница.
c == cols - 1   // Правая граница.
```

Если остров касается любой из этих границ, он не считается закрытым.

### Как помечаются посещённые ячейки?

В рабочей копии сетки заменяем посещённую сушу `0` на `1`. Это не позволяет добавлять одну и ту же ячейку в стек повторно.

В коде ниже создаётся копия входного массива, чтобы сохранить исходную сетку для демонстрации и не менять переданный вызывающим кодом массив.

---

## 4. Как работает DFS

Для каждой найденной ячейки суши помещаем в стек её координаты. Когда извлекаем ячейку, проверяем её соседей:

- сверху: `(r - 1, c)`;
- снизу: `(r + 1, c)`;
- слева: `(r, c - 1)`;
- справа: `(r, c + 1)`.

Добавляем соседа в стек только тогда, когда он находится внутри сетки и содержит необработанную сушу `0`.

Чтобы хранить две координаты в одном целочисленном элементе стека, используем кодирование:

```java
position = r * cols + c;
```

Обратное преобразование:

```java
r = position / cols;
c = position % cols;
```

Например, если `cols = 5`, а координаты ячейки `(2, 3)`, то:

```text
position = 2 * 5 + 3 = 13
row      = 13 / 5 = 2
col      = 13 % 5 = 3
```

## 5. Полный код Java с визуализацией

Сохрани код в файле `Solution1.java`. Он решает задачу и выводит в консоль исходную сетку, тип каждого найденного острова и итоговую сетку с обозначениями.

Обозначения визуализации:

- `~` — вода;
- `.` — ещё не обработанная суша;
- `C` — закрытый остров;
- `O` — открытый остров, касающийся границы.

> Визуализация использует дополнительные массивы для копии сетки и отображения островов. Метод `closedIsland` при этом возвращает корректный результат для LeetCode.

```java
import java.util.Arrays; // Подключаем утилиты для копирования массивов.

public class Solution1 { // Объявляем класс решения задачи.

    public int closedIsland(int[][] grid) { // Метод LeetCode: возвращает число закрытых островов.
        return solveAndVisualize(grid, false); // Запускаем алгоритм без подробной визуализации.
    } // Завершаем метод closedIsland.

    private int solveAndVisualize(int[][] grid, boolean visualize) { // Решает задачу и при необходимости показывает результат.
        int rows = grid.length; // Получаем количество строк.
        int cols = grid[0].length; // Получаем количество столбцов.
        int[][] work = new int[rows][cols]; // Создаём копию сетки для обхода.

        for (int r = 0; r < rows; r++) { // Перебираем строки.
            work[r] = Arrays.copyOf(grid[r], cols); // Копируем строку, чтобы не менять исходный массив.
        } // Завершаем копирование сетки.

        char[][] picture = new char[rows][cols]; // Создаём сетку для визуализации.

        for (int r = 0; r < rows; r++) { // Перебираем строки.
            for (int c = 0; c < cols; c++) { // Перебираем столбцы.
                picture[r][c] = grid[r][c] == 1 ? '~' : '.'; // Вода — ~, ещё не обработанная суша — точка.
            } // Завершаем перебор столбцов.
        } // Завершаем подготовку визуальной сетки.

        int[] stack = new int[rows * cols]; // Создаём стек для итеративного DFS.
        int[] islandCells = new int[rows * cols]; // Храним ячейки текущего острова.
        int closedIslands = 0; // Изначально закрытых островов нет.
        int islandNumber = 0; // Счётчик всех найденных островов.

        for (int r = 0; r < rows; r++) { // Перебираем все строки сетки.
            for (int c = 0; c < cols; c++) { // Перебираем все столбцы сетки.
                if (work[r][c] != 0) { // Если это вода или уже обработанная ячейка, пропускаем её.
                    continue; // Переходим к следующей ячейке.
                } // Завершаем проверку, нужно ли начинать новый обход.

                int top = 0; // Изначально стек пуст.
                int cellsCount = 0; // Считаем ячейки текущего острова.
                boolean isClosed = true; // Сначала предполагаем, что остров закрытый.

                stack[top++] = r * cols + c; // Добавляем стартовую ячейку в стек.
                work[r][c] = 1; // Помечаем её посещённой.

                while (top > 0) { // Обрабатываем ячейки, пока стек не опустеет.
                    int position = stack[--top]; // Извлекаем последнюю добавленную ячейку.
                    int cr = position / cols; // Восстанавливаем номер строки.
                    int cc = position % cols; // Восстанавливаем номер столбца.
                    islandCells[cellsCount++] = position; // Сохраняем ячейку текущего острова.

                    if (cr == 0 || cr == rows - 1 || cc == 0 || cc == cols - 1) { // Проверяем касание границы.
                        isClosed = false; // Остров касается края и не является закрытым.
                    } // Завершаем проверку границы.

                    if (cr > 0 && work[cr - 1][cc] == 0) { // Если сверху есть необработанная суша.
                        work[cr - 1][cc] = 1; // Помечаем соседа посещённым сразу.
                        stack[top++] = (cr - 1) * cols + cc; // Добавляем верхнего соседа в стек.
                    } // Завершаем проверку верхнего соседа.

                    if (cr < rows - 1 && work[cr + 1][cc] == 0) { // Если снизу есть необработанная суша.
                        work[cr + 1][cc] = 1; // Помечаем соседа посещённым сразу.
                        stack[top++] = (cr + 1) * cols + cc; // Добавляем нижнего соседа в стек.
                    } // Завершаем проверку нижнего соседа.

                    if (cc > 0 && work[cr][cc - 1] == 0) { // Если слева есть необработанная суша.
                        work[cr][cc - 1] = 1; // Помечаем соседа посещённым сразу.
                        stack[top++] = cr * cols + cc - 1; // Добавляем левого соседа в стек.
                    } // Завершаем проверку левого соседа.

                    if (cc < cols - 1 && work[cr][cc + 1] == 0) { // Если справа есть необработанная суша.
                        work[cr][cc + 1] = 1; // Помечаем соседа посещённым сразу.
                        stack[top++] = cr * cols + cc + 1; // Добавляем правого соседа в стек.
                    } // Завершаем проверку правого соседа.
                } // Завершаем обход текущего острова.

                islandNumber++; // Увеличиваем номер найденного острова.
                char symbol = isClosed ? 'C' : 'O'; // C — закрытый остров, O — открытый остров.

                for (int i = 0; i < cellsCount; i++) { // Перебираем все ячейки текущего острова.
                    int cell = islandCells[i]; // Получаем закодированные координаты.
                    int ir = cell / cols; // Вычисляем строку ячейки.
                    int ic = cell % cols; // Вычисляем столбец ячейки.
                    picture[ir][ic] = symbol; // Отмечаем остров на визуальной сетке.
                } // Завершаем визуальную разметку острова.

                if (isClosed) { // Если остров не касается границы.
                    closedIslands++; // Увеличиваем ответ.
                } // Завершаем подсчёт закрытого острова.

                if (visualize) { // Если включён подробный режим.
                    System.out.println("Остров №" + islandNumber + ": " // Выводим номер острова.
                            + (isClosed ? "закрытый (C)" : "открытый (O)")); // Выводим тип острова.
                    System.out.println("Размер острова: " + cellsCount + " ячеек"); // Выводим размер острова.
                    printGrid(picture); // Показываем сетку после обработки этого острова.
                    System.out.println(); // Добавляем пустую строку для читаемости.
                } // Завершаем вывод промежуточного состояния.
            } // Завершаем перебор столбцов.
        } // Завершаем перебор строк.

        if (visualize) { // Если включена визуализация.
            System.out.println("Итоговая сетка:"); // Выводим заголовок итоговой сетки.
            printGrid(picture); // Показываем все острова.
            System.out.println("Обозначения: ~ — вода, C — закрытый остров, O — открытый остров."); // Выводим легенду.
            System.out.println("Количество закрытых островов: " + closedIslands); // Выводим ответ.
        } // Завершаем итоговый вывод.

        return closedIslands; // Возвращаем количество закрытых островов.
    } // Завершаем метод solveAndVisualize.

    private void printGrid(char[][] grid) { // Метод выводит символьную сетку в консоль.
        for (char[] row : grid) { // Перебираем строки.
            for (char cell : row) { // Перебираем ячейки строки.
                System.out.print(cell + " "); // Выводим ячейку с пробелом.
            } // Завершаем вывод строки.
            System.out.println(); // Переходим на новую строку.
        } // Завершаем вывод сетки.
    } // Завершаем метод printGrid.

    private void runExample(String title, int[][] grid, int expected) { // Запускает пример и проверяет результат.
        System.out.println("========================================"); // Разделитель примеров.
        System.out.println(title); // Выводим название примера.
        System.out.println("Исходная сетка (0 — суша, 1 — вода):"); // Поясняем значения исходной сетки.

        for (int[] row : grid) { // Перебираем строки исходной сетки.
            for (int cell : row) { // Перебираем значения строки.
                System.out.print(cell + " "); // Выводим значение ячейки.
            } // Завершаем вывод значений строки.
            System.out.println(); // Переходим на следующую строку.
        } // Завершаем вывод исходной сетки.

        System.out.println(); // Добавляем пустую строку.
        int actual = solveAndVisualize(grid, true); // Решаем задачу и выводим визуализацию.
        System.out.println("Ожидаемый результат: " + expected); // Показываем ожидаемый ответ.
        System.out.println("Фактический результат: " + actual); // Показываем ответ алгоритма.
        System.out.println("Тест: " + (actual == expected ? "ПРОЙДЕН" : "НЕ ПРОЙДЕН")); // Сравниваем ответы.
        System.out.println(); // Отделяем примеры друг от друга.
    } // Завершаем метод runExample.

    public static void main(String[] args) { // Точка входа в программу.
        Solution1 solution = new Solution1(); // Создаём объект решения.

        int[][] grid1 = { // Исходные данные примера 1.
                {1, 1, 1, 1, 1, 1, 1, 0}, // Строка 0.
                {1, 0, 0, 0, 0, 1, 1, 0}, // Строка 1.
                {1, 0, 1, 0, 1, 1, 1, 0}, // Строка 2.
                {1, 0, 0, 0, 0, 1, 0, 1}, // Строка 3.
                {1, 1, 1, 1, 1, 1, 1, 0}  // Строка 4.
        }; // Завершаем объявление примера 1.

        int[][] grid2 = { // Исходные данные примера 2.
                {0, 0, 1, 0, 0}, // Строка 0.
                {0, 1, 0, 1, 0}, // Строка 1.
                {0, 1, 1, 1, 0}  // Строка 2.
        }; // Завершаем объявление примера 2.

        int[][] grid3 = { // Исходные данные примера 3.
                {1, 1, 1, 1, 1, 1, 1}, // Строка 0.
                {1, 0, 0, 0, 0, 0, 1}, // Строка 1.
                {1, 0, 1, 1, 1, 0, 1}, // Строка 2.
                {1, 0, 1, 0, 1, 0, 1}, // Строка 3.
                {1, 0, 1, 1, 1, 0, 1}, // Строка 4.
                {1, 0, 0, 0, 0, 0, 1}, // Строка 5.
                {1, 1, 1, 1, 1, 1, 1}  // Строка 6.
        }; // Завершаем объявление примера 3.

        solution.runExample("ПРИМЕР 1", grid1, 2); // Визуализируем первый пример и проверяем ответ.
        solution.runExample("ПРИМЕР 2", grid2, 1); // Визуализируем второй пример и проверяем ответ.
        solution.runExample("ПРИМЕР 3", grid3, 2); // Визуализируем третий пример и проверяем ответ.
    } // Завершаем main.
} // Завершаем класс Solution1.
```

## 7. Пошаговый разбор примера 1

Исходная сетка имеет размер `5 × 8`. Индексы строк — от `0` до `4`, столбцов — от `0` до `7`.

### Первый остров: открытый

Первая необработанная суша находится в `(0, 7)`. Она расположена на верхней границе.

DFS находит соединённые ячейки `(0, 7)`, `(1, 7)` и `(2, 7)`. Остров касается границы, поэтому `isClosed = false`. Счётчик остаётся равным `0`.

### Второй остров: закрытый

Следующая большая группа начинается в `(1, 1)`. DFS обходит всю группу:

```text
(1,1), (1,2), (1,3), (1,4)
(2,1), (2,3)
(3,1), (3,2), (3,3), (3,4)
```

Ни одна ячейка этой группы не находится на краю массива. Поэтому `isClosed = true`, а `closedIslands` увеличивается до `1`.

### Третий остров: закрытый

Ячейка `(3, 6)` — отдельный остров. Все четыре соседа являются водой. Он не касается границы, поэтому счётчик увеличивается до `2`.

### Четвёртый остров: открытый

Ячейка `(4, 7)` находится на нижней границе. Этот остров не закрытый, и счётчик не меняется.

**Результат примера 1: `2`.**

## 8. Пошаговый разбор примера 2

Исходная сетка имеет размер `3 × 5`.

### Первый остров: открытый

DFS начинается в `(0, 0)` и обходит левую группу:

```text
(0,0), (0,1), (1,0), (2,0)
```

Она касается верхней и нижней границ. Счётчик остаётся `0`.

### Второй остров: открытый

Следующая группа начинается в `(0, 3)`:

```text
(0,3), (0,4), (1,4), (2,4)
```

Она касается верхней, правой и нижней границ. Счётчик по-прежнему равен `0`.

### Третий остров: закрытый

Ячейка `(1, 2)` окружена водой:

- сверху `(0, 2)` — `1`;
- снизу `(2, 2)` — `1`;
- слева `(1, 1)` — `1`;
- справа `(1, 3)` — `1`.

Это отдельный остров из одной ячейки. Он не касается границы, поэтому `closedIslands` становится равным `1`.

**Результат примера 2: `1`.**

## 9. Пошаговый разбор примера 3

Сетка имеет размер `7 × 7`.

### Первый остров: закрытое кольцо

DFS начинает обход в `(1, 1)` и обнаруживает кольцевую группу суши:

- верхняя часть — строка `1`, столбцы `1–5`;
- левая часть — столбец `1`, строки `2–4`;
- правая часть — столбец `5`, строки `2–4`;
- нижняя часть — строка `5`, столбцы `1–5`.

Все эти ячейки соединены по горизонтали и вертикали. Кольцо не касается границы сетки, поэтому счётчик становится равным `1`.

### Второй остров: центральная ячейка

Затем DFS обнаруживает `(3, 3)`. Все четыре соседние ячейки содержат воду (`1`), поэтому центр не соединён с кольцом.

Это отдельный закрытый остров. Счётчик увеличивается до `2`.

**Результат примера 3: `2`.**

## 10. Сложность алгоритма

Обозначим количество строк через `m`, а количество столбцов через `n`.

### Временная сложность: `O(m × n)`

Внешние циклы просматривают каждую ячейку. При DFS каждая ячейка суши добавляется в стек не более одного раза, потому что сразу после добавления помечается как посещённая.

Следовательно, суммарная работа пропорциональна количеству ячеек.

### Пространственная сложность

Для основного алгоритма DFS требуется до `O(m × n)` памяти на стек в худшем случае.

В учебной реализации дополнительно создаются:

- `work` — копия входной сетки;
- `picture` — символьная сетка визуализации;
- `islandCells` — список ячеек текущего острова.

Поэтому полная реализация с визуализацией использует `O(m × n)` дополнительной памяти.

При ограничениях задачи `m, n <= 100`, то есть сетка содержит не более `10 000` ячеек.

## 11. Что важно запомнить

1. Остров — это вся связная группа нулей, а не отдельная ячейка.
2. Соседство по диагонали не учитывается.
3. Если хотя бы одна ячейка острова касается границы, остров открытый.
4. DFS обходит остров целиком.
5. Сразу помечайте найденные ячейки как посещённые, чтобы не добавлять их в стек повторно.
6. Итеративный DFS позволяет избежать переполнения стека рекурсии.
7. Визуализация помогает увидеть, какие острова алгоритм объединяет в группы и почему они считаются закрытыми или открытыми.

**Итоговые ответы:** пример 1 — `2`, пример 2 — `1`, пример 3 — `2`.
