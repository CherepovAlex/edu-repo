# Задача 35. Поиск позиции вставки (Search Insert Position)

## 📋 Условие задачи

Дан **отсортированный** массив различных целых чисел и целевое значение. Верните индекс, если целевое значение найдено. Если нет, верните индекс, на котором оно находилось бы, если бы было вставлено в порядке следования.

Требуется написать алгоритм со сложностью **O(log n)**.

### Примеры

**Пример 1:**
```
Входные данные: nums = [1,3,5,6], target = 5
Результат: 2
```

**Пример 2:**
```
Входные данные: nums = [1,3,5,6], target = 2
Результат: 1
```

**Пример 3:**
```
Входные данные: nums = [1,3,5,6], target = 7
Результат: 4
```

### Ограничения

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` содержит отдельные значения, отсортированные по возрастанию
- `-10^4 <= target <= 10^4`

---

## 💡 Разбор задачи

Нам дан **отсортированный** массив уникальных целых чисел. Нужно найти:

- индекс `target`, если он есть в массиве;
- индекс, куда его нужно вставить, чтобы порядок сохранился, если его нет.

Ключевое требование — **O(log n)**, а значит обычный линейный поиск не подходит. Нужен **бинарный поиск**.

### Идея бинарного поиска для этой задачи

Заведём два указателя `left = 0` и `right = nums.length - 1`. На каждом шаге смотрим в середину `mid`. Далее:

- если `nums[mid] == target` → ответ найден, возвращаем `mid`;
- если `nums[mid] < target` → искомое значение правее, двигаем `left = mid + 1`;
- если `nums[mid] > target` → искомое значение левее, двигаем `right = mid - 1`.

Когда цикл завершается (`left > right`), указатель `left` как раз указывает на **позицию вставки**: все элементы слева от `left` меньше `target`, а все элементы начиная с `left` — больше `target`. Возвращаем `left`.

### Сложность

| Параметр | Значение | Объяснение |
|----------|----------|------------|
| Время    | **O(log n)** | На каждом шаге диапазон сокращается вдвое |
| Память   | **O(1)**     | Используются только три целочисленные переменные |

## 💻 Код с комментариями к каждой строке

```java
public class Solution1 {
    // Метод, который решает задачу: возвращает индекс target или позицию вставки
    public int searchInsert(int[] nums, int target) {
        // Левый указатель — начало рассматриваемого диапазона массива
        int left = 0;
        // Правый указатель — конец рассматриваемого диапазона массива (включительно)
        int right = nums.length - 1;

        // Пока диапазон не сузился до пустого (left <= right означает, что ещё есть что смотреть)
        while (left <= right) {
            // Вычисляем середину так, чтобы избежать переполнения int:
            // left + (right - left) / 2 эквивалентно (left + right) / 2, но безопаснее
            int mid = left + (right - left) / 2;

            // Если элемент в середине равен target — нашли, возвращаем его индекс
            if (nums[mid] == target) {
                return mid;
            // Если элемент в середине меньше target — искомое значение находится правее
            } else if (nums[mid] < target) {
                // Сужаем диапазон, сдвигая левую границу за середину
                left = mid + 1;
            // Иначе элемент в середине больше target — искомое значение левее
            } else {
                // Сужаем диапазон, сдвигая правую границу перед серединой
                right = mid - 1;
            }
        }
        // Цикл завершился: left > right.
        // В этот момент left указывает на позицию, куда нужно вставить target,
        // чтобы сохранить отсортированный порядок. Возвращаем её.
        return left;
    }

    // Точка входа для локального запуска и проверки примеров
    public static void main(String[] args) {
        // Создаём экземпляр класса, чтобы вызывать нестатический метод searchInsert
        Solution1 solution = new Solution1();

        // Пример 1: nums = [1,3,5,6], target = 5 — ожидаем 2
        int[] nums1 = {1, 3, 5, 6};
        // Вызываем метод и печатаем результат
        System.out.println(solution.searchInsert(nums1, 5)); // 2

        // Пример 2: nums = [1,3,5,6], target = 2 — ожидаем 1
        int[] nums2 = {1, 3, 5, 6};
        // Вызываем метод и печатаем результат
        System.out.println(solution.searchInsert(nums2, 2)); // 1

        // Пример 3: nums = [1,3,5,6], target = 7 — ожидаем 4
        int[] nums3 = {1, 3, 5, 6};
        // Вызываем метод и печатаем результат
        System.out.println(solution.searchInsert(nums3, 7)); // 4
    }
}
```

## 🔍 Пошаговый разбор каждого примера

### Пример 1: `nums = [1, 3, 5, 6]`, `target = 5`

Инициализация: `left = 0`, `right = 3`.

| Шаг | left | right | mid | nums[mid] | Сравнение с target=5 | Действие |
|-----|------|-------|-----|-----------|----------------------|----------|
| 1 | 0 | 3 | 1 | 3 | 3 < 5 | `left = mid + 1 = 2` |
| 2 | 2 | 3 | 2 | 5 | 5 == 5 | **возвращаем 2** |

**Ответ: 2** ✅

---

### Пример 2: `nums = [1, 3, 5, 6]`, `target = 2`

Инициализация: `left = 0`, `right = 3`.

| Шаг | left | right | mid | nums[mid] | Сравнение с target=2 | Действие |
|-----|------|-------|-----|-----------|----------------------|----------|
| 1 | 0 | 3 | 1 | 3 | 3 > 2 | `right = mid - 1 = 0` |
| 2 | 0 | 0 | 0 | 1 | 1 < 2 | `left = mid + 1 = 1` |
| 3 | 1 | 0 | — | — | `left > right` → цикл завершён | возвращаем `left = 1` |

Проверка логики: `2` больше `nums[0] = 1` и меньше `nums[1] = 3`, значит его место — индекс 1.

**Ответ: 1** ✅

---

### Пример 3: `nums = [1, 3, 5, 6]`, `target = 7`

Инициализация: `left = 0`, `right = 3`.

| Шаг | left | right | mid | nums[mid] | Сравнение с target=7 | Действие |
|-----|------|-------|-----|-----------|----------------------|----------|
| 1 | 0 | 3 | 1 | 3 | 3 < 7 | `left = mid + 1 = 2` |
| 2 | 2 | 3 | 2 | 5 | 5 < 7 | `left = mid + 1 = 3` |
| 3 | 3 | 3 | 3 | 6 | 6 < 7 | `left = mid + 1 = 4` |
| 4 | 4 | 3 | — | — | `left > right` → цикл завершён | возвращаем `left = 4` |

Проверка логики: `7` больше всех элементов массива, значит его место — после последнего элемента, индекс 4 (длина массива).

**Ответ: 4** ✅

---

## ✅ Итог

- Алгоритм — классический **бинарный поиск**.
- Время: **O(log n)** — на каждом шаге диапазон сокращается вдвое.
- Память: **O(1)** — используются только три целочисленные переменные.
- Ключевой момент: после выхода из цикла `left` всегда указывает на корректную позицию вставки — это свойство бинарного поиска, и его не нужно обрабатывать отдельным случаем.

## 📝 Дополнительно: пограничные случаи

| Случай | Пример | Результат | Почему |
|--------|--------|-----------|--------|
| Массив из 1 элемента, target совпадает | `nums = [1]`, `target = 1` | `0` | Найдено на первом шаге |
| Массив из 1 элемента, target меньше | `nums = [1]`, `target = 0` | `0` | Вставляем перед первым элементом |
| Массив из 1 элемента, target больше | `nums = [1]`, `target = 2` | `1` | Вставляем после последнего элемента |
| Target меньше всех | `nums = [1,3,5,6]`, `target = 0` | `0` | `right` уходит в `-1`, возвращаем `left = 0` |
| Target больше всех | `nums = [1,3,5,6]`, `target = 10` | `4` | `left` выходит за границу, равняется длине массива |
