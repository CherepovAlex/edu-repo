# LeetCode 35. Search Insert Position

> **Курс:** Java Разработка  
> **Тема:** Бинарный поиск (Binary Search)  
> **Сложность:** Легкая (Easy)  
> **Требования к сложности:** O(log n) по времени, O(1) по памяти

## Описание задачи

Дан отсортированный массив различных целых чисел `nums` и целевое значение `target`.  
Необходимо вернуть индекс, если `target` найден в массиве.  
Если `target` не найден, вернуть индекс, на котором он должен быть вставлен, чтобы сохранить порядок сортировки массива.

**Ограничения:**
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` содержит уникальные значения, отсортированные по возрастанию.
- `-10^4 <= target <= 10^4`

## Почему O(log n)?

Условие задачи требует алгоритмической сложности **O(log n)**.  
Линейный поиск (`for` цикл) имеет сложность O(n), что не удовлетворяет требованиям.  
Следовательно, необходимо использовать **бинарный поиск**, который на каждом шаге сокращает область поиска в два раза.

---

## Алгоритм решения

Мы используем два указателя: `left` (начало диапазона) и `right` (конец диапазона).

1. **Инициализация:**
   - `left = 0`
   - `right = nums.length - 1`

2. **Цикл бинарного поиска (`while left <= right`):**
   - Вычисляем середину: `mid = left + (right - left) / 2`.  
     *(Использование `left + (right - left) / 2` предотвращает переполнение integer при больших значениях индексов, хотя для данной задачи это не критично, но является хорошей практикой).*
   - **Сравнение:**
     - Если `nums[mid] == target`: Элемент найден. Возвращаем `mid`.
     - Если `nums[mid] < target`: Целевое значение больше среднего. Ищем в правой половине.  
       Обновляем: `left = mid + 1`.
     - Если `nums[mid] > target`: Целевое значение меньше среднего. Ищем в левой половине.  
       Обновляем: `right = mid - 1`.

3. **Возврат результата:**
   - Если цикл завершился, это означает, что `target` не найден.
   - В этот момент `left` указывает на индекс, куда нужно вставить `target`.
   - **Почему `left`?**  
     Когда цикл останавливается, условие `left <= right` становится ложным, то есть `left > right`.  
     Переменная `left` всегда смещается вправо, когда мы ищем элементы, большие текущего `mid`. Таким образом, `left` останавливается на первой позиции, где элемент массива больше `target`. Это и есть корректная позиция для вставки.

## Код решения (Java)

```java
public class Solution1 {

    /**
     * Находит индекс, на который нужно вставить target в отсортированный массив nums.
     * Если target уже есть в массиве, возвращает его индекс.
     *
     * @param nums   Отсортированный массив уникальных целых чисел.
     * @param target Целевое значение для поиска или вставки.
     * @return Индекс элемента или позиция для вставки.
     *         Сложность: O(log n) по времени, O(1) по памяти.
     */
    public int searchInsert(int[] nums, int target) {
        // Инициализируем левый указатель на начало массива (индекс 0)
        int left = 0;
        
        // Инициализируем правый указатель на конец массива (последний индекс)
        int right = nums.length - 1;

        // Цикл выполняется, пока левый указатель не станет больше правого
        // Это означает, что диапазон поиска пуст
        while (left <= right) {
            // Находим середину диапазона.
            // Формула left + (right - left) / 2 безопаснее от переполнения, чем (left + right) / 2
            int mid = left + (right - left) / 2;

            // Если элемент в середине равен целевому, мы нашли его!
            if (nums[mid] == target) {
                return mid; // Возвращаем индекс найденного элемента
            }
            // Если элемент в середине меньше целевого, ищем в правой половине
            else if (nums[mid] < target) {
                left = mid + 1; // Сдвигаем левую границу вправо от mid
            }
            // Если элемент в середине больше целевого, ищем в левой половине
            else {
                right = mid - 1; // Сдвигаем правую границу влево от mid
            }
        }

        // Если цикл завершился, значит target не найден.
        // В этот момент left указывает на позицию вставки.
        // left > right, и left является первым индексом, где nums[left] > target.
        return left;
    }

    public static void main(String[] args) {
        Solution1 solution = new Solution1();

        // Пример 1: Target найден в массиве
        int[] nums1 = {1, 3, 5, 6};
        int target1 = 5;
        System.out.println("Пример 1: " + solution.searchInsert(nums1, target1)); 
        // Ожидается: 2

        // Пример 2: Target не найден, нужно вставить между 1 и 3
        int[] nums2 = {1, 3, 5, 6};
        int target2 = 2;
        System.out.println("Пример 2: " + solution.searchInsert(nums2, target2)); 
        // Ожидается: 1

        // Пример 3: Target больше всех элементов, вставка в конец
        int[] nums3 = {1, 3, 5, 6};
        int target3 = 7;
        System.out.println("Пример 3: " + solution.searchInsert(nums3, target3)); 
        // Ожидается: 4
    }
}
```

## Пошаговый разбор примеров

Ниже приведена таблица выполнения алгоритма для каждого примера.

### Пример 1: `nums = [1, 3, 5, 6]`, `target = 5`

| Шаг | `left` | `right` | `mid` | `nums[mid]` | Сравнение | Действие |
|:---:|:------:|:-------:|:-----:|:-----------:|:---------:|:--------:|
| 1   | 0      | 3       | 1     | `3`         | `3 < 5`   | `left = 1 + 1 = 2` |
| 2   | 2      | 3       | 2     | `5`         | `5 == 5`  | **Найден!** Возвращаем `2` |

**Результат:** `2`

---

### Пример 2: `nums = [1, 3, 5, 6]`, `target = 2`

| Шаг | `left` | `right` | `mid` | `nums[mid]` | Сравнение | Действие |
|:---:|:------:|:-------:|:-----:|:-----------:|:---------:|:--------:|
| 1   | 0      | 3       | 1     | `3`         | `3 > 2`   | `right = 1 - 1 = 0` |
| 2   | 0      | 0       | 0     | `1`         | `1 < 2`   | `left = 0 + 1 = 1` |
| 3   | 1      | 0       | -     | -           | `left > right` | Цикл завершается |

Цикл остановился, так как `left (1) > right (0)`.  
Мы возвращаем `left`, который равен `1`.  
Это правильный индекс, так как `2` должен вставиться между `1` (индекс 0) и `3` (индекс 1).

**Результат:** `1`

---

### Пример 3: `nums = [1, 3, 5, 6]`, `target = 7`

| Шаг | `left` | `right` | `mid` | `nums[mid]` | Сравнение | Действие |
|:---:|:------:|:-------:|:-----:|:-----------:|:---------:|:--------:|
| 1   | 0      | 3       | 1     | `3`         | `3 < 7`   | `left = 1 + 1 = 2` |
| 2   | 2      | 3       | 2     | `5`         | `5 < 7`   | `left = 2 + 1 = 3` |
| 3   | 3      | 3       | 3     | `6`         | `6 < 7`   | `left = 3 + 1 = 4` |
| 4   | 4      | 3       | -     | -           | `left > right` | Цикл завершается |

Цикл остановился, так как `left (4) > right (3)`.  
Мы возвращаем `left`, который равен `4`.  
Это правильный индекс, так как `7` больше всех элементов в массиве, и его нужно вставить в конец (после индекса 3).

**Результат:** `4`

## Анализ сложности

- **Время:** **O(log n)**  
  На каждой итерации цикла диапазон поиска сокращается вдвое. Для массива из $N$ элементов требуется не более $\log_2 N$ итераций.

- **Пространство:** **O(1)**  
  Мы используем фиксированное количество переменных (`left`, `right`, `mid`), независимо от размера входного массива. Дополнительные структуры данных не создаются.
