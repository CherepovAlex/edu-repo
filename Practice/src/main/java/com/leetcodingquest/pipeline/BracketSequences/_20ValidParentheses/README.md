## 1. Условие задачи

**LeetCode №20 — Valid Parentheses (Допустимые скобки).**

Дана строка `s`, содержащая только следующие символы:

- `(` — открывающая круглая скобка;
- `)` — закрывающая круглая скобка;
- `[` — открывающая квадратная скобка;
- `]` — закрывающая квадратная скобка;
- `{` — открывающая фигурная скобка;
- `}` — закрывающая фигурная скобка.

Необходимо определить, является ли входная строка допустимой.

Строка является допустимой, если выполняются все три условия:

1. Каждая открывающая скобка закрывается скобкой того же типа.
2. Скобки закрываются в правильном порядке.
3. Каждой закрывающей скобке соответствует открывающая скобка.

Если строка допустима, метод должен вернуть `true`. В противном случае метод должен вернуть `false`.

### Ограничения

- `1 <= s.length <= 10^4`.
- Строка `s` содержит только символы `()[]{}`.

### Сигнатура метода

```java
public boolean isValid(String s)
```

Метод получает строку и возвращает логическое значение `boolean`.

## 3. Объяснение задачи простыми словами

Представим, что мы проверяем правильность расстановки скобок в математическом выражении.

Например:

```text
(2 + 3) * [4 - 1]
```

Скобки расставлены правильно: каждая открывающая скобка имеет соответствующую закрывающую.

Теперь рассмотрим строку:

```text
([)]
```

В ней присутствуют две открывающие и две закрывающие скобки. Однако строка неправильная, потому что скобки закрываются не в том порядке.

Главное правило:

**Последняя открывающая скобка должна закрываться первой.**

Если мы открыли круглую скобку, а затем внутри неё квадратную, то сначала нужно закрыть квадратную, а уже потом круглую.

Правильно:

```text
([])
```

Неправильно:

```text
([)]
```

Именно это правило позволяет эффективно решить задачу с помощью стека.

## 4. Идея решения

Для решения используем следующий алгоритм.

1. Создаём пустой стек для хранения открывающих скобок.
2. Перебираем строку слева направо.
3. Если встречаем открывающую скобку, добавляем её в стек.
4. Если встречаем закрывающую скобку:
   - проверяем, пуст ли стек;
   - если стек пуст, возвращаем `false`;
   - если стек не пуст, проверяем верхнюю открывающую скобку;
   - если типы не совпадают, возвращаем `false`;
   - если типы совпадают, удаляем открывающую скобку из стека.
5. После обработки всей строки проверяем стек:
   - если стек пуст, возвращаем `true`;
   - если стек не пуст, возвращаем `false`.

### Алгоритм в виде псевдокода

```text
Создать пустой стек

Для каждого символа строки:
    Если символ — открывающая скобка:
        Добавить символ в стек
    Иначе:
        Если стек пуст:
            Вернуть false

        Посмотреть верхний элемент стека

        Если тип скобок не совпадает:
            Вернуть false

        Удалить верхний элемент стека

Если стек пуст:
    Вернуть true
Иначе:
    Вернуть false
```

Обрати внимание: мы не пытаемся искать подходящую открывающую скобку где-то внутри стека. Проверяется именно его вершина.

---

## 5. Почему используем стек

Стек — это структура данных, которая работает по принципу **LIFO (Last In, First Out)**.

Перевод: «последним пришёл — первым вышел».

Представим стопку тарелок. Если мы кладём тарелки одну на другую, то последнюю положенную тарелку снимаем первой.

Со скобками работает такой же принцип.

Рассмотрим строку:

```text
([])
```

Последовательность действий:

1. Встречаем `(` — кладём в стек.
2. Встречаем `[` — кладём поверх `(`.
3. Встречаем `]` — проверяем верхушку стека, удаляем `[`.
4. Встречаем `)` — проверяем верхушку стека, удаляем `(`.
5. Стек пуст — строка допустима.

Состояние стека можно представить так:

| Обработанный символ | Содержимое стека | Действие |
|---|---|---|
| Начало | Пусто | Создали стек |
| `(` | `(` | Добавили круглую скобку |
| `[` | `([` | Добавили квадратную скобку |
| `]` | `(` | Удалили квадратную скобку |
| `)` | Пусто | Удалили круглую скобку |

Таким образом, стек позволяет запомнить, какие скобки ещё не закрыты и в каком порядке они должны закрываться.

## 6. Решение на Java

Для реализации стека используем `Deque<Character>` с реализацией `ArrayDeque`.

Это стандартный и эффективный подход для данной задачи.

### Полный код `Solution.java`

```java
import java.util.ArrayDeque; // Импортируем реализацию стека ArrayDeque.
import java.util.Deque;      // Импортируем интерфейс Deque для работы со стеком.

class Solution { // Объявляем класс решения для LeetCode.

    public boolean isValid(String s) { // Создаём метод, который проверяет допустимость строки.
        Deque<Character> stack = new ArrayDeque<>(); // Создаём пустой стек для открывающих скобок.

        for (int i = 0; i < s.length(); i++) { // Перебираем все символы строки слева направо.
            char current = s.charAt(i); // Получаем текущий символ строки по индексу i.

            if (current == '(' || current == '[' || current == '{') { // Проверяем, является ли символ открывающей скобкой.
                stack.push(current); // Добавляем открывающую скобку на вершину стека.
            } else { // Если символ не открывающий, значит, это закрывающая скобка.
                if (stack.isEmpty()) { // Проверяем, есть ли открывающая скобка для текущей закрывающей.
                    return false; // Если стек пуст, закрывающая скобка лишняя.
                } // Завершаем проверку пустого стека.

                char top = stack.peek(); // Получаем верхнюю скобку, не удаляя её из стека.

                if (current == ')' && top != '(') { // Проверяем, соответствует ли ) открывающей (.
                    return false; // Если типы не совпадают, строка недопустима.
                } // Завершаем проверку круглых скобок.

                if (current == ']' && top != '[') { // Проверяем, соответствует ли ] открывающей [.
                    return false; // Если типы не совпадают, строка недопустима.
                } // Завершаем проверку квадратных скобок.

                if (current == '}' && top != '{') { // Проверяем, соответствует ли } открывающей {.
                    return false; // Если типы не совпадают, строка недопустима.
                } // Завершаем проверку фигурных скобок.

                stack.pop(); // Удаляем верхнюю открывающую скобку после успешной проверки.
            } // Завершаем обработку текущего символа.
        } // Завершаем перебор символов строки.

        return stack.isEmpty(); // Возвращаем true, если все открывающие скобки закрыты.
    } // Завершаем метод isValid.
} // Завершаем класс Solution.
```

**Важно:** для отправки решения на LeetCode достаточно класса `Solution` с методом `isValid`. Метод `main` не требуется, поскольку платформа самостоятельно вызывает решение.

## 7. Подробный разбор кода

### 7.1. Импорт библиотек

```java
import java.util.ArrayDeque;
import java.util.Deque;
```

`Deque` — интерфейс, который позволяет добавлять и удалять элементы с разных концов последовательности.

`ArrayDeque` — реализация этого интерфейса, которую мы используем в качестве стека.

Для нашей задачи нужны следующие методы:

| Метод | Назначение |
|---|---|
| `push(value)` | Добавляет элемент на вершину стека |
| `peek()` | Возвращает верхний элемент, не удаляя его |
| `pop()` | Удаляет и возвращает верхний элемент |
| `isEmpty()` | Проверяет, пуст ли стек |

### 7.2. Создание метода

```java
public boolean isValid(String s)
```

Метод принимает строку `s` и возвращает `boolean`.

Возможны два результата:

- `true` — скобки расставлены правильно;
- `false` — скобки расставлены неправильно.

### 7.3. Создание стека

```java
Deque<Character> stack = new ArrayDeque<>();
```

Создаём пустой стек, который будет хранить открывающие скобки.

Например, после обработки строки `([` стек будет содержать две скобки: сначала `(`, затем `[`.

Вершина стека — `[`.

### 7.4. Перебор строки

```java
for (int i = 0; i < s.length(); i++) {
    char current = s.charAt(i);
}
```

Цикл проходит по строке от первого символа до последнего.

Переменная `i` — индекс текущего символа.

В Java индексация начинается с нуля.

Например, для строки `"([])"`:

| Индекс | Символ |
|---:|:---:|
| 0 | `(` |
| 1 | `[` |
| 2 | `]` |
| 3 | `)` |

Команда `s.charAt(i)` возвращает символ, расположенный по индексу `i`.

### 7.5. Обработка открывающих скобок

```java
if (current == '(' || current == '[' || current == '{') {
    stack.push(current);
}
```

Проверяем, является ли текущий символ открывающей скобкой.

Оператор `||` означает логическое «ИЛИ».

Если выполняется хотя бы одно из условий, символ добавляется в стек.

Например, при обработке `[` выполняется:

```java
stack.push('[');
```

Квадратная скобка помещается на вершину стека.

### 7.6. Проверка пустого стека

```java
if (stack.isEmpty()) {
    return false;
}
```

Предположим, входная строка:

```text
")"
```

Первый символ — закрывающая скобка.

Но стек пуст: ни одной открывающей скобки ещё не было.

Следовательно, закрывать нечего. Строка недопустима, и метод возвращает `false`.

### 7.7. Получение вершины стека

```java
char top = stack.peek();
```

Метод `peek()` позволяет узнать, какая открывающая скобка была добавлена последней.

Например, если стек содержит:

```text
( [
```

и `[` находится на вершине, то `peek()` вернёт `'['`.

При этом стек останется без изменений.

### 7.8. Проверка соответствия типов

```java
if (current == ')' && top != '(') {
    return false;
}
```

Здесь проверяются два условия одновременно:

1. Текущий символ — закрывающая круглая скобка `)`.
2. Верхний элемент стека не является открывающей круглой скобкой `(`.

Оператор `&&` означает логическое «И».

Если оба условия истинны, мы нашли неправильную последовательность и возвращаем `false`.

Аналогично проверяются квадратные и фигурные скобки:

```java
if (current == ']' && top != '[') {
    return false;
}

if (current == '}' && top != '{') {
    return false;
}
```

### 7.9. Удаление открывающей скобки

```java
stack.pop();
```

Эта команда выполняется только после успешной проверки соответствия типов.

Например, если текущий символ — `]`, а на вершине стека находится `[`, мы удаляем `[`, поскольку пара закрыта правильно.

### 7.10. Финальная проверка

```java
return stack.isEmpty();
```

После обработки всей строки возможны два случая.

**Случай 1. Стек пуст.**

Все открывающие скобки нашли соответствующие закрывающие. Возвращаем `true`.

**Случай 2. Стек не пуст.**

В стеке остались открывающие скобки, для которых не нашлось закрывающих. Возвращаем `false`.

Например, для строки:

```text
"((("
```

после завершения цикла в стеке останутся три открывающие скобки. Поэтому результат будет `false`.

## 8. Пошаговый разбор всех пяти примеров

Для каждого примера будем отслеживать индекс символа, действие алгоритма и состояние стека.

В таблицах стек записывается от дна к вершине. Например, `([` означает, что `(` находится внизу, а `[` — на вершине.

### Пример 1. `s = "()"`

Ожидаемый результат: `true`.

Исходная строка:

```text
()
```

Изначально стек пуст.

| Шаг | Индекс | Символ | Действие | Стек после действия |
|---:|---:|:---:|---|---|
| 1 | 0 | `(` | Добавляем открывающую скобку | `(` |
| 2 | 1 | `)` | Проверяем соответствие и удаляем `(` | Пусто |

**Подробно:**

1. На индексе `0` встречаем `(`. Это открывающая скобка, поэтому добавляем её в стек.
2. На индексе `1` встречаем `)`. Стек не пуст, а на вершине находится `(`.
3. Типы совпадают. Удаляем `(` из стека.
4. Строка закончилась, стек пуст.

**Результат: `true`.**

### Пример 2. `s = "()[]{}"`

Ожидаемый результат: `true`.

Исходная строка:

```text
()[]{}
```

| Шаг | Индекс | Символ | Действие | Стек после действия |
|---:|---:|:---:|---|---|
| 1 | 0 | `(` | Добавляем круглую скобку | `(` |
| 2 | 1 | `)` | Закрываем круглую скобку | Пусто |
| 3 | 2 | `[` | Добавляем квадратную скобку | `[` |
| 4 | 3 | `]` | Закрываем квадратную скобку | Пусто |
| 5 | 4 | `{` | Добавляем фигурную скобку | `{` |
| 6 | 5 | `}` | Закрываем фигурную скобку | Пусто |

**Подробно:**

1. Символ `(` добавляется в стек.
2. Символ `)` соответствует `(`. Удаляем её.
3. Символ `[` добавляется в пустой стек.
4. Символ `]` соответствует `[`. Удаляем её.
5. Символ `{` добавляется в стек.
6. Символ `}` соответствует `{`. Удаляем её.

После каждого закрытия стек становится пустым.

**Результат: `true`.**

### Пример 3. `s = "(]"`

Ожидаемый результат: `false`.

Исходная строка:

```text
(]
```

| Шаг | Индекс | Символ | Действие | Стек после действия |
|---:|---:|:---:|---|---|
| 1 | 0 | `(` | Добавляем круглую скобку | `(` |
| 2 | 1 | `]` | Проверяем соответствие типов | `(` |

**Подробно:**

1. На индексе `0` встречаем `(` и добавляем её в стек.
2. На индексе `1` встречаем `]`.
3. Стек не пуст, поэтому получаем верхний элемент: `top = '('`.
4. Для `]` нужна открывающая скобка `[`, но в стеке находится `(`.
5. Условие `current == ']' && top != '['` истинно.
6. Метод немедленно возвращает `false`.

**Результат: `false`.**

Важно: здесь не имеет значения, что в строке есть открывающая скобка. Она должна соответствовать закрывающей скобке по типу.

### Пример 4. `s = "([])"`

Ожидаемый результат: `true`.

Исходная строка:

```text
([])
```

| Шаг | Индекс | Символ | Действие | Стек после действия |
|---:|---:|:---:|---|---|
| 1 | 0 | `(` | Добавляем круглую скобку | `(` |
| 2 | 1 | `[` | Добавляем квадратную скобку | `([` |
| 3 | 2 | `]` | Закрываем квадратную скобку | `(` |
| 4 | 3 | `)` | Закрываем круглую скобку | Пусто |

**Подробно:**

1. Символ `(` помещается в стек.
2. Символ `[` помещается поверх `(`.
3. Символ `]` закрывает последнюю открытую скобку `[`. Удаляем `[`.
4. На вершине стека снова находится `(`.
5. Символ `)` закрывает круглую скобку. Удаляем `(`.
6. Стек пуст.

**Результат: `true`.**

Этот пример показывает главное преимущество стека: мы всегда знаем, какую скобку необходимо закрыть следующей.

### Пример 5. `s = "([)]"`

Ожидаемый результат: `false`.

Исходная строка:

```text
([)]
```

| Шаг | Индекс | Символ | Действие | Стек после действия |
|---:|---:|:---:|---|---|
| 1 | 0 | `(` | Добавляем круглую скобку | `(` |
| 2 | 1 | `[` | Добавляем квадратную скобку | `([` |
| 3 | 2 | `)` | Несоответствие типов | `([` |
| 4 | 3 | `]` | Не обрабатывается | — |

**Подробно:**

1. На индексе `0` встречаем `(`. Добавляем её в стек.
2. На индексе `1` встречаем `[`. Добавляем её поверх круглой скобки.
3. На индексе `2` встречаем `)`.
4. Проверяем вершину стека: `top = '['`.
5. Для закрывающей круглой скобки `)` требуется открывающая круглая скобка `(`.
6. Но вершина стека содержит `[`.
7. Условие `current == ')' && top != '('` истинно.
8. Метод возвращает `false`. Последний символ `]` уже не обрабатывается.

Почему нельзя пропустить квадратную скобку и закрыть круглую?

Потому что это нарушило бы порядок вложенности. Сначала должна закрываться последняя открытая скобка.

**Результат: `false`.**

## 9. Дополнительные тесты

Для проверки решения полезно рассмотреть несколько других строк.

| Входная строка | Результат | Причина |
|---|---|---|
| `"("` | `false` | Осталась незакрытая скобка |
| `")"` | `false` | Закрывающая скобка без открывающей |
| `"((("` | `false` | Все три скобки остались открытыми |
| `"())"` | `false` | Последняя закрывающая скобка лишняя |
| `"{{}}"` | `true` | Обе пары фигурных скобок закрыты правильно |
| `"({[]})"` | `true` | Все вложенные скобки закрываются в правильном порядке |
| `"{[(])}"` | `false` | Нарушен порядок закрытия вложенных скобок |
| `"[][]"` | `true` | Две корректные пары квадратных скобок |

### Почему строка `"())"` недопустима?

1. `(` добавляется в стек.
2. Первый `)` закрывает `(`, стек становится пустым.
3. Второй `)` встречается при пустом стеке.
4. Метод возвращает `false`.

### Почему строка `"({[]})"` допустима?

1. `(` — добавляем.
2. `{` — добавляем.
3. `[` — добавляем.
4. `]` — удаляем `[`.
5. `}` — удаляем `{`.
6. `)` — удаляем `(`.
7. Стек пуст, поэтому результат `true`.

## 10. Доказательство корректности

Докажем, что алгоритм правильно определяет допустимость строки.

### Шаг 1. Обработка открывающих скобок

Каждая открывающая скобка добавляется в стек.

Таким образом, стек хранит все открывающие скобки, которые ещё не были закрыты, в порядке их появления.

### Шаг 2. Обработка закрывающих скобок

При встрече закрывающей скобки алгоритм проверяет вершину стека.

Возможны три ситуации:

1. **Стек пуст.** Закрывающей скобке не соответствует открывающая. Возвращаем `false`.
2. **Типы скобок не совпадают.** Строка нарушает правила вложенности. Возвращаем `false`.
3. **Типы совпадают.** Удаляем верхнюю открывающую скобку, поскольку её пара найдена.

Алгоритм не позволяет закрыть более раннюю скобку, пока не закрыта последняя открытая скобка.

### Шаг 3. Проверка после завершения цикла

После обработки всех символов:

- если стек пуст, каждая открывающая скобка была корректно закрыта;
- если стек не пуст, в строке остались незакрытые открывающие скобки.

Следовательно, алгоритм возвращает `true` тогда и только тогда, когда строка допустима.

**Вывод:** алгоритм корректен.

## 11. Оценка сложности

Обозначим длину строки через `n`.

### Временная сложность: `O(n)`

Цикл проходит по каждому символу строки не более одного раза.

Для каждого символа выполняется ограниченное число операций:

- чтение символа;
- проверка типа;
- добавление в стек;
- просмотр вершины стека;
- удаление из стека.

Операции `push`, `peek`, `pop` и `isEmpty` у `ArrayDeque` имеют амортизированную сложность `O(1)`.

Следовательно, общая временная сложность:

```text
O(n)
```

При максимальной длине строки `10 000` алгоритм обработает не более 10 000 символов.

### Пространственная сложность: `O(n)`

В худшем случае строка содержит только открывающие скобки:

```text
(((((((((
```

Каждая скобка будет добавлена в стек. Поэтому в нём может находиться до `n` элементов.

Пространственная сложность:

```text
O(n)
```

## 13. Итог

Для решения LeetCode №20 используется стек, который хранит открывающие скобки.

Основные правила алгоритма:

1. Открывающую скобку добавляем в стек.
2. При встрече закрывающей скобки проверяем вершину стека.
3. Если стек пуст или типы скобок не совпадают, возвращаем `false`.

### Что необходимо запомнить

**Стек работает по принципу LIFO: последняя открытая скобка должна закрываться первой.**

Это позволяет одновременно проверять тип скобок и правильность их вложенности.
