# LeetCode 10. Сопоставление с регулярным выражением

**Тема:** Dynamic Programming (динамическое программирование)  
**Язык:** Java  
**Уровень объяснения:** с нуля, пошагово  
**Цель:** проверить, соответствует ли вся входная строка шаблону.

---

## 1. Условие задачи

Даны две строки:

- `s` — входная строка, которую нужно проверить;
- `p` — шаблон, с которым нужно сопоставить строку.

Необходимо реализовать метод:

```java
public boolean isMatch(String s, String p)
```

Метод должен вернуть `true`, если **вся строка `s` соответствует всему шаблону `p`**, и `false` в противном случае.

Шаблон поддерживает два специальных символа:

| Символ | Значение | Пример |
|---|---|---|
| `.` | Соответствует любому одному символу | `a.c` подходит к `abc` |
| `*` | Соответствует нулю или более повторений предыдущего элемента | `a*` подходит к `""`, `"a"`, `"aa"` |

Важно: `*` повторяет именно предыдущий элемент шаблона.

- `a*` — ноль или более букв `a`;
- `b*` — ноль или более букв `b`;
- `.*` — ноль или более любых символов.

Совпадение должно охватывать всю строку, а не только её часть.

## 2. Примеры из условия

### Пример 1

```text
s = "aa"
p = "a"
Результат: false
```

Шаблон содержит только одну букву `a`, а строка — две. Первую букву можно сопоставить, но для второй буквы в шаблоне ничего не остаётся.

### Пример 2

```text
s = "aa"
p = "a*"
Результат: true
```

`a*` разрешает использовать букву `a` ноль, один или несколько раз. Поэтому он подходит к строке `"aa"`.

### Пример 3

```text
s = "ab"
p = ".*"
Результат: true
```

Точка `.` подходит к любому одному символу, а `*` позволяет повторять точку. Поэтому `.*` может описать и `a`, и `b`.

## 3. Сначала представим задачу как игру

Представим, что строка `s` — это карточки с буквами, а шаблон `p` — правила, по которым мы проверяем эти карточки.

Например:

```text
s = "aa"
p = "a"
```

В строке две буквы, а в шаблоне одна. Вторая буква остаётся без пары — результат `false`.

Но для:

```text
s = "aa"
p = "a*"
```

звёздочка разрешает повторить букву `a`. Обе буквы строки можно сопоставить шаблону, поэтому результат `true`.

А для:

```text
s = "ab"
p = ".*"
```

точка подходит к `a`, а затем ещё раз к `b`. Результат — `true`.

## 4. Что такое динамическое программирование?

Вместо того чтобы сразу отвечать на большой вопрос «Совпадает ли вся строка со всем шаблоном?», будем отвечать на маленькие вопросы:

- Совпадает ли пустая строка с пустым шаблоном?
- Совпадает ли строка `"a"` с шаблоном `"a"`?
- Совпадает ли строка `"aa"` с шаблоном `"a*"`?

Ответы на маленькие вопросы помогут получить ответ на исходную задачу.

Обозначим:

- `m` — длина строки `s`;
- `n` — длина шаблона `p`;
- `dp[i][j]` — соответствует ли первые `i` символов строки первым `j` символам шаблона.

Индексы `i` и `j` — это количества символов, а не индексы конкретных букв. Поэтому `dp[0][0]` означает сравнение двух пустых строк.

### Самая первая ситуация

Пустая строка соответствует пустому шаблону:

```text
s = ""
p = ""
```

Ответ — `true`, поэтому:

```java
dp[0][0] = true;
```

Но непустая строка не может соответствовать пустому шаблону:

```text
s = "a"
p = ""
```

Ответ — `false`.

## 5. Три правила для заполнения таблицы

### Правило 1. Пустая строка и шаблон со звёздочками

Некоторые шаблоны могут соответствовать пустой строке. Например, `a*`: букву `a` можно использовать ноль раз.

Если последний символ шаблона — `*`, можно пропустить и звёздочку, и элемент перед ней:

```java
dp[0][j] = dp[0][j - 2];
```

Например, `a*` соответствует пустой строке, а `ab*` также может соответствовать строке `"a"`: часть `b*` используется ноль раз.

### Правило 2. Обычная буква или точка

Если текущий символ шаблона — обычная буква или точка, нужны два условия одновременно:

1. Символы подходят друг к другу: они одинаковые или символ шаблона — `.`;
2. Предыдущие части строки и шаблона уже совпадали.

Формула:

```text
dp[i][j] = matches && dp[i - 1][j - 1]
```

Здесь `matches` — подходит ли текущий символ строки к текущему символу шаблона.

Например, строка `"a"` подходит к шаблону `"a"`, потому что символы одинаковые и пустые предыдущие части также совпадают.

### Правило 3. Если текущий символ шаблона — `*`

Для `*` рассматриваем два варианта.

**Вариант A: использовать предыдущий элемент ноль раз.**

Пропускаем предыдущий элемент и `*`:

```java
dp[i][j] = dp[i][j - 2];
```

Например, `a*` может соответствовать пустой строке.

**Вариант B: использовать предыдущий элемент ещё раз.**

Это возможно, если текущий символ строки подходит к элементу перед `*`, а шаблон с этим `*` уже соответствовал строке без последнего символа:

```java
dp[i][j] = matches && dp[i - 1][j];
```

В итоге объединяем оба варианта:

```java
dp[i][j] = dp[i][j - 2]
        || (matches && dp[i - 1][j]);
```

Знак `||` означает «ИЛИ»: достаточно, чтобы сработал хотя бы один вариант.

## 6. Полное решение на Java — двумерная таблица

Сначала разберём самый наглядный вариант. Он использует таблицу `dp`, в которой видны все промежуточные результаты. Для обучения это хороший способ понять переходы алгоритма.

```java
class Solution { // Объявляем класс решения для LeetCode.

    public boolean isMatch(String s, String p) { // Проверяем, соответствует ли вся строка шаблону.
        int m = s.length(); // Сохраняем длину входной строки.
        int n = p.length(); // Сохраняем длину шаблона.

        boolean[][] dp = new boolean[m + 1][n + 1]; // Создаём таблицу для всех префиксов строки и шаблона.
        dp[0][0] = true; // Пустая строка соответствует пустому шаблону.

        for (int j = 2; j <= n; j++) { // Рассматриваем шаблоны, которые могут соответствовать пустой строке.
            if (p.charAt(j - 1) == '*') { // Если текущий символ шаблона — звёздочка.
                dp[0][j] = dp[0][j - 2]; // Пропускаем предыдущий элемент и звёздочку, то есть используем элемент ноль раз.
            }
        }

        for (int i = 1; i <= m; i++) { // Перебираем префиксы входной строки от одного символа до всей строки.
            for (int j = 1; j <= n; j++) { // Перебираем префиксы шаблона от одного символа до всего шаблона.
                char currentString = s.charAt(i - 1); // Получаем последний символ рассматриваемого префикса строки.
                char currentPattern = p.charAt(j - 1); // Получаем последний символ рассматриваемого префикса шаблона.

                if (currentPattern == '*') { // Если последний символ шаблона — звёздочка.
                    char previousPattern = p.charAt(j - 2); // Получаем элемент, который может повторяться.

                    boolean matches = previousPattern == '.' // Точка перед звёздочкой подходит к любому символу.
                            || previousPattern == currentString; // Обычная буква перед звёздочкой должна совпасть с символом строки.

                    dp[i][j] = dp[i][j - 2] // Вариант 1: использовать элемент перед звёздочкой ноль раз.
                            || (matches && dp[i - 1][j]); // Вариант 2: повторить элемент, если он подходит к текущему символу.
                } else { // Если текущий символ шаблона — обычная буква или точка.
                    boolean matches = currentPattern == '.' // Точка соответствует любому одному символу.
                            || currentPattern == currentString; // Обычные символы должны совпадать.

                    dp[i][j] = matches && dp[i - 1][j - 1]; // Символы должны подходить, а предыдущие части — совпадать.
                }
            }
        }

        return dp[m][n]; // Возвращаем ответ для всей строки и всего шаблона.
    }
}
```

### Как читать двумерную таблицу?

- `dp[i][j]` — ответ для первых `i` символов строки и первых `j` символов шаблона.
- `dp[i - 1][j - 1]` — ответ для частей, из которых убрали по одному последнему символу.
- `dp[i][j - 2]` — ответ, если пропустить предыдущий элемент шаблона и звёздочку.
- `dp[i - 1][j]` — ответ для строки без последнего символа, но с тем же шаблоном.

Этот вариант использует больше памяти, но его проще изучать. Далее рассмотрим, как уменьшить расход памяти.

## 7. Пошаговый разбор примера 1

Входные данные:

```text
s = "aa"
p = "a"
```

Ожидаемый результат: `false`.

Длина строки `m = 2`, длина шаблона `n = 1`. Таблица имеет 3 строки и 2 столбца: учитываем также пустые префиксы.

### Шаг 1. Инициализация

Начинаем с таблицы:

| `s \ p` | `""` | `"a"` |
|---|---:|---:|
| `""` | `true` | `false` |
| `"a"` | `false` | `false` |
| `"aa"` | `false` | `false` |

На этом этапе известен только ответ `dp[0][0] = true`. Остальные ячейки пока равны `false`.

### Шаг 2. Сравниваем `"a"` с `"a"`

Текущие символы — `a` и `a`. Они одинаковые, поэтому `matches = true`.

Предыдущие части — пустая строка и пустой шаблон — совпадают: `dp[0][0] = true`.

Получаем:

```text
dp[1][1] = true && true = true
```

Теперь строка `"a"` соответствует шаблону `"a"`.

### Шаг 3. Сравниваем `"aa"` с `"a"`

Последние символы снова совпадают, поэтому `matches = true`.

Но теперь предыдущая часть строки — `"a"`, а предыдущая часть шаблона — пустой шаблон. Они не совпадают: `dp[1][0] = false`.

Получаем:

```text
dp[2][1] = true && false = false
```

Итоговая таблица:

| `s \ p` | `""` | `"a"` |
|---|---:|---:|
| `""` | `true` | `false` |
| `"a"` | `false` | `true` |
| `"aa"` | `false` | `false` |

Возвращаем `dp[2][1]`, то есть `false`.

**Вывод:** шаблон `a` не может сопоставить две буквы `a`, потому что в нём нет звёздочки.

## 8. Пошаговый разбор примера 2

Входные данные:

```text
s = "aa"
p = "a*"
```

Ожидаемый результат: `true`.

Длина строки `m = 2`, длина шаблона `n = 2`.

### Шаг 1. Инициализация

Сначала:

```text
dp[0][0] = true
```

Шаблон `a*` может соответствовать пустой строке, потому что `a` разрешено использовать ноль раз:

```text
dp[0][2] = dp[0][0] = true
```

Начальная таблица:

| `s \ p` | `""` | `"a"` | `"a*"` |
|---|---:|---:|---:|
| `""` | `true` | `false` | `true` |
| `"a"` | `false` | `false` | `false` |
| `"aa"` | `false` | `false` | `false` |

### Шаг 2. Обрабатываем строку `"a"`

**Сначала шаблон `"a"`:**

- Символы `a` и `a` совпадают.
- Пустые предыдущие части совпадают.

Поэтому:

```text
dp[1][1] = true
```

**Теперь шаблон `"a*"`:**

Последний символ шаблона — `*`, предыдущий — `a`. Текущая буква строки тоже `a`.

Проверяем два варианта:

1. Ноль повторений: `dp[1][0] = false`.
2. Повторение: `matches && dp[0][2] = true && true = true`.

Объединяем:

```text
dp[1][2] = false || true = true
```

Строка `"a"` соответствует `a*`.

### Шаг 3. Обрабатываем строку `"aa"`

**Сначала шаблон `"a"`:**

Последние буквы совпадают, но строка без последней буквы — `"a"` — не соответствует пустому шаблону.

Поэтому:

```text
dp[2][1] = true && false = false
```

**Теперь шаблон `"a*"`:**

Текущая буква строки — `a`, и элемент перед `*` — тоже `a`.

Снова два варианта:

1. Ноль повторений: `dp[2][0] = false`.
2. Повторение: `matches && dp[1][2] = true && true = true`.

Следовательно:

```text
dp[2][2] = false || true = true
```

Итоговая таблица:

| `s \ p` | `""` | `"a"` | `"a*"` |
|---|---:|---:|---:|
| `""` | `true` | `false` | `true` |
| `"a"` | `false` | `true` | `true` |
| `"aa"` | `false` | `false` | `true` |

Возвращаем `dp[2][2]`, то есть `true`.

**Вывод:** звёздочка позволяет использовать букву `a` несколько раз.

## 9. Пошаговый разбор примера 3

Входные данные:

```text
s = "ab"
p = ".*"
```

Ожидаемый результат: `true`.

### Шаг 1. Инициализация

Пустая строка соответствует пустому шаблону:

```text
dp[0][0] = true
```

Шаблон `.*` может соответствовать пустой строке, потому что точка используется ноль раз:

```text
dp[0][2] = dp[0][0] = true
```

Начальная таблица:

| `s \ p` | `""` | `"."` | `".*"` |
|---|---:|---:|---:|
| `""` | `true` | `false` | `true` |
| `"a"` | `false` | `false` | `false` |
| `"ab"` | `false` | `false` | `false` |

### Шаг 2. Обрабатываем символ `a`

**Шаблон `"."`:**

Точка соответствует любому символу, поэтому она подходит к `a`. Предыдущие пустые части совпадают.

```text
dp[1][1] = true
```

**Шаблон `".*"`:**

Перед звёздочкой стоит точка. Точка подходит к `a`.

- Ноль повторений: `dp[1][0] = false`.
- Повторение: `matches && dp[0][2] = true && true = true`.

Получаем:

```text
dp[1][2] = true
```

### Шаг 3. Обрабатываем символ `b`

**Шаблон `"."`:**

Точка подходит к `b`, но одной точки недостаточно, чтобы сопоставить всю строку `"ab"`.

```text
dp[2][1] = true && false = false
```

**Шаблон `".*"`:**

Точка перед звёздочкой подходит к `b`.

- Ноль повторений: `dp[2][0] = false`.
- Повторение: `matches && dp[1][2] = true && true = true`.

Получаем:

```text
dp[2][2] = true
```

Итоговая таблица:

| `s \ p` | `""` | `"."` | `".*"` |
|---|---:|---:|---:|
| `""` | `true` | `false` | `true` |
| `"a"` | `false` | `true` | `true` |
| `"ab"` | `false` | `false` | `true` |

Возвращаем `dp[2][2]`, то есть `true`.

**Вывод:** точка подходит к любой букве, а звёздочка разрешает повторить точку для следующей буквы.

## 10. Как уменьшить потребление памяти

Двумерная таблица `dp[m + 1][n + 1]` проста для понимания, но хранит все промежуточные результаты. На каждом шаге алгоритму нужны только значения из предыдущей строки таблицы и уже обработанные значения текущей строки.

Поэтому можно хранить только один массив:

```java
boolean[] dp = new boolean[n + 1];
```

Это уменьшает дополнительную память с `O(m * n)` до `O(n)`.

Но нужно сохранить значения, которые мы собираемся перезаписать. Для этого используем две переменные:

- `up` — старое значение текущей ячейки `dp[j]`;
- `diagonal` — старое значение ячейки, которая находилась слева и выше в двумерной таблице.

### Оптимизированный код на Java

```java
class Solution { // Объявляем класс решения для LeetCode.

    public boolean isMatch(String s, String p) { // Проверяем полное совпадение строки и шаблона.
        int m = s.length(); // Сохраняем длину входной строки.
        int n = p.length(); // Сохраняем длину шаблона.

        boolean[] dp = new boolean[n + 1]; // Храним результаты для префиксов шаблона в одном массиве.
        dp[0] = true; // Пустая строка соответствует пустому шаблону.

        for (int j = 2; j <= n; j++) { // Проверяем, какие части шаблона могут соответствовать пустой строке.
            if (p.charAt(j - 1) == '*') { // Если текущий символ шаблона — звёздочка.
                dp[j] = dp[j - 2]; // Пропускаем предыдущий элемент и звёздочку.
            }
        }

        for (int i = 1; i <= m; i++) { // Последовательно добавляем символы входной строки.
            boolean diagonal = dp[0]; // Сохраняем старое значение для предыдущего префикса строки и пустого шаблона.
            dp[0] = false; // Непустая строка не соответствует пустому шаблону.

            for (int j = 1; j <= n; j++) { // Перебираем все непустые префиксы шаблона.
                boolean up = dp[j]; // Сохраняем старое значение ячейки до её изменения.

                char currentPattern = p.charAt(j - 1); // Получаем текущий символ шаблона.
                char currentString = s.charAt(i - 1); // Получаем текущий символ входной строки.

                if (currentPattern == '*') { // Если текущий символ шаблона — звёздочка.
                    char previousPattern = p.charAt(j - 2); // Получаем символ перед звёздочкой.

                    boolean matches = previousPattern == '.' // Точка соответствует любому одному символу.
                            || previousPattern == currentString; // Обычный символ должен совпадать с символом строки.

                    dp[j] = dp[j - 2] // Вариант: предыдущий элемент используется ноль раз.
                            || (matches && up); // Вариант: предыдущий элемент повторяется, если подходит к символу строки.
                } else { // Если текущий символ — обычная буква или точка.
                    boolean matches = currentPattern == '.' // Точка подходит к любому символу.
                            || currentPattern == currentString; // Обычные символы должны совпадать.

                    dp[j] = matches && diagonal; // Текущие символы и предыдущие части должны совпасть.
                }

                diagonal = up; // Сохраняем старое значение для следующего шага внутреннего цикла.
            }
        }

        return dp[n]; // Возвращаем результат для всей строки и всего шаблона.
    }
}
```

Этот вариант делает те же вычисления, что и двумерный, но использует меньше памяти. Если ты только изучаешь задачу, сначала разберись с двумерной таблицей, а затем возвращайся к оптимизированной версии.

## 11. Сложность алгоритма

Обозначим длину строки как `m`, а длину шаблона как `n`.

| Версия | Время | Дополнительная память |
|---|---|---|
| Двумерная таблица | `O(m * n)` | `O(m * n)` |
| Одномерный массив | `O(m * n)` | `O(n)` |

Почему время `O(m * n)`? Для каждого из `m` символов строки мы проверяем до `n` позиций шаблона.

При ограничениях задачи `m <= 20` и `n <= 20` это не более 400 основных обновлений DP в двумерной версии.

## 12. Что важно запомнить

1. `.` соответствует любому одному символу.
2. `*` означает ноль или более повторений предыдущего элемента.
3. Совпасть должна вся строка, а не только её часть.
4. Для обычного символа проверяем совпадение текущих символов и предыдущих частей.
5. Для `*` проверяем два варианта: ноль повторений или ещё одно повторение.
6. Двумерная таблица проще для обучения, а одномерный массив экономит память.

## 13. Дополнительная самостоятельная проверка

Попробуй самостоятельно определить результат для каждого случая, а затем проверить его запуском кода.

| Входная строка `s` | Шаблон `p` | Ожидаемый результат | Причина |
|---|---|---|---|
| `"ab"` | `".*"` | `true` | Точка может повторяться и соответствовать любым символам |
| `"aab"` | `"c*a*b"` | `true` | `c*` используется ноль раз, `a*` соответствует двум буквам `a`, затем совпадает `b` |
| `"mississippi"` | `"mis*is*p*."` | `false` | Нельзя сопоставить всю строку заданным шаблоном |
| `"aaa"` | `"a*a"` | `true` | `a*` может соответствовать двум `a`, последняя `a` — третьей |
| `"ab"` | `".*c"` | `false` | После любых символов шаблон требует ещё одну букву `c`, которой в строке нет |

## Итог

Мы решили задачу LeetCode 10 с помощью динамического программирования.

- **Время:** `O(m * n)`.
- **Дополнительная память оптимизированной версии:** `O(n)`.
