# LeetCode 3863 — Минимальное количество операций для сортировки строки

## Условие задачи

Дана строка `s`, состоящая из строчных букв английского алфавита.

За одну операцию можно выбрать любую **непрерывную подстроку**, которая **не совпадает со всей строкой**, и отсортировать выбранную подстроку в неубывающем алфавитном порядке.

Нужно вернуть минимальное количество операций, необходимых для сортировки всей строки. Если отсортировать строку невозможно, вернуть `-1`.

### Примеры

| Входные данные | Результат |
|---|---:|
| `s = "dog"` | `1` |
| `s = "card"` | `2` |
| `s = "gf"` | `-1` |

### Ограничения

- `1 <= s.length <= 10^5`
- `s` состоит только из строчных английских букв.

---

## Идея решения

Не нужно действительно сортировать строку. Достаточно определить:

1. Отсортирована ли строка уже.
2. Минимальный и максимальный символы строки.
3. Где находятся эти символы — на краях строки или внутри.

Обозначим:

- `n` — длина строки;
- `minChar` — минимальный символ строки;
- `maxChar` — максимальный символ строки.

В Java строчные английские буквы сравниваются в алфавитном порядке: например, `'a' < 'b' < 'c'`.

### Разбор случаев

1. **Строка уже отсортирована** — ответ `0`.
2. **Строка не отсортирована и её длина равна `2`** — ответ `-1`. Единственная подстрока длины два совпадает со всей строкой, а сортировать её запрещено. Односимвольные подстроки ничего не меняют.
3. **Первый символ — минимальный или последний символ — максимальный** — ответ `1`. Можно отсортировать оставшуюся часть строки одной операцией.
4. **Минимальный или максимальный символ находится внутри строки** — ответ `2`.
5. **Минимальный символ находится только в конце, а максимальный — только в начале** — ответ `3`.

Последний случай означает, что крайние символы стоят в противоположных крайних позициях. Для такой строки из трёх или более символов понадобится три операции.

---

## Решение на Java

```java
class Solution { // Объявляем класс решения для LeetCode.
    public int minOperations(String s) { // Возвращаем минимальное число операций.
        int n = s.length(); // Сохраняем длину строки.
        char minChar = s.charAt(0); // Изначально считаем первый символ минимальным.
        char maxChar = s.charAt(0); // Изначально считаем первый символ максимальным.
        boolean isSorted = true; // Предполагаем, что строка уже отсортирована.

        for (int i = 1; i < n; i++) { // Перебираем строку со второго символа.
            char current = s.charAt(i); // Получаем текущий символ.

            if (current < minChar) { // Проверяем, меньше ли символ текущего минимума.
                minChar = current; // Обновляем минимальный символ.
            }

            if (current > maxChar) { // Проверяем, больше ли символ текущего максимума.
                maxChar = current; // Обновляем максимальный символ.
            }

            if (current < s.charAt(i - 1)) { // Проверяем, нарушен ли порядок соседних символов.
                isSorted = false; // Запоминаем, что строка не отсортирована.
            }
        }

        if (isSorted) { // Проверяем, отсортирована ли строка.
            return 0; // Если да, операции не нужны.
        }

        if (n == 2) { // Проверяем случай строки из двух символов.
            return -1; // Нельзя отсортировать всю строку одной разрешённой операцией.
        }

        if (s.charAt(0) == minChar || s.charAt(n - 1) == maxChar) { // Проверяем правильный край.
            return 1; // Достаточно одной операции.
        }

        for (int i = 1; i < n - 1; i++) { // Проверяем символы между первым и последним.
            char current = s.charAt(i); // Получаем очередной внутренний символ.

            if (current == minChar || current == maxChar) { // Ищем минимум или максимум внутри.
                return 2; // В этом случае достаточно двух операций.
            }
        }

        return 3; // Иначе минимум только в конце, а максимум только в начале.
    }
}
```

## Подробное объяснение кода

### 1. Инициализация

```java
int n = s.length();
char minChar = s.charAt(0);
char maxChar = s.charAt(0);
boolean isSorted = true;
```

- `n` хранит длину строки.
- `minChar` хранит минимальный символ, найденный на текущий момент.
- `maxChar` хранит максимальный символ, найденный на текущий момент.
- `isSorted` показывает, отсортирована ли строка.

Минимум и максимум изначально равны первому символу, потому что остальные символы ещё не проверены.

### 2. Один проход по строке

```java
for (int i = 1; i < n; i++) {
    char current = s.charAt(i);

    if (current < minChar) {
        minChar = current;
    }

    if (current > maxChar) {
        maxChar = current;
    }

    if (current < s.charAt(i - 1)) {
        isSorted = false;
    }
}
```

На каждой итерации алгоритм:

- получает очередной символ;
- при необходимости обновляет минимум;
- при необходимости обновляет максимум;
- сравнивает текущий символ с предыдущим.

Если хотя бы один текущий символ меньше предыдущего, порядок нарушен и строка не отсортирована.

### 3. Проверка отсортированности

```java
if (isSorted) {
    return 0;
}
```

Если ни одна пара соседних символов не нарушает порядок, строка уже отсортирована. Возвращаем `0`.

### 4. Особый случай: два символа

```java
if (n == 2) {
    return -1;
}
```

Если строка из двух символов не отсортирована, единственная подстрока, содержащая оба символа, — это вся строка. Её выбирать нельзя. Сортировка подстроки из одного символа не меняет строку, поэтому решение невозможно.

### 5. Проверка крайних позиций

```java
if (s.charAt(0) == minChar || s.charAt(n - 1) == maxChar) {
    return 1;
}
```

Если минимальный символ уже стоит в начале или максимальный уже стоит в конце, достаточно отсортировать часть строки, не затрагивая этот правильный край. Ответ — `1`.

### 6. Проверка внутренних позиций

```java
for (int i = 1; i < n - 1; i++) {
    char current = s.charAt(i);

    if (current == minChar || current == maxChar) {
        return 2;
    }
}
```

Проверяем все символы, кроме первого и последнего. Если минимальный или максимальный символ находится внутри, строку можно отсортировать за две операции.

Если цикл не нашёл такой символ, а строка не отсортирована и длина больше двух, минимальный символ находится только в конце, а максимальный — только в начале. В этом случае ответ — `3`.

## Пошаговый разбор примеров

## Пример 1: `s = "dog"`

**Ожидаемый результат: `1`.**

### Шаг 1. Инициализация

- `n = 3`
- `minChar = 'd'`
- `maxChar = 'd'`
- `isSorted = true`

### Шаг 2. Проходим по символам

**Индекс `1`: символ `'o'`**

- `'o' < 'd'` — нет, минимум остаётся `'d'`.
- `'o' > 'd'` — да, максимум становится `'o'`.
- `'o' < 'd'` — нет, порядок пока не нарушен.

**Индекс `2`: символ `'g'`**

- `'g' < 'd'` — нет, минимум остаётся `'d'`.
- `'g' > 'o'` — нет, максимум остаётся `'o'`.
- `'g' < 'o'` — да, строка не отсортирована: `isSorted = false`.

После цикла:

- `minChar = 'd'`
- `maxChar = 'o'`
- `isSorted = false`

### Шаг 3. Выбираем ответ

- Строка не отсортирована.
- Длина не равна `2`.
- Первый символ `'d'` равен минимуму `'d'`.

Поэтому алгоритм возвращает `1`.

### Операция

Сортируем подстроку `"og"`:

```text
dog
 |
 og -> go

Результат: dgo
```

Строка `"dgo"` отсортирована. **Ответ: `1`.**

---

## Пример 2: `s = "card"`

**Ожидаемый результат: `2`.**

### Шаг 1. Инициализация

- `n = 4`
- `minChar = 'c'`
- `maxChar = 'c'`
- `isSorted = true`

### Шаг 2. Проходим по символам

**Индекс `1`: символ `'a'`**

- `'a' < 'c'` — да, минимум становится `'a'`.
- `'a' > 'c'` — нет, максимум остаётся `'c'`.
- `'a' < 'c'` — да, строка не отсортирована.

**Индекс `2`: символ `'r'`**

- `'r' < 'a'` — нет.
- `'r' > 'c'` — да, максимум становится `'r'`.
- `'r' < 'a'` — нет.

**Индекс `3`: символ `'d'`**

- `'d' < 'a'` — нет.
- `'d' > 'r'` — нет.
- `'d' < 'r'` — да, порядок также нарушен.

После цикла:

- `minChar = 'a'`
- `maxChar = 'r'`
- `isSorted = false`

### Шаг 3. Выбираем ответ

- Строка не отсортирована.
- Длина больше двух.
- Первый символ `'c'` не равен минимуму `'a'`.
- Последний символ `'d'` не равен максимуму `'r'`.
- Внутри строки есть минимум `'a'`.

Поэтому алгоритм возвращает `2`.

### Операция 1

Сортируем подстроку `"car"`:

```text
card -> acrd
```

### Операция 2

Сортируем подстроку `"rd"`:

```text
acrd -> acdr
```

Строка `"acdr"` отсортирована. **Ответ: `2`.**

---

## Пример 3: `s = "gf"`

**Ожидаемый результат: `-1`.**

### Шаг 1. Инициализация

- `n = 2`
- `minChar = 'g'`
- `maxChar = 'g'`
- `isSorted = true`

### Шаг 2. Проверяем символ `'f'`

- `'f' < 'g'` — да, минимум становится `'f'`.
- `'f' > 'g'` — нет, максимум остаётся `'g'`.
- `'f' < 'g'` — да, порядок нарушен, `isSorted = false`.

После цикла:

- `minChar = 'f'`
- `maxChar = 'g'`
- `isSorted = false`

### Шаг 3. Выбираем ответ

- Строка не отсортирована.
- `n == 2` — условие выполняется.

Алгоритм возвращает `-1`.

Почему нельзя исправить строку?

- Подстрока `"gf"` — это вся строка, а её сортировать запрещено.
- Подстроки `"g"` и `"f"` содержат по одному символу, поэтому их сортировка ничего не меняет.

**Ответ: `-1`.**

| Входная строка | Ответ | Причина |
|---|---:|---|
| `"a"` | `0` | Один символ уже отсортирован |
| `"abc"` | `0` | Строка уже отсортирована |

| `"dcab"` | `2` | Минимум `'a'` находится внутри строки |

## Оценка сложности

Пусть `n` — длина строки.

### Временная сложность: `O(n)`

- Первый цикл проходит по строке один раз: `O(n)`.
- Второй цикл в худшем случае проходит по внутренним символам: `O(n)`.
- Общая сложность: `O(n) + O(n) = O(n)`.

### Дополнительная пространственная сложность: `O(1)`

Алгоритм использует только несколько переменных (`n`, `minChar`, `maxChar`, `isSorted` и `current`). Дополнительные массивы и строки не создаются.

---

## Итог

Решение работает за линейное время и использует постоянную дополнительную память:

- **Время:** `O(n)`.
- **Память:** `O(1)`.

Главный вывод: чтобы определить минимальное число операций, не обязательно сортировать строку. Достаточно проверить, отсортирована ли она, найти минимум и максимум и определить их положение относительно границ строки.
