## 1. Условие задачи

Дан целочисленный массив `nums` длины `n`, который является перестановкой целых чисел от `0` до `n - 1`.

Это означает, что каждый элемент из диапазона `[0, n - 1]` встречается ровно один раз.

Разрешены только две операции:

1. Развернуть весь массив.
2. Выполнить циклический сдвиг влево на одну позицию: первый элемент перемещается в конец массива, а все остальные элементы сдвигаются на одну позицию влево.

Необходимо вернуть минимальное количество операций, требуемых для сортировки массива по возрастанию.

Если отсортировать массив невозможно, необходимо вернуть `-1`.

### Ограничения

- `1 <= n == nums.length <= 100000`
- `0 <= nums[i] <= n - 1`
- `nums` является перестановкой целых чисел от `0` до `n - 1`.

### Пример 1

**Входные данные:**

```text
nums = [0, 2, 1]
```

**Выходные данные:**

```text
2
```

Объяснение:

```text
[0, 2, 1]
    |
    | Циклический сдвиг влево
    v
[2, 1, 0]
    |
    | Разворот массива
    v
[0, 1, 2]
```

Для сортировки требуется две операции.

### Пример 2

**Входные данные:**

```text
nums = [1, 0, 2]
```

**Выходные данные:**

```text
2
```

Объяснение:

```text
[1, 0, 2]
    |
    | Разворот массива
    v
[2, 0, 1]
    |
    | Циклический сдвиг влево
    v
[0, 1, 2]
```

Для сортировки требуется две операции.

### Пример 3

**Входные данные:**

```text
nums = [2, 0, 1, 3]
```

**Выходные данные:**

```text
-1
```

Объяснение:

Массив нельзя преобразовать в `[0, 1, 2, 3]` с помощью разрешённых операций.

## 2. Объяснение условия простыми словами

Представим, что у нас есть массив:

```text
[0, 1, 2, 3, 4]
```

Нужно получить именно такой порядок чисел.

Но обычная сортировка запрещена. Нельзя просто поменять местами любые два элемента.

Разрешено только:

- переворачивать весь массив;
- переносить первый элемент в конец массива.

Поэтому задача заключается не в поиске способа отсортировать произвольный массив, а в проверке того, можно ли получить отсортированный массив с помощью этих двух конкретных операций.

Например, циклическими сдвигами можно получить:

```text
[0, 1, 2, 3, 4]
[1, 2, 3, 4, 0]
[2, 3, 4, 0, 1]
[3, 4, 0, 1, 2]
[4, 0, 1, 2, 3]
```

Обрати внимание: порядок чисел сохраняется, но начало последовательности перемещается.

После разворота можно получить обратный порядок:

```text
[4, 3, 2, 1, 0]
```

И циклически сдвигать уже его.

Следовательно, существуют только два возможных направления последовательности:

- возрастающее;
- убывающее.

В каждом направлении возможно `n` циклических сдвигов.

**Главное наблюдение:** если массив не является циклическим сдвигом ни возрастающей, ни убывающей последовательности, сортировка невозможна.

Если сортировка возможна, необходимо найти минимальное количество операций.

Для этого используем алгоритм BFS — поиск в ширину.

## 3. Разрешённые операции

### 3.1. Разворот массива

Разворот меняет порядок всех элементов на противоположный.

Например:

```text
Было:  [0, 2, 1]
Стало: [1, 2, 0]
```

Ещё один пример:

```text
Было:  [1, 0, 2]
Стало: [2, 0, 1]
```

Один разворот считается одной операцией.

### 3.2. Циклический сдвиг влево

При циклическом сдвиге влево первый элемент перемещается в конец массива.

Например:

```text
Было:  [0, 2, 1]
Стало: [2, 1, 0]
```

Ещё один пример:

```text
Было:  [2, 1, 0]
Стало: [1, 0, 2]
```

Один циклический сдвиг тоже считается одной операцией.

Важно: нельзя считать перемещение нескольких позиций одной операцией. Каждый сдвиг на одну позицию стоит одну операцию.

## 4. Главная идея решения

Рассмотрим массив длины `5`.

Возрастающая последовательность:

```text
[0, 1, 2, 3, 4]
```

Все её циклические сдвиги:

```text
A0 = [0, 1, 2, 3, 4]
A1 = [1, 2, 3, 4, 0]
A2 = [2, 3, 4, 0, 1]
A3 = [3, 4, 0, 1, 2]
A4 = [4, 0, 1, 2, 3]
```

Обозначим их `A0`, `A1`, `A2`, `A3`, `A4`.

Теперь рассмотрим обратное направление:

```text
B0 = [4, 3, 2, 1, 0]
B1 = [0, 4, 3, 2, 1]
B2 = [1, 0, 4, 3, 2]
B3 = [2, 1, 0, 4, 3]
B4 = [3, 2, 1, 0, 4]
```

Получаем ещё пять состояний.

Всего:

```text
n обычных состояний
+
n обратных состояний
=
2 * n состояний
```

Для `n = 5` это всего `10` состояний.

Вместо того чтобы постоянно создавать новые массивы, будем хранить только номер состояния.

### Как состояния связаны друг с другом

Из любого состояния можно выполнить две операции:

- циклический сдвиг влево;
- разворот.

Переходы:

| Текущее состояние | Операция | Новое состояние |
|---|---|---|
| `A_k` | Сдвиг влево | `A_(k+1)` |
| `A_k` | Разворот | `B_k` |
| `B_k` | Сдвиг влево | `B_(k-1)` |
| `B_k` | Разворот | `A_k` |

Индексы циклические: после `A_(n-1)` следует `A_0`, а перед `B_0` находится `B_(n-1)`.

Цель — состояние `A_0`, соответствующее отсортированному массиву:

```text
[0, 1, 2, ..., n - 1]
```

## 5. Представление состояний

Чтобы сделать решение эффективным, не будем хранить сами массивы в очереди BFS.

Вместо этого каждому состоянию назначим целочисленный номер.

Для обычных состояний:

```text
A0 -> 0
A1 -> 1
A2 -> 2
...
A(n-1) -> n-1
```

Для обратных состояний:

```text
B0 -> n
B1 -> n + 1
B2 -> n + 2
...
B(n-1) -> 2 * n - 1
```

Таким образом, для любого состояния можно определить:

- направление;
- индекс циклического сдвига.

Если номер состояния меньше `n`, это обычное состояние `A_k`.

Если номер состояния больше или равен `n`, это обратное состояние `B_k`.

Например, при `n = 3`:

| Номер состояния | Состояние | Массив |
|---:|---|---|
| `0` | `A0` | `[0, 1, 2]` |
| `1` | `A1` | `[1, 2, 0]` |
| `2` | `A2` | `[2, 0, 1]` |
| `3` | `B0` | `[2, 1, 0]` |
| `4` | `B1` | `[0, 2, 1]` |
| `5` | `B2` | `[1, 0, 2]` |

Обрати внимание: для обратных состояний индекс `k` не обязательно совпадает с первым элементом массива. В состоянии `B_k` первый элемент равен `(k - 1 + n) % n`.

Поэтому номер обратного состояния для исходного массива вычисляется отдельно.

### Как проверить направление массива

Пусть:

```text
first = nums[0]
```

Для обычной последовательности ожидаем:

```java
(first + i) % n
```

Для обратной последовательности ожидаем:

```java
(first - i + n) % n
```

Если фактический элемент `nums[i]` не совпадает с ожидаемым, соответствующее направление исключается.

Если оба направления исключены, возвращаем `-1`.

## 6. Алгоритм решения

Решение состоит из двух основных этапов.

### Этап 1. Проверка возможности сортировки

1. Получаем длину массива `n`.
2. Сохраняем первый элемент `first`.
3. Проверяем, соответствует ли массив обычной циклической последовательности.
4. Проверяем, соответствует ли массив обратной циклической последовательности.
5. Если не подходит ни одно направление, возвращаем `-1`.

Эта проверка занимает `O(n)` времени.

### Этап 2. Поиск минимального числа операций

1. Определяем номер исходного состояния.
2. Создаём массив `distance`, в котором храним минимальное число операций до каждого состояния.
3. Изначально заполняем `distance` значением `-1`, обозначающим непосещённое состояние.
4. Добавляем исходное состояние в очередь BFS и устанавливаем расстояние `0`.
5. Извлекаем состояние из очереди.
6. Если его номер равен `0`, возвращаем найденное расстояние.
7. Иначе рассматриваем оба возможных перехода.
8. Добавляем каждое ранее не посещённое состояние в очередь и записываем расстояние до него.
9. Продолжаем, пока не найдём цель.

BFS исследует состояния в порядке увеличения количества операций. Поэтому первое достижение цели даёт минимальное число операций.

## 7. Полный код на Java

Решение предназначено для LeetCode, где требуется реализовать класс `Solution` и метод `minOperations`.

```java
import java.util.ArrayDeque; // Подключаем очередь для поиска в ширину (BFS).
import java.util.Arrays; // Подключаем заполнение массива расстояний значением -1.

class Solution { // Объявляем класс решения для LeetCode.

    public int minOperations(int[] nums) { // Возвращаем минимальное число операций или -1.
        int n = nums.length; // Сохраняем длину исходного массива.

        boolean normal = true; // Предполагаем, что массив является обычным циклическим сдвигом.
        boolean reversed = true; // Предполагаем, что массив является обратным циклическим сдвигом.

        int first = nums[0]; // Первый элемент определяет начало последовательности.

        for (int i = 0; i < n; i++) { // Проверяем каждый элемент массива.
            if (nums[i] != (first + i) % n) { // Проверяем обычную последовательность с циклическим переходом через n.
                normal = false; // Если элемент не подходит, обычный вариант невозможен.
            } // Завершаем проверку обычного варианта для текущего элемента.

            if (nums[i] != (first - i + n) % n) { // Проверяем последовательность в обратном направлении.
                reversed = false; // Если элемент не подходит, обратный вариант невозможен.
            } // Завершаем проверку обратного варианта для текущего элемента.
        } // Завершаем проверку исходного массива.

        if (!normal && !reversed) { // Если не подходит ни одно направление.
            return -1; // Возвращаем -1: сортировка невозможна.
        } // Завершаем проверку достижимости.

        int startState; // Объявляем номер начального состояния BFS.

        if (normal) { // Если массив имеет обычное направление.
            startState = first; // Состояние A_k имеет номер k, а k равен первому элементу.
        } else { // Иначе массив имеет обратное направление.
            int k = (first + 1) % n; // Для B_k первый элемент равен (k - 1 + n) % n.
            startState = n + k; // Состояния B_k нумеруются от n до 2*n - 1.
        } // Завершаем определение начального состояния.

        int totalStates = 2 * n; // Есть n обычных и n обратных состояний.
        int[] distance = new int[totalStates]; // Храним минимальное число операций до каждого состояния.
        Arrays.fill(distance, -1); // Значение -1 означает, что состояние ещё не посещено.

        ArrayDeque<Integer> queue = new ArrayDeque<>(); // Создаём очередь BFS.
        queue.offer(startState); // Добавляем начальное состояние в очередь.
        distance[startState] = 0; // До начального состояния нужно ноль операций.

        while (!queue.isEmpty()) { // Продолжаем, пока в очереди остаются состояния.
            int state = queue.poll(); // Извлекаем состояние с минимальным расстоянием.
            int steps = distance[state]; // Получаем число операций до этого состояния.

            if (state == 0) { // Состояние 0 означает отсортированный массив A_0.
                return steps; // Возвращаем минимальное количество операций.
            } // Завершаем проверку цели.

            int k; // Объявляем индекс циклического сдвига.
            int next; // Объявляем переменную для следующего состояния.

            if (state < n) { // Если состояние обычное A_k.
                k = state; // Номер состояния совпадает со сдвигом k.

                next = (k + 1) % n; // Сдвиг влево переводит A_k в A_(k+1).
                if (distance[next] == -1) { // Проверяем, посещали ли новое состояние.
                    distance[next] = steps + 1; // Записываем расстояние до него.
                    queue.offer(next); // Добавляем его в очередь.
                } // Завершаем обработку сдвига обычного состояния.

                next = n + k; // Разворот переводит A_k в B_k.
                if (distance[next] == -1) { // Проверяем, посещали ли обратное состояние.
                    distance[next] = steps + 1; // Записываем расстояние до него.
                    queue.offer(next); // Добавляем его в очередь.
                } // Завершаем обработку разворота обычного состояния.

            } else { // Иначе состояние обратное B_k.
                k = state - n; // Получаем индекс обратного состояния.

                next = n + (k - 1 + n) % n; // Сдвиг влево переводит B_k в B_(k-1).
                if (distance[next] == -1) { // Проверяем, посещали ли новое состояние.
                    distance[next] = steps + 1; // Записываем расстояние до него.
                    queue.offer(next); // Добавляем его в очередь.
                } // Завершаем обработку сдвига обратного состояния.

                next = k; // Разворот переводит B_k в A_k.
                if (distance[next] == -1) { // Проверяем, посещали ли обычное состояние.
                    distance[next] = steps + 1; // Записываем расстояние до него.
                    queue.offer(next); // Добавляем его в очередь.
                } // Завершаем обработку разворота обратного состояния.
            } // Завершаем обработку переходов.
        } // Завершаем BFS, если очередь опустела.

        return -1; // Страховочный возврат: цель не найдена.
    } // Завершаем метод minOperations.
} // Завершаем класс Solution.
```

## 8. Подробный разбор кода

### 8.1. Подключение необходимых классов

```java
import java.util.ArrayDeque;
import java.util.Arrays;
```

`ArrayDeque` используется как очередь для BFS.

`Arrays.fill()` позволяет быстро заполнить массив расстояний значением `-1`.

### 8.2. Определение длины массива

```java
int n = nums.length;
```

Например:

```text
nums = [0, 2, 1]
```

Тогда:

```text
n = 3
```

### 8.3. Проверка обычной последовательности

```java
if (nums[i] != (first + i) % n) {
    normal = false;
}
```

Формула `(first + i) % n` позволяет получить ожидаемое значение обычной циклической последовательности.

Допустим:

```text
first = 2
n = 4
```

Тогда ожидаемая последовательность:

```text
i = 0: (2 + 0) % 4 = 2
i = 1: (2 + 1) % 4 = 3
i = 2: (2 + 2) % 4 = 0
i = 3: (2 + 3) % 4 = 1
```

Получаем:

```text
[2, 3, 0, 1]
```

### 8.4. Проверка обратной последовательности

```java
if (nums[i] != (first - i + n) % n) {
    reversed = false;
}
```

Формула вычитает индекс `i` из первого элемента и возвращает результат в диапазон от `0` до `n - 1`.

Например:

```text
first = 2
n = 4
```

Получаем:

```text
i = 0: (2 - 0 + 4) % 4 = 2
i = 1: (2 - 1 + 4) % 4 = 1
i = 2: (2 - 2 + 4) % 4 = 0
i = 3: (2 - 3 + 4) % 4 = 3
```

Обратная последовательность:

```text
[2, 1, 0, 3]
```

### 8.5. Проверка достижимости

```java
if (!normal && !reversed) {
    return -1;
}
```

Оператор `!` означает отрицание.

Выражение `!normal` означает, что обычная последовательность не подходит.

Выражение `!reversed` означает, что обратная последовательность не подходит.

Если оба условия истинны, сортировка невозможна.

### 8.6. Определение начального состояния

```java
if (normal) {
    startState = first;
} else {
    int k = (first + 1) % n;
    startState = n + k;
}
```

Для обычного состояния `A_k` номер состояния равен `k`. Первый элемент массива также равен `k`.

Для обратного состояния `B_k` первый элемент равен `(k - 1 + n) % n`. Поэтому, чтобы найти `k`, используем:

```text
k = (first + 1) % n
```

После этого прибавляем `n`, чтобы получить номер обратного состояния.

### 8.7. Создание массива расстояний

```java
int totalStates = 2 * n;
int[] distance = new int[totalStates];
Arrays.fill(distance, -1);
```

Если `n = 3`, всего имеется `6` состояний.

Массив `distance` сначала содержит:

```text
[-1, -1, -1, -1, -1, -1]
```

Значение `-1` означает, что состояние ещё не посещено.

### 8.8. Инициализация BFS

```java
ArrayDeque<Integer> queue = new ArrayDeque<>();
queue.offer(startState);
distance[startState] = 0;
```

Создаём очередь, добавляем исходное состояние и указываем, что для его достижения нужно ноль операций.

### 8.9. Извлечение состояния

```java
while (!queue.isEmpty()) {
    int state = queue.poll();
    int steps = distance[state];
```

Пока очередь не пуста, извлекаем следующее состояние.

Метод `poll()` удаляет и возвращает первый элемент очереди.

Переменная `steps` хранит минимальное количество операций до текущего состояния.

### 8.10. Проверка цели

```java
if (state == 0) {
    return steps;
}
```

Номер `0` соответствует состоянию `A_0`:

```text
[0, 1, 2, ..., n - 1]
```

Это отсортированный массив.

Поскольку BFS обрабатывает состояния по возрастанию расстояния, первое посещение цели гарантирует минимальный ответ.

### 8.11. Переходы из обычного состояния

```java
if (state < n) {
    k = state;
```

Если номер меньше `n`, это состояние `A_k`.

Сдвиг влево:

```java
next = (k + 1) % n;
```

Разворот:

```java
next = n + k;
```

Каждый переход добавляет ровно одну операцию.

### 8.12. Переходы из обратного состояния

```java
else {
    k = state - n;
```

Если номер не меньше `n`, это состояние `B_k`.

Сдвиг влево:

```java
next = n + (k - 1 + n) % n;
```

Разворот:

```java
next = k;
```

Каждое состояние имеет два перехода: сдвиг и разворот.

### 8.13. Защита от повторного посещения

```java
if (distance[next] == -1) {
    distance[next] = steps + 1;
    queue.offer(next);
}
```

Если расстояние равно `-1`, состояние ещё не посещено.

Записываем расстояние `steps + 1` и добавляем состояние в очередь.

Если состояние уже посещено, повторно добавлять его не нужно. BFS уже нашёл кратчайший путь к нему.

## 9. Пошаговый разбор примера 1

Входные данные:

```text
nums = [0, 2, 1]
```

Ожидаемый результат:

```text
2
```

### Шаг 1. Определяем параметры

```text
n = 3
first = 0
```

### Шаг 2. Проверяем обычную последовательность

Вычисляем `(first + i) % n`.

| `i` | Вычисление | Ожидаемое значение | `nums[i]` |
|---:|---|---:|---:|
| 0 | `(0 + 0) % 3` | 0 | 0 |
| 1 | `(0 + 1) % 3` | 1 | 2 |
| 2 | `(0 + 2) % 3` | 2 | 1 |

При `i = 1` возникает несовпадение.

Поэтому:

```text
normal = false
```

### Шаг 3. Проверяем обратную последовательность

Вычисляем `(first - i + n) % n`.

| `i` | Вычисление | Ожидаемое значение | `nums[i]` |
|---:|---|---:|---:|
| 0 | `(0 - 0 + 3) % 3` | 0 | 0 |
| 1 | `(0 - 1 + 3) % 3` | 2 | 2 |
| 2 | `(0 - 2 + 3) % 3` | 1 | 1 |

Все элементы совпадают.

Следовательно:

```text
reversed = true
```

Массив допустим для сортировки.

### Шаг 4. Определяем начальное состояние

```text
k = (first + 1) % n
k = (0 + 1) % 3
k = 1
```

```text
startState = n + k
startState = 3 + 1
startState = 4
```

Начинаем с состояния `B_1`.

### Шаг 5. Инициализируем очередь

```text
queue = [4]
distance[4] = 0
```

Состояние `4` соответствует массиву:

```text
[0, 2, 1]
```

### Шаг 6. Обрабатываем состояние `B_1`

Извлекаем:

```text
state = 4
steps = 0
k = state - n = 4 - 3 = 1
```

Первый переход — сдвиг влево:

```text
next = n + (k - 1 + n) % n
next = 3 + (1 - 1 + 3) % 3
next = 3
```

Состояние `3` ещё не посещено.

Записываем:

```text
distance[3] = 1
queue = [3]
```

Состояние `3` соответствует массиву:

```text
[2, 1, 0]
```

Второй переход — разворот:

```text
next = k = 1
```

Состояние `1` ещё не посещено.

Записываем:

```text
distance[1] = 1
queue = [3, 1]
```

Состояние `1` соответствует массиву:

```text
[1, 2, 0]
```

### Шаг 7. Обрабатываем состояние `B_0`

Извлекаем:

```text
state = 3
steps = 1
k = 3 - 3 = 0
```

Сдвиг влево:

```text
next = 3 + (0 - 1 + 3) % 3
next = 3 + 2
next = 5
```

Состояние `5` ещё не посещено.

```text
distance[5] = 2
queue = [1, 5]
```

Состояние `5` соответствует массиву `[1, 0, 2]`.

Разворот:

```text
next = k = 0
```

Состояние `0` ещё не посещено.

```text
distance[0] = 2
queue = [1, 5, 0]
```

Состояние `0` соответствует массиву:

```text
[0, 1, 2]
```

### Шаг 8. Достигаем цели

Когда очередь дойдёт до состояния `0`, выполняется:

```java
if (state == 0) {
    return steps;
}
```

Расстояние до него равно `2`.

**Ответ: `2`.**

Кратчайший путь:

```text
[0, 2, 1]
    |
    | Сдвиг влево
    v
[2, 1, 0]
    |
    | Разворот
    v
[0, 1, 2]
```

Меньше двух операций недостаточно: исходный массив не отсортирован, а результат ни одного из двух разрешённых действий не равен `[0, 1, 2]`.

nums = [1, 0, 2]

next = 3 + (2 - 1 + 3) % 3

## 11. Пошаговый разбор примера 3

Входные данные:

```text
nums = [2, 0, 1, 3]
```

Ожидаемый результат:

```text
-1
```

### Шаг 1. Определяем параметры

```text
n = 4
first = 2
```

### Шаг 2. Проверяем обычное направление

Ожидаемое значение вычисляется по формуле:

```text
(first + i) % n
```

| `i` | Вычисление | Ожидаемое значение | `nums[i]` |
|---:|---|---:|---:|
| 0 | `(2 + 0) % 4` | 2 | 2 |
| 1 | `(2 + 1) % 4` | 3 | 0 |
| 2 | `(2 + 2) % 4` | 0 | 1 |
| 3 | `(2 + 3) % 4` | 1 | 3 |

Элементы не совпадают.

```text
normal = false
```

### Шаг 3. Проверяем обратное направление

Ожидаемое значение вычисляется по формуле:

```text
(first - i + n) % n
```

| `i` | Вычисление | Ожидаемое значение | `nums[i]` |
|---:|---|---:|---:|
| 0 | `(2 - 0 + 4) % 4` | 2 | 2 |
| 1 | `(2 - 1 + 4) % 4` | 1 | 0 |
| 2 | `(2 - 2 + 4) % 4` | 0 | 1 |
| 3 | `(2 - 3 + 4) % 4` | 3 | 3 |

Элементы также не совпадают.

```text
reversed = false
```

### Шаг 4. Возвращаем результат

Выполняется условие:

```java
if (!normal && !reversed) {
    return -1;
}
```

Поскольку оба направления невозможны, метод возвращает `-1`.

BFS даже не запускается.

**Ответ: `-1`.**

Причина: разрешённые операции позволяют менять начало последовательности и её направление, но не позволяют произвольно переставлять элементы. Исходный массив не соответствует ни одной из допустимых последовательностей.

## 12. Доказательство корректности

Докажем, что алгоритм возвращает правильный ответ.

### Утверждение 1. Любой достижимый массив является циклическим сдвигом возрастающей или убывающей последовательности

Изначально элементы образуют перестановку чисел от `0` до `n - 1`.

Циклический сдвиг не меняет циклический порядок элементов.

Разворот меняет направление этого порядка.

Следовательно, после любой последовательности разрешённых операций массив остаётся циклическим сдвигом либо возрастающей последовательности, либо её обратной версии.

Поэтому проверка двух направлений позволяет правильно определить, достижим ли отсортированный массив.

### Утверждение 2. Граф состояний правильно моделирует разрешённые операции

Каждое состояние обозначает определённую последовательность.

Из обычного состояния `A_k`:

- сдвиг влево переводит в `A_(k+1)`;
- разворот переводит в `B_k`.

Из обратного состояния `B_k`:

- сдвиг влево переводит в `B_(k-1)`;
- разворот переводит в `A_k`.

Таким образом, каждому разрешённому действию соответствует ребро графа состояний.

Поэтому путь от исходного состояния до `A_0` соответствует допустимой последовательности операций, и наоборот.

### Утверждение 3. BFS находит минимальное количество операций

Каждое ребро графа соответствует ровно одной операции.

BFS сначала посещает состояния на расстоянии `0`, затем `1`, затем `2` и так далее.

Следовательно, первое извлечение целевого состояния `A_0` происходит на минимально возможном расстоянии от исходного состояния.

Значит, возвращаемое значение является минимальным количеством операций.

### Вывод

Если массив недостижим, алгоритм возвращает `-1`.

Если массив достижим, BFS возвращает минимальное количество операций для его сортировки.

Следовательно, алгоритм корректен.

## 13. Сложность алгоритма

Пусть `n` — длина входного массива.

### Временная сложность

Проверка двух направлений проходит по всем `n` элементам:

```text
O(n)
```

Всего существует не более `2 * n` состояний.

Каждое состояние добавляется в очередь не более одного раза, а из каждого состояния проверяются два перехода.

Поэтому BFS работает за:

```text
O(2 * n) = O(n)
```

Общая временная сложность:

```text
O(n) + O(n) = O(n)
```

### Пространственная сложность

Массив `distance` содержит `2 * n` элементов:

```text
O(n)
```

Очередь BFS также может содержать до `2 * n` состояний:

```text
O(n)
```

Дополнительная память:

```text
O(n) + O(n) = O(n)
```

### Итоговая таблица

| Показатель | Сложность |
|---|---|
| Время | `O(n)` |
| Дополнительная память | `O(n)` |
| Максимальное количество состояний | `2 * n` |
| Максимальное количество переходов | `4 * n` |

При `n = 100000` алгоритм рассматривает не более `200000` состояний. Поэтому он подходит для заданных ограничений.

## 14. Итог

Для решения задачи используются два основных приёма.

**Первый — проверка структуры массива.**

Разрешённые операции не позволяют произвольно менять порядок чисел. Поэтому сначала проверяем, является ли исходный массив циклическим сдвигом возрастающей или убывающей последовательности.

Если нет, возвращаем `-1`.

**Второй — поиск в ширину (BFS).**

Если сортировка возможна, представляем каждое состояние целым числом. Для каждого состояния рассматриваем сдвиг влево и разворот.

BFS находит кратчайший путь к состоянию `A_0`, соответствующему отсортированному массиву.

### Запомни главное

- Не нужно создавать копии массивов для каждого состояния.
- Достаточно хранить номера состояний.
- Каждая операция соответствует одному переходу.
- BFS находит минимальное число операций.
- Временная сложность решения — `O(n)`.
- Дополнительная пространственная сложность — `O(n)`.

**Результат:** линейное по времени решение, подходящее для массива длиной до `100000` элементов.
