# LeetCode 26. Удаление дубликатов из отсортированного массива (Remove Duplicates from Sorted Array)

## 1. Условие задачи

Дан целочисленный массив `nums`, отсортированный в порядке неубывания.

Необходимо удалить дубликаты **на месте**, чтобы каждый уникальный элемент встречался только один раз. Относительный порядок элементов должен остаться прежним.

Нужно вернуть количество уникальных элементов `k`.

После выполнения метода первые `k` элементов массива `nums` должны содержать уникальные числа в отсортированном порядке. Элементы после индекса `k - 1` можно игнорировать.

### Требования

1. Изменить исходный массив, не создавая дополнительный массив для результата.
2. Сохранить относительный порядок уникальных элементов.
3. Вернуть количество уникальных элементов `k`.
4. Обеспечить оптимальную временную и пространственную сложность.

### Пользовательский судья LeetCode

Платформа проверяет решение примерно следующим образом:

```java
int[] nums = [...];          // Входной массив
int[] expectedNums = [...];  // Ожидаемый результат

int k = removeDuplicates(nums);

assert k == expectedNums.length;

for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
```

Проверяются количество уникальных элементов и содержимое первых `k` позиций массива.

Значение последнего элемента не имеет значения.

**Объяснение:**

Уникальные значения массива: `0`, `1`, `2`, `3`, `4`.

Всего пять уникальных элементов, поэтому метод возвращает `5`.

**Входные данные:**

**Объяснение:**

## 3. Ограничения

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- Массив `nums` отсортирован в порядке неубывания.

Порядок неубывания означает, что каждый следующий элемент больше или равен предыдущему.

Например:

```text
[-3, -3, 0, 1, 1, 2, 5]
```

Такой массив отсортирован правильно.

## 4. Идея решения

Для решения используем алгоритм **Two Pointers (два указателя)**.

Поскольку массив отсортирован, все одинаковые элементы находятся рядом друг с другом.

Поэтому не нужно сравнивать каждый элемент со всеми предыдущими. Достаточно сравнивать текущий элемент с последним найденным уникальным значением.

Используем два указателя:

- `i` — индекс последнего найденного уникального элемента.
- `j` — индекс элемента, который проверяем в данный момент.

### Как работают указатели

1. Первый элемент массива считаем уникальным.
2. Устанавливаем `i = 0`.
3. Запускаем цикл с `j = 1`.
4. Сравниваем `nums[j]` и `nums[i]`.
5. Если значения одинаковые, пропускаем текущий элемент.
6. Если значения различаются, увеличиваем `i` и записываем `nums[j]` в `nums[i]`.
7. После завершения цикла возвращаем `i + 1`.

### Пример работы

Исходный массив:

```text
nums = [1, 1, 2, 2, 3]
```

Первый элемент `1` сразу считаем уникальным.

Затем проверяем остальные элементы:

- Второй `1` совпадает с последним уникальным значением — пропускаем.
- `2` отличается от `1` — записываем `2` в следующую позицию.
- Второй `2` совпадает с последним уникальным значением — пропускаем.
- `3` отличается от `2` — записываем `3` в следующую позицию.

Результат:

```text
nums = [1, 2, 3, 2, 3]
```

Первые три элемента содержат ответ:

```text
[1, 2, 3]
```

Количество уникальных элементов равно `3`.

Важно: массив физически не уменьшается. В Java длина массива фиксирована после создания.

## 5. Оптимальное решение на Java

Полный класс для запуска в IntelliJ IDEA:

```java
public class Solution {

    public int removeDuplicates(int[] nums) {
        // Если массив пустой, уникальных элементов нет.
        // По условию LeetCode массив не пустой,
        // но эта проверка делает метод универсальнее.
        if (nums.length == 0) {
            return 0;
        }

        // Индекс последнего найденного уникального элемента.
        // Первый элемент массива считаем уникальным.
        int i = 0;

        // Перебираем массив со второго элемента до конца.
        for (int j = 1; j < nums.length; j++) {

            // Если текущий элемент отличается
            // от последнего найденного уникального элемента,
            // значит, найдено новое уникальное значение.
            if (nums[j] != nums[i]) {

                // Перемещаем границу уникальной части массива
                // на следующую позицию.
                i++;

                // Записываем новое уникальное значение
                // в следующую свободную позицию.
                nums[i] = nums[j];
            }
        }

        // Индексы начинаются с нуля,
        // поэтому количество элементов равно i + 1.
        return i + 1;
    }

    public static void main(String[] args) {
        // Создаём объект класса Solution,
        // чтобы вызвать нестатический метод.
        Solution solution = new Solution();

        // Пример 1.
        int[] nums1 = {1, 1, 2};

        // Вызываем метод и сохраняем количество уникальных элементов.
        int k1 = solution.removeDuplicates(nums1);

        // Выводим результат.
        System.out.print("Пример 1: k = " + k1 + ", nums = ");
        printResult(nums1, k1);

        // Пример 2.
        int[] nums2 = {0, 0, 1, 1, 1, 2, 2, 3, 3, 4};

        // Вызываем метод.
        int k2 = solution.removeDuplicates(nums2);

        // Выводим результат.
        System.out.print("Пример 2: k = " + k2 + ", nums = ");
        printResult(nums2, k2);

        // Пример 3.
        int[] nums3 = {5, 5, 5, 5};

        // Вызываем метод.
        int k3 = solution.removeDuplicates(nums3);

        // Выводим результат.
        System.out.print("Пример 3: k = " + k3 + ", nums = ");
        printResult(nums3, k3);
    }

    // Вспомогательный метод выводит только первые k элементов.
    private static void printResult(int[] nums, int k) {
        // Открываем квадратную скобку результата.
        System.out.print("[");

        // Перебираем только уникальную часть массива.
        for (int i = 0; i < k; i++) {

            // Выводим текущий элемент.
            System.out.print(nums[i]);

            // Добавляем запятую, если элемент не последний.
            if (i < k - 1) {
                System.out.print(", ");
            }
        }

        // Закрываем квадратную скобку и переходим на новую строку.
        System.out.println("]");
    }
}
```

### Важно для отправки на LeetCode

На LeetCode достаточно отправить только метод `removeDuplicates`. Класс `Solution` платформа предоставляет сама, а метод `main` и вспомогательный `printResult` для проверки на платформе не нужны.

Код для отправки:

```java
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) {
        return 0;
    }

    int i = 0;

    for (int j = 1; j < nums.length; j++) {
        if (nums[j] != nums[i]) {
            i++;
            nums[i] = nums[j];
        }
    }

    return i + 1;
}
```

## 6. Разбор каждой строки алгоритма

### Объявление метода

```java
public int removeDuplicates(int[] nums) {
```

- `public` — метод доступен извне класса.
- `int` — тип возвращаемого значения.
- `removeDuplicates` — название метода.
- `int[] nums` — входной массив целых чисел.

Метод принимает массив и возвращает количество уникальных элементов.

### Проверка массива

```java
if (nums.length == 0) {
    return 0;
}
```

`nums.length` возвращает количество элементов массива.

Если длина равна нулю, метод возвращает `0`.

В условиях задачи массив гарантированно содержит хотя бы один элемент, поэтому проверка не обязательна для LeetCode, но она не мешает решению.

### Инициализация указателя

```java
int i = 0;
```

Указатель `i` показывает позицию последнего найденного уникального элемента.

В начале первый элемент считается уникальным.

Например:

```text
nums = [1, 1, 2]
        ^
        i
```

### Цикл

```java
for (int j = 1; j < nums.length; j++) {
```

- `int j = 1` — начинаем со второго элемента.
- `j < nums.length` — продолжаем, пока индекс меньше длины массива.
- `j++` — увеличиваем индекс на единицу после каждой итерации.

Первый элемент не проверяется, потому что он уже считается уникальным.

### Сравнение элементов

```java
if (nums[j] != nums[i]) {
```

Сравниваем текущий элемент с последним найденным уникальным.

Если значения равны, текущий элемент является дубликатом.

Если значения различаются, найдено новое уникальное значение.

### Перемещение указателя

```java
i++;
```

Увеличиваем индекс последнего уникального элемента на единицу.

Теперь появилась следующая позиция для нового уникального значения.

### Перезапись массива

```java
nums[i] = nums[j];
```

Копируем новое уникальное значение в начало массива, в следующую свободную позицию уникальной части.

Дополнительный массив не создаётся.

### Возвращаем количество

```java
return i + 1;
```

Индексация массива в Java начинается с нуля.

Если последний уникальный элемент находится на индексе `4`, количество уникальных элементов равно `5`.

Поэтому возвращаем `i + 1`.

## 7. Пошаговый разбор примера № 1

Входной массив:

```text
nums = [1, 1, 2]
```

Начальное состояние:

```text
i = 0
nums = [1, 1, 2]
```

Первый элемент `1` считаем уникальным.

### Итерация 1

Значение `j = 1`.

Сравниваем:

```java
nums[j] != nums[i]
```

Подставляем значения:

```text
nums[1] != nums[0]
1 != 1
false
```

Условие ложно. Тело `if` не выполняется.

Состояние:

```text
i = 0
nums = [1, 1, 2]
```

### Итерация 2

Значение `j = 2`.

Сравниваем:

```text
nums[2] != nums[0]
2 != 1
true
```

Условие истинно.

Сначала выполняется:

```java
i++;
```

Получаем:

```text
i = 1
```

Затем выполняется:

```java
nums[i] = nums[j];
```

Подставляем индексы:

```java
nums[1] = nums[2];
```

Записываем `2` в индекс `1`.

Новый массив:

```text
[1, 2, 2]
```

### Завершение цикла

Следующий индекс `j = 3` уже не удовлетворяет условию `j < nums.length`.

Цикл завершается.

Выполняется:

```java
return i + 1;
```

Получаем:

```text
return 1 + 1;
return 2;
```

**Ответ:**

```text
k = 2
Первые k элементов: [1, 2]
```

## 11. Доказательство корректности алгоритма

Корректность решения можно объяснить с помощью трёх утверждений.

### Утверждение 1. Первый элемент уникален

В начале:

```java
int i = 0;
```

Первый элемент считается уникальным относительно уже обработанной части массива, поскольку эта часть состоит только из него.

### Утверждение 2. Каждый найденный уникальный элемент записывается в правильную позицию

Когда выполняется условие:

```java
if (nums[j] != nums[i])
```

текущий элемент отличается от последнего уникального значения.

Поскольку массив отсортирован, новое значение не может совпадать с каким-либо более ранним уникальным значением, отличным от последнего: все ранее найденные уникальные значения не превосходят текущего.

Поэтому мы можем увеличить `i` и записать текущее число в следующую позицию.

### Утверждение 3. После цикла начало массива содержит все уникальные значения

Цикл проверяет каждый элемент массива.

Дубликаты пропускаются, а каждое новое уникальное значение записывается в следующую позицию.

Таким образом, первые `i + 1` элементов содержат все уникальные значения в исходном порядке.

Следовательно, алгоритм возвращает правильное количество уникальных элементов и формирует требуемое начало массива.

## 12. Анализ временной сложности

Пусть `n` — длина входного массива.

Цикл:

```java
for (int j = 1; j < nums.length; j++)
```

проходит по массиву один раз.

Для каждого элемента выполняется сравнение. Если найдено новое уникальное значение, дополнительно выполняются увеличение индекса и запись элемента.

Эти операции занимают постоянное время.

Количество итераций не превышает `n - 1`.

Поэтому временная сложность:

```text
O(n)
```

Это оптимально по асимптотике: в общем случае нужно проверить каждый элемент массива, поэтому нижняя граница времени составляет `Ω(n)`.

## 13. Анализ пространственной сложности

Алгоритм использует несколько переменных:

```java
int i = 0;
int j;
```

Новый массив не создаётся. Все изменения выполняются в исходном `nums`.

Количество используемых дополнительных переменных не зависит от размера входного массива.

Поэтому пространственная сложность:

```text
O(1)
```

## 14. Частые ошибки начинающих

### Ошибка 1. Возвращать `i` вместо `i + 1`

Неправильно:

```java
return i;
```

Правильно:

```java
return i + 1;
```

Если последний уникальный элемент находится на индексе `4`, количество уникальных элементов равно `5`.

### Ошибка 2. Начинать цикл с `j = 0`

Неправильно:

```java
for (int j = 0; j < nums.length; j++)
```

При таком подходе первый элемент сравнивается сам с собой.

Правильно:

```java
for (int j = 1; j < nums.length; j++)
```

Первый элемент уже считается уникальным.

### Ошибка 3. Создавать новый массив

Например:

```java
int[] result = new int[nums.length];
```

Для этой задачи такой массив не нужен. Требуется изменить исходный массив на месте.

### Ошибка 4. Пытаться уменьшить длину массива

В Java размер массива фиксирован после создания.

Не нужно пытаться изменить `nums.length`. Достаточно вернуть `k`, а судья будет проверять только первые `k` элементов.

### Ошибка 5. Не учитывать, что `i` и `j` выполняют разные функции

`i` указывает на последний уникальный элемент.

`j` проходит по массиву и ищет следующие уникальные значения.

Именно это разделение ролей позволяет решить задачу за один проход.
