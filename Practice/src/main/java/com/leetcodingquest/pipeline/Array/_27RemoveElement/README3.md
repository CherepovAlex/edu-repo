# Remove Element (LeetCode 27)

## Описание задачи

Дан целочисленный массив `nums` и целое число `val`. Необходимо удалить все вхождения `val` из массива `nums` **на месте** (in-place). Порядок элементов может быть изменен. Затем верните количество элементов в `nums`, которые не равны `val`.

### Условия
1.  Измените массив `nums` так, чтобы первые `k` элементов содержали элементы, не равные `val`.
2.  Остальные элементы массива не важны.
3.  Верните `k`.

### Ограничения
-   `0 <= nums.length <= 100`
-   `0 <= nums[i] <= 50`
-   `0 <= val <= 100`

### Сложность решения
-   **Время:** $O(N)$ — один проход по массиву.
-   **Пространство:** $O(1)$ — изменение на месте, без дополнительного выделения памяти.

## Решение на Java

```java
public class Solution1 {

    /**
     * Удаляет все вхождения val из массива nums на месте.
     * Возвращает количество элементов, не равных val.
     *
     * @param nums входной массив
     * @param val  значение, которое нужно удалить
     * @return количество элементов, не равных val
     */
    public int removeElement(int[] nums, int val) {
        // slow указывает на позицию, куда нужно записать следующий элемент,
        // который НЕ равен val.
        int slow = 0;

        // fast проходит по всем элементам массива, чтобы найти "хорошие" элементы.
        for (int fast = 0; fast < nums.length; fast++) {

            // Проверяем, является ли текущий элемент (по индексу fast)
            // тем, который нужно оставить (т.е. он НЕ равен val).
            if (nums[fast] != val) {
                // Если элемент "хороший", записываем его в позицию slow.
                // Так как порядок не важен, мы просто копируем значение.
                nums[slow] = nums[fast];

                // Увеличиваем slow на 1, чтобы следующий "хороший" элемент
                // записался на следующую позицию.
                slow++;
            }
            // Если nums[fast] == val, мы ничего не делаем.
            // Мы просто продолжаем цикл, и fast увеличивается автоматически.
        }

        // После завершения цикла slow равно количеству элементов,
        // которые мы успешно записали (т.е. не равных val).
        return slow;
    }

    public static void main(String[] args) {
        // Создаем экземпляр класса для вызова метода
        Solution1 solution = new Solution1();

        // Пример 1
        int[] nums1 = {3, 2, 2, 3};
        int val1 = 3;
        int k1 = solution.removeElement(nums1, val1);
        System.out.println("Пример 1: k = " + k1);
        System.out.print("Массив после удаления: ");
        for (int i = 0; i < k1; i++) {
            System.out.print(nums1[i] + " ");
        }
        System.out.println();

        // Пример 2
        int[] nums2 = {0, 1, 2, 2, 3, 0, 4, 2};
        int val2 = 2;
        int k2 = solution.removeElement(nums2, val2);
        System.out.println("Пример 2: k = " + k2);
        System.out.print("Массив после удаления: ");
        for (int i = 0; i < k2; i++) {
            System.out.print(nums2[i] + " ");
        }
        System.out.println();
        
        // Пример 3 (Граничный случай)
        int[] nums3 = {1};
        int val3 = 1;
        int k3 = solution.removeElement(nums3, val3);
        System.out.println("Пример 3: k = " + k3);
        System.out.print("Массив после удаления: ");
        for (int i = 0; i < k3; i++) {
            System.out.print(nums3[i] + " ");
        }
        System.out.println();
    }
}
```

## Детальный разбор алгоритма

### Идея: Два указателя (Two Pointers)

Мы используем два индекса (указателя):
1.  **`slow` (медленный):** Указывает на позицию, куда нужно записать следующий элемент, который **не равен** `val`. Этот указатель формирует "чистую" часть массива в начале.
2.  **`fast` (быстрый):** Бегает по всему массиву, проверяя каждый элемент.

### Логика работы
1.  Мы итерируем `fast` от `0` до `nums.length - 1`.
2.  Если `nums[fast] != val`:
    *   Этот элемент нам нужен.
    *   Мы копируем его значение в `nums[slow]`.
    *   Увеличиваем `slow` на 1 (готовим место для следующего нужного элемента).
3.  Если `nums[fast] == val`:
    *   Этот элемент нужно удалить.
    *   Мы ничего не записываем и просто продолжаем движение `fast`.
4.  В конце `slow` будет равно количеству элементов, не равных `val`.

## Пошаговое выполнение на примерах

### Пример 1: `nums = [3, 2, 2, 3]`, `val = 3`

**Инициализация:** `slow = 0`, `fast = 0`.

| Шаг | `fast` | `nums[fast]` | `nums[fast] != val`? | Действие | Состояние `nums` | `slow` |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 0 | 3 | Нет (3 == 3) | Пропуск. | `[3, 2, 2, 3]` | 0 |
| 2 | 1 | 2 | **Да** (2 != 3) | `nums[0] = nums[1]` (2). `slow++`. | `[2, 2, 2, 3]` | 1 |
| 3 | 2 | 2 | **Да** (2 != 3) | `nums[1] = nums[2]` (2). `slow++`. | `[2, 2, 2, 3]` | 2 |
| 4 | 3 | 3 | Нет (3 == 3) | Пропуск. | `[2, 2, 2, 3]` | 2 |

**Результат:** `k = 2`. Первые два элемента: `[2, 2]`.

---

### Пример 2: `nums = [0, 1, 2, 2, 3, 0, 4, 2]`, `val = 2`

**Инициализация:** `slow = 0`, `fast = 0`.

| Шаг | `fast` | `nums[fast]` | `nums[fast] != val`? | Действие | Состояние `nums` (первые 5 индексов) | `slow` |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 0 | 0 | **Да** (0 != 2) | `nums[0] = 0`. `slow++`. | `[0, 1, 2, 2, 3, ...]` | 1 |
| 2 | 1 | 1 | **Да** (1 != 2) | `nums[1] = 1`. `slow++`. | `[0, 1, 2, 2, 3, ...]` | 2 |
| 3 | 2 | 2 | Нет (2 == 2) | Пропуск. | `[0, 1, 2, 2, 3, ...]` | 2 |
| 4 | 3 | 2 | Нет (2 == 2) | Пропуск. | `[0, 1, 2, 2, 3, ...]` | 2 |
| 5 | 4 | 3 | **Да** (3 != 2) | `nums[2] = 3`. `slow++`. | `[0, 1, 3, 2, 3, ...]` | 3 |
| 6 | 5 | 0 | **Да** (0 != 2) | `nums[3] = 0`. `slow++`. | `[0, 1, 3, 0, 3, ...]` | 4 |
| 7 | 6 | 4 | **Да** (4 != 2) | `nums[4] = 4`. `slow++`. | `[0, 1, 3, 0, 4, ...]` | 5 |
| 8 | 7 | 2 | Нет (2 == 2) | Пропуск. | `[0, 1, 3, 0, 4, ...]` | 5 |

**Результат:** `k = 5`. Первые пять элементов: `[0, 1, 3, 0, 4]`.

### Пример 3 (Граничный): `nums = [1]`, `val = 1`

**Инициализация:** `slow = 0`, `fast = 0`.

| Шаг | `fast` | `nums[fast]` | `nums[fast] != val`? | Действие | Состояние `nums` | `slow` |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 0 | 1 | Нет (1 == 1) | Пропуск. | `[1]` | 0 |

**Результат:** `k = 0`. Массив пуст (в рамках возвращаемой длины).

## Почему это решение оптимально?

1.  **Временная сложность $O(N)$**: Мы проходим по массиву ровно один раз. Нет вложенных циклов.
2.  **Пространственная сложность $O(1)$**: Мы используем только две переменные (`slow`, `fast`), независимо от размера массива. Не создается новых объектов.
3.  **In-place**: Изменение происходит непосредственно во входном массиве, что соответствует требованиям задачи и экономит память.

Этот подход является стандартным и наиболее эффективным решением для задачи "Remove Element" на LeetCode.
