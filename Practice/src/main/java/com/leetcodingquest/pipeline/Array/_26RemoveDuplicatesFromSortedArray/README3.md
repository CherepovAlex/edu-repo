# LeetCode 26: Remove Duplicates from Sorted Array

## 📋 Описание задачи

Дан целочисленный массив `nums`, отсортированный в порядке неубывания. Необходимо удалить дубликаты на месте (in-place), чтобы каждый уникальный элемент встречался только один раз. Относительный порядок элементов должен остаться прежним.

Необходимо вернуть количество уникальных элементов `k`. После выполнения функции первые `k` элементов массива `nums` должны содержать уникальные числа в отсортированном порядке. Остальные элементы после индекса `k - 1` можно игнорировать.

### Примеры

**Пример 1:**
```text
Входные данные: nums = [1,1,2]
Выходные данные: 2, nums = [1,2,_]
Пояснение: Ваша функция должна вернуть k = 2, при этом первые два элемента nums должны быть равны 1 и 2 соответственно.
```

**Пример 2:**
```text
Входные данные: nums = [0,0,1,1,1,2,2,3,3,4]
Выходные данные: 5, nums = [0,1,2,3,4,_,_,_,_,_]
Пояснение: Ваша функция должна вернуть k = 5, при этом первые пять элементов nums будут равны 0, 1, 2, 3 и 4 соответственно.
```

### Ограничения
- $1 \le \text{nums.length} \le 3 \times 10^4$
- $-100 \le \text{nums}[i] \le 100$
- `nums` отсортированы в порядке неубывания.

---

## 💡 Стратегия решения

Ключевое условие задачи — массив **уже отсортирован**. Это означает, что все дубликаты расположены рядом друг с другом. Мы можем использовать алгоритм **"Два указателя" (Two Pointers)** для эффективного решения задачи за $O(N)$ времени и $O(1)$ памяти.

### Алгоритм

Мы используем два указателя:
1.  **`slow` (медленный указатель)**: Указывает на позицию, куда нужно записать следующий уникальный элемент. Фактически, он определяет границу уникальной части массива.
2.  **`fast` (быстрый указатель)**: Пробегает по всему массиву, ища новые уникальные элементы.

**Логика работы:**
1.  Если массив пуст, возвращаем 0.
2.  Инициализируем `slow = 1` и `fast = 1`. Первый элемент (`nums[0]`) всегда уникален, поэтому начало уникальной части фиксировано.
3.  Пока `fast` не достиг конца массива:
    -   Сравниваем `nums[fast]` с последним добавленным уникальным элементом `nums[slow - 1]`.
    -   Если элементы **различны**, значит, `nums[fast]` — это новый уникальный элемент.
        -   Записываем `nums[fast]` в позицию `nums[slow]`.
        -   Увеличиваем `slow` на 1 (сдвигаем границу уникальной части).
    -   В любом случае увеличиваем `fast` на 1, чтобы продолжить просмотр массива.
4.  По завершении цикла значение `slow` будет равно количеству уникальных элементов, так как оно указывает на индекс первого свободного места после последнего записанного уникального элемента.

## 🛠️ Реализация на Java

```java
public class Solution {
    /**
     * Удаляет дубликаты из отсортированного массива на месте.
     *
     * @param nums Отсортированный массив целых чисел.
     * @return Количество уникальных элементов k.
     */
    public int removeDuplicates(int[] nums) {
        // Если массив пуст или имеет один элемент, дубликатов нет.
        // Возвращаем длину массива как количество уникальных элементов.
        if (nums.length == 0) {
            return 0;
        }

        // slow указывает на позицию следующего уникального элемента.
        // Первый элемент (индекс 0) всегда уникален, поэтому начинаем с 1.
        int slow = 1;

        // fast пробегает по всему массиву, начиная со второго элемента.
        int fast = 1;

        // Цикл продолжается, пока fast не дойдет до конца массива
        while (fast < nums.length) {
            // Проверяем, отличается ли текущий элемент (fast) от последнего добавленного уникального элемента (slow - 1)
            // Если nums[fast] != nums[slow - 1], значит, nums[fast] — это новый уникальный элемент.
            if (nums[fast] != nums[slow - 1]) {
                // Записываем новый уникальный элемент в позицию slow
                nums[slow] = nums[fast];
                // Увеличиваем slow, чтобы следующему уникальному элементу была зарезервирована следующая позиция
                slow++;
            }
            // Увеличиваем fast, чтобы перейти к следующему элементу массива для проверки
            fast++;
        }

        // slow теперь указывает на индекс первого элемента, который был перезаписан или вышел за границы.
        // Следовательно, количество уникальных элементов равно значению slow.
        return slow;
    }

    public static void main(String[] args) {
        // Тестирование на примерах из условия задачи
        Solution solution = new Solution();

        // Пример 1
        int[] nums1 = {1, 1, 2};
        int k1 = solution.removeDuplicates(nums1);
        System.out.println("Пример 1: k = " + k1);
        System.out.print("Массив: ");
        for (int i = 0; i < k1; i++) {
            System.out.print(nums1[i] + " ");
        }
        System.out.println();

        // Пример 2
        int[] nums2 = {0, 0, 1, 1, 1, 2, 2, 3, 3, 4};
        int k2 = solution.removeDuplicates(nums2);
        System.out.println("Пример 2: k = " + k2);
        System.out.print("Массив: ");
        for (int i = 0; i < k2; i++) {
            System.out.print(nums2[i] + " ");
        }
        System.out.println();
    }
}
```

## 📊 Пошаговый разбор вычислений

### Случай 0: Пустой массив `nums = []`
*(Хотя в ограничениях сказано `1 <= nums.length`, это хороший крайний случай для проверки логики)*

1.  `if (nums.length == 0)` возвращает `true`.
2.  Функция сразу возвращает `0`.
3.  **Результат:** `k = 0`.

### Пример 1: `nums = [1, 1, 2]`
Длина массива `n = 3`.

1.  **Инициализация:**
    -   `slow = 1`
    -   `fast = 1`

2.  **Итерация 1:** `fast = 1`
    -   Условие `fast < 3` верно.
    -   Проверяем: `nums[fast]` (то есть `nums[1]` = 1) != `nums[slow - 1]` (то есть `nums[0]` = 1)?
    -   `1 != 1` — **Ложь** (это дубликат).
    -   Блок `if` не выполняется.
    -   `fast` увеличивается до `2`.
    -   Состояние массива: `[1, 1, 2]` (не изменился), `slow = 1`, `fast = 2`.

3.  **Итерация 2:** `fast = 2`
    -   Условие `fast < 3` верно.
    -   Проверяем: `nums[fast]` (то есть `nums[2]` = 2) != `nums[slow - 1]` (то есть `nums[0]` = 1)?
    -   `2 != 1` — **Истина** (новый уникальный элемент).
    -   Выполняем `nums[slow] = nums[fast]` -> `nums[1] = 2`.
    -   Массив теперь: `[1, 2, 2]`.
    -   `slow` увеличивается до `2`.
    -   `fast` увеличивается до `3`.
    -   Состояние: `slow = 2`, `fast = 3`.

4.  **Итерация 3:** `fast = 3`
    -   Условие `fast < 3` — **Ложь**. Цикл завершается.

5.  **Возврат:**
    -   Возвращаем `slow`, который равен `2`.
    -   Первые 2 элемента массива: `[1, 2]`. Остальные игнорируются.
    -   **Результат:** `k = 2`.

### Пример 2: `nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`
Длина массива `n = 10`.

1.  **Инициализация:**
    -   `slow = 1`
    -   `fast = 1`

2.  **Итерация 1:** `fast = 1` (`nums[1]=0`)
    -   `nums[1]` (0) != `nums[0]` (0)? Ложь.
    -   `fast` -> 2.
    -   Массив: `[0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`

3.  **Итерация 2:** `fast = 2` (`nums[2]=1`)
    -   `nums[2]` (1) != `nums[0]` (0)? Истина.
    -   `nums[1] = 1`. Массив: `[0, 1, 1, 1, 1, 2, 2, 3, 3, 4]`
    -   `slow` -> 2.
    -   `fast` -> 3.

4.  **Итерация 3:** `fast = 3` (`nums[3]=1`)
    -   `nums[3]` (1) != `nums[1]` (1)? Ложь. (Сравниваем с последним уникальным, который теперь на индексе `slow-1`=1)
    -   `fast` -> 4.

5.  **Итерация 4:** `fast = 4` (`nums[4]=1`)
    -   `nums[4]` (1) != `nums[1]` (1)? Ложь.
    -   `fast` -> 5.

6.  **Итерация 5:** `fast = 5` (`nums[5]=2`)
    -   `nums[5]` (2) != `nums[1]` (1)? Истина.
    -   `nums[2] = 2`. Массив: `[0, 1, 2, 1, 1, 2, 2, 3, 3, 4]`
    -   `slow` -> 3.
    -   `fast` -> 6.

7.  **Итерация 6:** `fast = 6` (`nums[6]=2`)
    -   `nums[6]` (2) != `nums[2]` (2)? Ложь.
    -   `fast` -> 7.

8.  **Итерация 7:** `fast = 7` (`nums[7]=3`)
    -   `nums[7]` (3) != `nums[2]` (2)? Истина.
    -   `nums[3] = 3`. Массив: `[0, 1, 2, 3, 1, 2, 2, 3, 3, 4]`
    -   `slow` -> 4.
    -   `fast` -> 8.

9.  **Итерация 8:** `fast = 8` (`nums[8]=3`)
    -   `nums[8]` (3) != `nums[3]` (3)? Ложь.
    -   `fast` -> 9.

10. **Итерация 9:** `fast = 9` (`nums[9]=4`)
    -   `nums[9]` (4) != `nums[3]` (3)? Истина.
    -   `nums[4] = 4`. Массив: `[0, 1, 2, 3, 4, 2, 2, 3, 3, 4]`
    -   `slow` -> 5.
    -   `fast` -> 10.

11. **Итерация 10:** `fast = 10`
    -   Условие `fast < 10` — Ложь. Цикл завершен.

12. **Возврат:**
    -   Возвращаем `slow`, который равен `5`.
    -   Первые 5 элементов: `[0, 1, 2, 3, 4]`.
    -   **Результат:** `k = 5`.

## ⚡ Анализ сложности

1.  **Временная сложность: $O(N)$**
    -   Мы проходим по массиву ровно один раз с помощью указателя `fast`.
    -   Внутренние операции (сравнение и присваивание) выполняются за константное время $O(1)$.

2.  **Пространственная сложность: $O(1)$**
    -   Мы используем только две дополнительные переменные (`slow` и `fast`), независимо от размера входных данных.
    -   Решение работает **in-place**, не создавая новых массивов или коллекций.

3.  **Преимущества подхода:**
    -   **Однопроходный алгоритм:** Не требует повторных проходов или сортировки.
    -   **Минимальная память:** Использует фиксированное количество переменных.
    -   **Сохранение порядка:** Поскольку мы всегда записываем новый уникальный элемент сразу за предыдущим уникальным элементом, относительный порядок сохраняется.
    -   **Безопасность границ:** Проверка `if (nums.length == 0)` предотвращает выход за границы массива, а инициализация `slow = 1` гарантирует, что обращение к `nums[slow-1]` всегда валидно для непустого массива.

Это решение является "золотым стандартом" для данной задачи на LeetCode и часто используется как шаблон для других задач на сжатие массивов или работу с двумя указателями.
