# Remove Element (LeetCode 27) — решение на Java

> Подробный разбор задачи [LeetCode 27. Remove Element](https://leetcode.com/problems/remove-element/) с оптимальным решением, комментариями к каждой строке и пошаговым разбором всех примеров. Материал оформлен как учебный конспект для курса по Java-разработке.

---

## 📋 Условие задачи

Дан целочисленный массив `nums` и целое число `val`. Удалите все вхождения `val` в массиве `nums` **на месте** (in-place). Порядок элементов может быть изменён.

Верните количество элементов массива, которые **не равны** `val`.

Пусть это количество равно `k`. Чтобы решение было принято, нужно:

1. Изменить массив `nums` так, чтобы **первые `k` элементов** содержали элементы, не равные `val`.
2. Остальные элементы массива и его реальный размер — не важны.
3. Вернуть `k`.

### Проверка судьёй

```java
int[] nums = [...];               // Входной массив
int val = ...;                    // Значение, которое нужно удалить
int[] expectedNums = [...];       // Ожидаемый ответ правильной длины
                                  // (отсортирован, без значений, равных val)

int k = removeElement(nums, val); // Вызов вашей реализации

assert k == expectedNums.length;
sort(nums, 0, k);                 // Сортировка первых k элементов nums

for (int i = 0; i < actualLength; i++) {
    assert nums[i] == expectedNums[i];
}
```

Если все утверждения верны — решение принято.

### Примеры

#### Пример 1
```
Вход:  nums = [3, 2, 2, 3], val = 3
Выход: 2, nums = [2, 2, _, _]
```
**Пояснение:** функция должна вернуть `k = 2`, при этом первые два элемента `nums` равны `2`. Значения за пределами `k` не важны (обозначены `_`).

#### Пример 2
```
Вход:  nums = [0, 1, 2, 2, 3, 0, 4, 2], val = 2
Выход: 5, nums = [0, 1, 4, 0, 3, _, _, _]
```
**Пояснение:** функция должна вернуть `k = 5`, первые пять элементов `nums` содержат `0, 0, 1, 3, 4` (в любом порядке). Значения за пределами `k` не важны.

#### Ограничения
```
0 <= nums.length <= 100
0 <= nums[i]      <= 50
0 <= val          <= 100
```

## 💡 Идея решения — метод двух указателей

Заведём указатель `k` — позицию, **куда нужно записать следующий «хороший» элемент** (не равный `val`).

Проходим массив одним циклом:

- если `nums[i] != val` → копируем `nums[i]` в позицию `k` и увеличиваем `k`;
- если `nums[i] == val` → пропускаем элемент.

В конце `k` совпадает с количеством «хороших» элементов, а первые `k` ячеек массива содержат именно их.

### Сложность

| Ресурс | Оценка | Почему |
|--------|--------|--------|
| **Время**  | `O(n)` | Один проход по массиву, внутри — O(1) операций |
| **Память** | `O(1)` | Только одна переменная `k`; массив модифицируется на месте |

Это оптимально: массив нужно просмотреть как минимум один раз, а дополнительная память не требуется.

> **Альтернатива.** Можно использовать два указателя — слева (`left`) и справа (`right`) — с обменом элементов. Такое решение тоже даёт `O(n)`/`O(1)`, но требует обменов. Вариант с одним указателем `k` проще и выполняет только копирование, что корректно, так как порядок элементов не важен.

## 🧩 Полный код решения

```java
public class Solution1 {

    public int removeElement(int[] nums, int val) {
        // k — указатель на позицию, куда запишем следующий элемент, не равный val
        int k = 0;

        // Проходим по всем элементам массива от начала до конца
        for (int i = 0; i < nums.length; i++) {
            // Если текущий элемент НЕ равен удаляемому значению
            if (nums[i] != val) {
                // Записываем его в позицию k (в начало «хорошей» части массива)
                nums[k] = nums[i];
                // Сдвигаем указатель k вправо — следующий хороший элемент пойдёт следом
                k++;
            }
            // Если nums[i] == val — просто пропускаем его, ничего не записываем
        }

        // k теперь равно количеству элементов, не равных val
        return k;
    }

    public static void main(String[] args) {
        // Создаём объект решения
        Solution1 sol = new Solution1();

        // Тест 1
        int[] nums1 = {3, 2, 2, 3};
        int k1 = sol.removeElement(nums1, 3);
        System.out.println("k = " + k1 + ", nums = " + java.util.Arrays.toString(nums1));

        // Тест 2
        int[] nums2 = {0, 1, 2, 2, 3, 0, 4, 2};
        int k2 = sol.removeElement(nums2, 2);
        System.out.println("k = " + k2 + ", nums = " + java.util.Arrays.toString(nums2));

        // Тест 3 (пустой массив)
        int[] nums3 = {};
        int k3 = sol.removeElement(nums3, 5);
        System.out.println("k = " + k3 + ", nums = " + java.util.Arrays.toString(nums3));
    }
}
```

### Комментарий к каждой строке

| Строка | Что делает |
|--------|-----------|
| `int k = 0;` | Инициализируем указатель записи `k = 0` — первый «хороший» элемент попадёт в начало массива |
| `for (int i = 0; i < nums.length; i++)` | Просматриваем массив по индексу `i` от 0 до `nums.length - 1` |
| `if (nums[i] != val)` | Проверяем, что текущий элемент нужно сохранить |
| `nums[k] = nums[i];` | Копируем «хороший» элемент в позицию `k` |
| `k++;` | Сдвигаем указатель записи на следующую позицию |
| `return k;` | Возвращаем итоговое количество «хороших» элементов |

## 🔍 Пошаговый разбор Пример 1

**Вход:** `nums = [3, 2, 2, 3]`, `val = 3`

| `i` | `nums[i]` | `nums[i] != 3`? | Действие | `k` после | Массив после шага |
|-----|-----------|-----------------|----------|-----------|-------------------|
| 0 | 3 | нет | пропуск | 0 | `[3, 2, 2, 3]` |
| 1 | 2 | да | `nums[0] = 2`, `k = 1` | 1 | `[2, 2, 2, 3]` |
| 2 | 2 | да | `nums[1] = 2`, `k = 2` | 2 | `[2, 2, 2, 3]` |
| 3 | 3 | нет | пропуск | 2 | `[2, 2, 2, 3]` |

**Результат:** `k = 2`, первые два элемента `[2, 2]` — верно. Остальные ячейки не важны.

## 🔍 Пошаговый разбор Пример 2

**Вход:** `nums = [0, 1, 2, 2, 3, 0, 4, 2]`, `val = 2`

| `i` | `nums[i]` | `!= 2`? | Действие | `k` | Массив после шага |
|-----|-----------|---------|----------|-----|-------------------|
| 0 | 0 | да | `nums[0] = 0`, `k = 1` | 1 | `[0, 1, 2, 2, 3, 0, 4, 2]` |
| 1 | 1 | да | `nums[1] = 1`, `k = 2` | 2 | `[0, 1, 2, 2, 3, 0, 4, 2]` |
| 2 | 2 | нет | пропуск | 2 | `[0, 1, 2, 2, 3, 0, 4, 2]` |
| 3 | 2 | нет | пропуск | 2 | `[0, 1, 2, 2, 3, 0, 4, 2]` |
| 4 | 3 | да | `nums[2] = 3`, `k = 3` | 3 | `[0, 1, 3, 2, 3, 0, 4, 2]` |
| 5 | 0 | да | `nums[3] = 0`, `k = 4` | 4 | `[0, 1, 3, 0, 3, 0, 4, 2]` |
| 6 | 4 | да | `nums[4] = 4`, `k = 5` | 5 | `[0, 1, 3, 0, 4, 0, 4, 2]` |
| 7 | 2 | нет | пропуск | 5 | `[0, 1, 3, 0, 4, 0, 4, 2]` |

**Результат:** `k = 5`, первые 5 элементов: `[0, 1, 3, 0, 4]`.

Проверка: это те же значения, что в ожидаемом `[0, 0, 1, 3, 4]`. Порядок отличается, но судья сортирует первые `k` элементов перед сравнением — значит ответ корректен. ✅

## 🔍 Пошаговый разбор Пример 3 (граничный случай)

**Вход:** `nums = []`, `val = 5` — пустой массив допустим по условию `0 <= nums.length`.

| `i` | — | — | — | `k` |
|-----|---|--------|---|-----|
| цикл не выполняется | | | | 0 |

**Результат:** `k = 0`, массив пуст — верно.

### Дополнительный случай: значения `val` нет в массиве

Например, `nums = [1, 2, 3]`, `val = 5`. Тогда на каждом шаге условие `nums[i] != val` истинно, запись идёт «сама в себя» (`k == i`), и в конце `k = 3`. Это тоже корректно — все элементы сохраняются.

## ✅ Итог

- Используется **метод двух указателей**: `i` — для чтения, `k` — для записи.
- Решение **модифицирует массив на месте**, не создавая новых массивов.
- **Время `O(n)`**, **память `O(1)`** — оптимально по обоим критериям.
- Порядок элементов может измениться — условие задачи это допускает.
- Решение корректно работает на пустом массиве и на массиве без вхождений `val`.
