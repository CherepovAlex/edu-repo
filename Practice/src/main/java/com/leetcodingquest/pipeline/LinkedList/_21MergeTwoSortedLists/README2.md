# Задача 21. Merge Two Sorted Lists

> **Платформа:** LeetCode  
> **Сложность:** Easy  
> **Темы:** Linked List, Recursion, Two Pointers  
> **Язык:** Java

---

## 📋 Условие задачи

Вам даны заголовки двух отсортированных связных списков `list1` и `list2`.

Объедините два списка в один отсортированный список. Список должен быть создан путём объединения узлов первых двух списков.

Вернуть голову объединённого связного списка.

### Пример 1

```
Вход:  list1 = [1,2,4], list2 = [1,3,4]
Выход: [1,1,2,3,4,4]
```

### Пример 2

```
Вход:  list1 = [], list2 = []
Выход: []
```

### Пример 3

```
Вход:  list1 = [], list2 = [0]
Выход: [0]
```

### Ограничения

- Количество узлов в обоих списках находится в диапазоне `[0, 50]`.
- `-100 <= Node.val <= 100`
- И `list1`, и `list2` отсортированы в **неубывающем** порядке.

---

## 💡 Подход к решению

Нам нужно слить два **отсортированных** связных списка в один отсортированный, **переиспользуя существующие узлы** (не создавая новые). Это классическая задача на слияние (как в merge sort).

### Оптимальный подход — итеративный с "фиктивным" (dummy) узлом

1. Создаём фиктивный узел `dummy` — он не входит в результат, но упрощает код (не нужно отдельно обрабатывать случай с пустым результатом в начале).
2. Держим указатель `current`, который указывает на последний узел уже собранного результата.
3. Сравниваем `list1.val` и `list2.val`:
   - если `list1.val <= list2.val` — присоединяем узел из `list1`, двигаем `list1` вперёд;
   - иначе — присоединяем узел из `list2`, двигаем `list2` вперёд.
4. Двигаем `current` вперёд.
5. Когда один из списков закончился — присоединяем остаток второго списка (он уже отсортирован).
6. Возвращаем `dummy.next` — настоящую голову результата.

### Сложность

| Параметр | Значение | Объяснение |
|----------|----------|------------|
| **Время** | `O(n + m)` | Каждый узел обоих списков посещается ровно один раз |
| **Память** | `O(1)` | Только несколько указателей, узлы переиспользуются |

### Почему не рекурсия?

Рекурсия тоже даёт `O(n+m)` по времени, но использует `O(n+m)` стека вызовов — хуже по памяти. Поэтому **итеративный вариант оптимальнее**.

## 🧩 Полный код решения

```java
public class Solution1 {

    // Метод сливает два отсортированных списка в один отсортированный
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        // Создаём фиктивный узел-заглушку; он не будет частью результата,
        // но позволяет не писать отдельную проверку "а есть ли уже голова?"
        ListNode dummy = new ListNode(0);
        // current — указатель на последний узел уже собранного результата;
        // начинаем с фиктивного узла
        ListNode current = dummy;

        // Пока оба списка не закончились — выбираем меньший элемент
        while (list1 != null && list2 != null) {
            // Если значение в первом списке меньше или равно — берём узел оттуда
            // (<= обеспечивает стабильность: при равенстве берём из list1)
            if (list1.val <= list2.val) {
                // Присоединяем узел list1 к хвосту результата
                current.next = list1;
                // Сдвигаем list1 на следующий узел
                list1 = list1.next;
            } else {
                // Иначе берём узел из list2
                current.next = list2;
                // Сдвигаем list2 на следующий узел
                list2 = list2.next;
            }
            // Двигаем указатель хвоста на только что добавленный узел
            current = current.next;
        }

        // Один из списков закончился. Оставшийся уже отсортирован —
        // просто присоединяем его целиком к хвосту
        // (если list1 == null — присоединится list2, и наоборот)
        current.next = (list1 != null) ? list1 : list2;

        // Возвращаем настоящую голову результата (пропускаем фиктивный узел)
        return dummy.next;
    }

    // Вспомогательный метод для удобной сборки списка из массива
    private static ListNode buildList(int[] values) {
        // Фиктивный узел для упрощения сборки
        ListNode dummy = new ListNode(0);
        // Указатель на текущий хвост
        ListNode current = dummy;
        // Проходим по всем значениям
        for (int v : values) {
            // Добавляем новый узел в конец
            current.next = new ListNode(v);
            // Сдвигаем хвост
            current = current.next;
        }
        // Возвращаем голову без фиктивного узла
        return dummy.next;
    }

    // Вспомогательный метод для печати списка в формате [a,b,c]
    private static void printList(ListNode head) {
        // Открываем квадратную скобку
        System.out.print("[");
        // Идём по списку
        while (head != null) {
            // Печатаем значение текущего узла
            System.out.print(head.val);
            // Если есть следующий — печатаем запятую-разделитель
            if (head.next != null) System.out.print(",");
            // Переходим к следующему узлу
            head = head.next;
        }
        // Закрываем квадратную скобку и переводим строку
        System.out.println("]");
    }

    public static void main(String[] args) {
        // Создаём экземпляр решения для вызова нестатического метода
        Solution1 solution = new Solution1();

        // ===== Пример 1 =====
        System.out.println("Пример 1:");
        // Собираем list1 = [1,2,4]
        ListNode l1 = buildList(new int[]{1, 2, 4});
        // Собираем list2 = [1,3,4]
        ListNode l2 = buildList(new int[]{1, 3, 4});
        // Сливаем списки
        ListNode merged1 = solution.mergeTwoLists(l1, l2);
        // Печатаем результат (ожидаем [1,1,2,3,4,4])
        printList(merged1);

        // ===== Пример 2 =====
        System.out.println("Пример 2:");
        // Оба списка пустые
        ListNode merged2 = solution.mergeTwoLists(null, null);
        // Печатаем результат (ожидаем [])
        printList(merged2);

        // ===== Пример 3 =====
        System.out.println("Пример 3:");
        // list1 пустой, list2 = [0]
        ListNode merged3 = solution.mergeTwoLists(null, buildList(new int[]{0}));
        // Печатаем результат (ожидаем [0])
        printList(merged3);
    }
}

class ListNode {
    // Значение узла
    int val;
    // Указатель на следующий узел
    ListNode next;

    // Пустой конструктор
    ListNode() {
    }

    // Конструктор с одним значением
    ListNode(int val) {
        this.val = val;
    }

    // Конструктор со значением и следующим узлом
    ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }
}
```

## 🔍 Пошаговый разбор примеров

### Пример 1: `list1 = [1,2,4]`, `list2 = [1,3,4]`

**Начальное состояние:**

```
dummy -> ?
current = dummy

list1: 1 -> 2 -> 4 -> null
list2: 1 -> 3 -> 4 -> null
```

| Шаг | Сравнение | Действие | Результат (после current) | list1 | list2 |
|-----|-----------|----------|---------------------------|-------|-------|
| 1 | 1 ≤ 1 | берём из list1 | `dummy -> 1` | 2→4 | 1→3→4 |
| 2 | 2 > 1 | берём из list2 | `dummy -> 1 -> 1` | 2→4 | 3→4 |
| 3 | 2 ≤ 3 | берём из list1 | `... -> 1 -> 2` | 4 | 3→4 |
| 4 | 4 > 3 | берём из list2 | `... -> 2 -> 3` | 4 | 4 |
| 5 | 4 ≤ 4 | берём из list1 | `... -> 3 -> 4` | null | 4 |
| — | list1 == null, выход из while | `current.next = list2` | `... -> 4 -> 4` | null | 4 |

**Итог:** `dummy.next` = `1 -> 1 -> 2 -> 3 -> 4 -> 4` ✅

---

### Пример 2: `list1 = []`, `list2 = []`

```
dummy
current = dummy
list1 = null
list2 = null
```

1. Цикл `while (list1 != null && list2 != null)` — **не выполняется**, потому что оба `null`.
2. `current.next = (list1 != null) ? list1 : list2` → `null` (оба `null`, выбирается `list2 == null`).
3. `return dummy.next` → `null`.

**Результат при печати:** `[]` ✅

---

### Пример 3: `list1 = []`, `list2 = [0]`

```
dummy
current = dummy
list1 = null
list2: 0 -> null
```

1. Цикл `while (list1 != null && list2 != null)` — **не выполняется**, т.к. `list1 == null`.
2. `current.next = (list1 != null) ? list1 : list2` → `list1 == null`, значит берём `list2` → `current.next = (узел 0)`.
3. `return dummy.next` → узел `0`.

**Результат при печати:** `[0]` ✅

## 📌 Ключевые моменты для запоминания

1. **Dummy-узел** — стандартный трюк: избавляет от проверки «а голова уже есть?» и делает код чище.
2. **Условие `<=`** важно для **стабильности** слияния (при равных значениях берём из первого списка) — это не влияет на корректность, но является хорошей практикой.
3. **Присоединение остатка** одним указателем (`current.next = ...`) корректно, потому что остаток уже отсортирован и связан между собой.
4. **`O(1)` памяти** достигается переиспользованием узлов — мы не создаём `new ListNode` для элементов результата.
5. **`O(n+m)` времени** — каждый узел обоих списков посещается ровно один раз.

## 🧪 Альтернативные варианты (для расширения кругозора)

### Рекурсивное решение

```java
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // Базовый случай: если один из списков пуст — возвращаем другой
    if (list1 == null) return list2;
    if (list2 == null) return list1;

    // Если голова list1 меньше — рекурсивно сливаем остаток
    if (list1.val <= list2.val) {
        list1.next = mergeTwoLists(list1.next, list2);
        return list1;
    } else {
        list2.next = mergeTwoLists(list1, list2.next);
        return list2;
    }
}
```

**Плюсы:** компактный и красивый код.  
**Минусы:** `O(n+m)` дополнительной памяти под стек вызовов — не оптимально по пространству.
