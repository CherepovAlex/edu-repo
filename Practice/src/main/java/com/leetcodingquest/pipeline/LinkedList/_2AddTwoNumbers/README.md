LeetCode №2. Сложение двух чисел (Add Two Numbers) — подробный урок по Java
Разберём задачу как на занятии по Java: сначала поймём условие, затем разработаем алгоритм, напишем оптимальное решение, прокомментируем каждую строку кода и вручную проследим вычисления для всех трёх примеров.
Главная идея задачи: мы складываем числа поразрядно, как в обычной арифметике в столбик, только цифры хранятся в связанных списках, начиная с младшего разряда.
1. Понимаем условие задачи
Нам даны два односвязных списка — l1 и l2.
Каждый узел списка содержит:
- val — одну цифру числа от 0 до 9;
- next — ссылку на следующий узел списка.
Например, список:
Связанный список [2, 4, 3]
2
val
4
val
3
val
null

Цифры записаны в обратном порядке. Поэтому список [2, 4, 3] представляет число 342, а не 243.

Почему 342? Потому что:
- первый узел 2 — единицы;
- второй узел 4 — десятки;
- третий узел 3 — сотни.
Аналогично, список [5, 6, 4] представляет число 465.
Нужно сложить эти числа и вернуть результат тоже в виде связанного списка с цифрами в обратном порядке.
\[
342 + 465 = 807
\]

Число 807 в обратном порядке — [7, 0, 8].
2. Как решить задачу без преобразования списков в числа?
Можно было бы попытаться преобразовать списки в обычные числа, сложить их и создать новый список. Но это не лучший подход: числа могут быть очень большими — в каждом списке допускается до 100 узлов. Такое число может не поместиться даже в long.
Поэтому используем поразрядное сложение с переносом.
Вспомним обычное сложение:
  342
+ 465
-----
  807


Складываем справа налево:
1. \(2 + 5 = 7\) — записываем 7.
2. \(4 + 6 = 10\) — записываем 0, переносим 1.
3. \(3 + 4 + 1 = 8\) — записываем 8.
Связанные списки уже хранят цифры в нужном для этого порядке, поэтому нам не требуется разворачивать списки или идти с конца.
3. Алгоритм решения
Для реализации нам понадобятся три основные переменные:
- l1 — текущий узел первого списка;
- l2 — текущий узел второго списка;
- carry — перенос из предыдущего разряда.
Также создадим результирующий список, в который будем записывать цифры суммы.
Что такое перенос (carry)?
Предположим, мы складываем цифры 7 и 8:
\[
7 + 8 = 15
\]

В текущий разряд записываем только последнюю цифру — 5. Единицу переносим в следующий разряд.
Это можно выразить двумя формулами:
\[
digit = sum \bmod 10
\]

\[
carry = \lfloor sum / 10 \rfloor
\]

Здесь:
- sum — сумма двух цифр и предыдущего переноса;
- % 10 — остаток от деления на 10, то есть цифра текущего разряда;
- / 10 для целых чисел Java — целочисленное деление, дающее перенос.
Например, если sum = 15, то digit = 5, а carry = 1.
Порядок работы алгоритма
1

Инициализируем результат
Создаём фиктивный узел dummy и указатель current, который будет указывать на последний узел построенного списка.



2

Складываем текущие цифры
Берём значения из l1 и l2. Если один список закончился, вместо его цифры используем 0. Прибавляем carry.



3

Создаём узел результата
Записываем sum % 10 в новый узел и присоединяем его к результирующему списку.



4

Обновляем перенос и указатели
Вычисляем carry = sum / 10 и переходим к следующим узлам обоих списков, если они существуют.



5

Проверяем завершение
Продолжаем, пока остались цифры хотя бы в одном списке или существует ненулевой перенос.



4. Оптимальное решение на Java
Ниже — готовое решение, которое можно вставить в LeetCode. Используется стандартное определение ListNode, уже предоставленное платформой.

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // Фиктивный узел перед началом результирующего списка.
        ListNode dummy = new ListNode(0);

        // Указатель на последний узел результирующего списка.
        ListNode current = dummy;

        // Перенос из предыдущего разряда.
        int carry = 0;

        // Продолжаем, пока есть цифры или остался перенос.
        while (l1 != null || l2 != null || carry != 0) {

            // Если первый список закончился, берём 0.
            int x = (l1 != null) ? l1.val : 0;

            // Если второй список закончился, берём 0.
            int y = (l2 != null) ? l2.val : 0;

            // Складываем цифры и перенос предыдущего разряда.
            int sum = x + y + carry;

            // Получаем цифру текущего разряда.
            int digit = sum % 10;

            // Вычисляем перенос в следующий разряд.
            carry = sum / 10;

            // Создаём узел с полученной цифрой.
            current.next = new ListNode(digit);

            // Перемещаем указатель на новый последний узел.
            current = current.next;

            // Переходим к следующему узлу первого списка,
            // если он существует.
            if (l1 != null) {
                l1 = l1.next;
            }

            // Переходим к следующему узлу второго списка,
            // если он существует.
            if (l2 != null) {
                l2 = l2.next;
            }
        }

        // Возвращаем первый настоящий узел результата,
        // пропуская фиктивный узел dummy.
        return dummy.next;
    }
}



5. Разбор каждой строки кода
Теперь рассмотрим ключевые конструкции подробнее, чтобы было понятно не только что делает программа, но и почему она работает.
5.1. Создание фиктивного узла
ListNode dummy = new ListNode(0);
ListNode current = dummy;


dummy — это технический узел, который упрощает построение результата. Он не является частью возвращаемого числа.
Изначально структура выглядит так:
0
dummy
null

current и dummy указывают на один и тот же узел.

Почему это удобно? Потому что каждый новый узел можно добавлять одинаковым способом — через current.next. Не нужно отдельно обрабатывать создание первого узла.
Когда вычисления закончатся, вернём dummy.next, то есть первый настоящий узел результата.
5.2. Переменная переноса
int carry = 0;


В начале перенос равен нулю, потому что перед первым разрядом ещё ничего не складывали.
После сложения очередных цифр он может стать равным 1.
5.3. Условие цикла
while (l1 != null || l2 != null || carry != 0)


Цикл работает, пока выполняется хотя бы одно из условий:
- l1 != null — в первом списке ещё есть цифры;
- l2 != null — во втором списке ещё есть цифры;
- carry != 0 — остался перенос, который нужно записать.
Последнее условие особенно важно. Например, \(9 + 1 = 10\). После обработки последнего узла может остаться перенос 1. Тогда нужно создать дополнительный узел с цифрой 1.
5.4. Безопасное получение цифр
int x = (l1 != null) ? l1.val : 0;
int y = (l2 != null) ? l2.val : 0;


Здесь используется тернарный оператор:
условие ? значение_если_истина : значение_если_ложь


Например, если l1 существует, в x записывается l1.val. Если l1 == null, в x записывается 0.
Это позволяет складывать списки разной длины, не обращаясь к несуществующим узлам.
5.5. Вычисление суммы, цифры и переноса
int sum = x + y + carry;
int digit = sum % 10;
carry = sum / 10;


Допустим, x = 9, y = 9, carry = 1.
Тогда:
- sum = 9 + 9 + 1 = 19;
- digit = 19 % 10 = 9;
- carry = 19 / 10 = 1.
В текущий разряд записывается 9, а единица переносится дальше.
5.6. Добавление узла результата
current.next = new ListNode(digit);
current = current.next;


Первая строка создаёт новый узел и присоединяет его после текущего узла.
Вторая строка перемещает current на только что созданный узел, чтобы следующий результат добавлялся после него.
5.7. Переход к следующим узлам
if (l1 != null) {
    l1 = l1.next;
}

if (l2 != null) {
    l2 = l2.next;
}


Указатели двигаются по исходным спискам независимо друг от друга. Если один список короче другого, его указатель становится null, а алгоритм продолжает складывать цифры оставшегося списка с нулями.
5.8. Возврат результата
return dummy.next;


Мы не возвращаем dummy, потому что он содержит служебный ноль. Возвращаем узел, следующий за ним, — начало настоящего результата.

9. Сложность алгоритма
Обозначим:
- \(m\) — количество узлов в первом списке;
- \(n\) — количество узлов во втором списке.
Временная сложность — \(O(\max(m,n))\)
Каждый узел обоих списков обрабатывается не более одного раза. После окончания более короткого списка мы продолжаем обрабатывать оставшиеся цифры и, при необходимости, перенос.
Следовательно, число итераций пропорционально длине более длинного списка.
Пространственная сложность
Здесь важно различать два вида памяти.
- Дополнительная память алгоритма без учёта результата: \(O(1)\). Мы используем только несколько переменных: dummy, current, carry, x, y, sum и digit.
- Память с учётом результирующего списка: \(O(\max(m,n))\). Для суммы требуется не больше \(\max(m,n)+1\) узлов.
Таким образом, решение оптимально по времени и использует постоянную дополнительную память, не считая списка результата, который необходимо вернуть.
10. Частые ошибки при решении
Ошибка 1. Считать цифры в обычном порядке
[2, 4, 3] — это 342, а не 243. Цифры начинаются с единиц.


Ошибка 2. Забыть перенос
Нельзя ограничиться x + y. Нужно складывать x + y + carry, иначе результат будет неправильным при суммах от 10 до 19.


Ошибка 3. Остановить цикл, когда закончился один список
Списки могут иметь разную длину. Продолжать нужно, пока остаются цифры хотя бы в одном списке или перенос.


Ошибка 4. Не обработать последний перенос
При сложении [9] + [1] результат должен быть [0, 1]. Если проверять только наличие узлов, последняя единица потеряется.


Ошибка 5. Вернуть dummy вместо dummy.next
dummy — служебный узел. Если вернуть его, в ответ попадёт лишний ноль в начале списка.

12. Что нужно запомнить
Для LeetCode №2 достаточно усвоить четыре ключевые идеи:
1. Цифры хранятся в обратном порядке, поэтому мы начинаем сложение с первых узлов.
2. Перенос обрабатывается на каждой итерации с помощью carry.
3. Фиктивный узел dummy упрощает построение списка, позволяя не обрабатывать первый узел отдельно.
4. Цикл учитывает и остаточный перенос, чтобы не потерять последнюю цифру суммы.
Это классическая задача на связные списки, указатели и арифметику. Её шаблон пригодится и в других задачах, где необходимо последовательно обрабатывать элементы нескольких списков и формировать новый список без использования дополнительных массивов.
