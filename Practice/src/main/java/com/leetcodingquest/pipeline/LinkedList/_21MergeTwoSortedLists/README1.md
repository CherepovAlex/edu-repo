## 1. Условие задачи

Даны головы двух отсортированных односвязных списков `list1` и `list2`.

Необходимо объединить их в один отсортированный список. Результат должен быть построен путём объединения узлов исходных списков.

Нужно вернуть голову объединённого списка.

### Пример 1

**Входные данные:**

```text
list1 = [1, 2, 4]
list2 = [1, 3, 4]
```

**Выходные данные:**

```text
[1, 1, 2, 3, 4, 4]
```

### Пример 2

**Входные данные:**

```text
list1 = []
list2 = []
```

**Выходные данные:**

```text
[]
```

### Пример 3

**Входные данные:**

```text
list1 = []
list2 = [0]
```

**Выходные данные:**

```text
[0]
```

### Ограничения

- Количество узлов в обоих списках находится в диапазоне `[0, 50]`.
- `-100 <= Node.val <= 100`.
- Оба списка отсортированы в неубывающем порядке.

Неубывающий порядок означает, что каждое следующее значение больше или равно предыдущему. Поэтому одинаковые значения разрешены.

## 2. Что такое связанный список

Односвязный список состоит из узлов. Каждый узел содержит:

- `val` — значение узла;
- `next` — ссылку на следующий узел.

Например, список `[1, 2, 4]` выглядит так:

```text
head
 |
 v
[1] -> [2] -> [4] -> null
```

`null` означает, что следующего узла нет и список закончился.

Если переменная `list1` указывает на первый узел, то:

- `list1.val` — значение первого узла;
- `list1.next` — ссылка на второй узел;
- `list1.next.next` — ссылка на третий узел.

Например:

```java
list1 = list1.next;
```

Эта инструкция передвигает ссылку `list1` на следующий узел. Сам узел не перемещается в памяти и не удаляется.

### Класс ListNode

```java
class ListNode {
    int val;
    ListNode next;

    ListNode() {
    }

    ListNode(int val) {
        this.val = val;
    }

    ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }
}
```

Разберём поля и конструкторы.

- `int val` — целочисленное значение узла.
- `ListNode next` — ссылка на следующий узел.
- `ListNode()` — конструктор без параметров.
- `ListNode(int val)` — создаёт узел с заданным значением.
- `ListNode(int val, ListNode next)` — создаёт узел с заданным значением и ссылкой на следующий узел.

Например:

```java
ListNode node3 = new ListNode(4);
ListNode node2 = new ListNode(2, node3);
ListNode node1 = new ListNode(1, node2);
```

Создаётся связанный список:

```text
node1
  |
  v
[1] -> [2] -> [4] -> null
```

## 3. Идея алгоритма

Поскольку оба исходных списка уже отсортированы, сортировать их заново не нужно.

Достаточно сравнивать первые ещё не обработанные узлы двух списков и каждый раз выбирать узел с меньшим значением.

Например, если текущие значения равны `2` и `3`, выбираем `2`. Если текущие значения равны `4` и `1`, выбираем `1`.

### Какие переменные используются

В алгоритме используются четыре ссылки:

| Переменная | Назначение |
|---|---|
| `list1` | Указывает на текущий необработанный узел первого списка |
| `list2` | Указывает на текущий необработанный узел второго списка |
| `dummy` | Вспомогательный узел перед началом результата |
| `tail` | Указывает на последний узел сформированного результата |

### Зачем нужен dummy

Создадим вспомогательный узел:

```java
ListNode dummy = new ListNode(-1);
ListNode tail = dummy;
```

Начальное состояние:

```text
dummy, tail
     |
     v
   [-1] -> null
```

`dummy` и `tail` ссылаются на один и тот же объект. Второй узел не создаётся.

Значение `-1` является техническим и не попадёт в ответ. В конце вернём `dummy.next`, то есть первый настоящий узел результата.

Преимущество `dummy`: не нужно отдельно обрабатывать добавление первого элемента в результирующий список.

### Алгоритм по шагам

1. Создать вспомогательный узел `dummy`.
2. Установить `tail = dummy`.
3. Пока оба списка не закончились:
   - сравнить `list1.val` и `list2.val`;
   - выбрать узел с меньшим значением;
   - присоединить его к результату;
   - передвинуть соответствующий исходный список;
   - передвинуть `tail` на конец результата.
4. После цикла присоединить остаток непустого списка.
5. Вернуть `dummy.next`.

Если значения равны, можно выбрать любой из двух узлов. В нашем решении используется условие `list1.val <= list2.val`, поэтому при равенстве сначала выбирается узел из `list1`.

## 4. Полное решение на Java

Ниже приведён самостоятельный вариант, который можно запустить в IntelliJ IDEA.

Сохраните его в файле `Solution1.java`.

```java
public class Solution1 {

    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {

        // Создаём вспомогательный узел перед началом результата.
        ListNode dummy = new ListNode(-1);

        // tail указывает на последний узел сформированного списка.
        ListNode tail = dummy;

        // Пока в обоих списках есть необработанные узлы.
        while (list1 != null && list2 != null) {

            // Если значение первого списка меньше или равно второму.
            if (list1.val <= list2.val) {

                // Присоединяем текущий узел первого списка.
                tail.next = list1;

                // Перемещаем list1 к следующему узлу.
                list1 = list1.next;

            } else {

                // Присоединяем текущий узел второго списка.
                tail.next = list2;

                // Перемещаем list2 к следующему узлу.
                list2 = list2.next;
            }

            // Передвигаем конец результата на добавленный узел.
            tail = tail.next;
        }

        // Присоединяем остаток list1, если он ещё существует.
        if (list1 != null) {
            tail.next = list1;
        }

        // Присоединяем остаток list2, если он ещё существует.
        if (list2 != null) {
            tail.next = list2;
        }

        // Возвращаем первый настоящий узел, пропуская dummy.
        return dummy.next;
    }

    public static void main(String[] args) {

        // Создаём объект решения для вызова нестатического метода.
        Solution1 solution = new Solution1();

        // Пример 1: создаём первый список [1, 2, 4].
        ListNode list1 = new ListNode(
                1, new ListNode(2, new ListNode(4)));

        // Пример 1: создаём второй список [1, 3, 4].
        ListNode list2 = new ListNode(
                1, new ListNode(3, new ListNode(4)));

        // Объединяем два списка.
        ListNode result1 = solution.mergeTwoLists(list1, list2);

        // Выводим результат первого примера.
        System.out.print("Пример 1: ");
        printList(result1);

        // Пример 2: оба списка пустые.
        ListNode empty1 = null;
        ListNode empty2 = null;

        // Объединяем пустые списки.
        ListNode result2 = solution.mergeTwoLists(empty1, empty2);

        // Выводим результат второго примера.
        System.out.print("Пример 2: ");
        printList(result2);

        // Пример 3: первый список пустой.
        ListNode empty3 = null;

        // Второй список содержит один узел со значением 0.
        ListNode list3 = new ListNode(0);

        // Объединяем пустой список со списком [0].
        ListNode result3 = solution.mergeTwoLists(empty3, list3);

        // Выводим результат третьего примера.
        System.out.print("Пример 3: ");
        printList(result3);
    }

    // Вспомогательный метод для вывода списка в консоль.
    public static void printList(ListNode head) {

        // Если голова равна null, список пуст.
        if (head == null) {
            System.out.println("[]");
            return;
        }

        // Начинаем обход с первого узла.
        ListNode current = head;

        // Идём по списку, пока не встретим null.
        while (current != null) {

            // Выводим значение текущего узла.
            System.out.print(current.val);

            // Если следующий узел существует, выводим стрелку.
            if (current.next != null) {
                System.out.print(" -> ");
            }

            // Переходим к следующему узлу.
            current = current.next;
        }

        // Завершаем строку вывода.
        System.out.println();
    }
}

// Класс узла односвязного списка.
class ListNode {

    // Значение, хранящееся в узле.
    int val;

    // Ссылка на следующий узел.
    ListNode next;

    // Конструктор для создания узла без параметров.
    ListNode() {
    }

    // Конструктор для создания узла с заданным значением.
    ListNode(int val) {
        this.val = val;
    }

    // Конструктор для создания узла со значением и следующим узлом.
    ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }
}
```

### Почему код оптимален

- Каждый исходный узел обрабатывается не более одного раза.
- Списки не сортируются повторно.
- Новые узлы для каждого значения не создаются.
- Используется один вспомогательный узел `dummy`.
- Дополнительная память не зависит от количества элементов.

## 5. Разбор основных строк кода

### 5.1. Создание вспомогательного узла

```java
ListNode dummy = new ListNode(-1);
ListNode tail = dummy;
```

Первая строка создаёт узел со значением `-1`.

Вторая строка присваивает переменной `tail` ссылку на тот же объект. Она не создаёт новый узел.

В начале `dummy` и `tail` указывают на один объект. Когда мы присоединяем первый узел, `dummy.next` становится ссылкой на начало результата.

### 5.2. Условие цикла

```java
while (list1 != null && list2 != null)
```

Цикл выполняется, пока оба списка содержат текущие узлы.

- `list1 != null` — первый список ещё не закончился.
- `list2 != null` — второй список ещё не закончился.
- `&&` — логическое «И», поэтому оба условия должны быть истинными.

Как только хотя бы один список заканчивается, цикл завершается.

### 5.3. Сравнение значений

```java
if (list1.val <= list2.val)
```

Сравниваются значения текущих узлов.

Если значение `list1` меньше или равно значению `list2`, выбирается узел первого списка. Иначе выбирается узел второго списка.

Оператор `<=` позволяет корректно обрабатывать одинаковые значения.

### 5.4. Присоединение узла

```java
tail.next = list1;
```

Эта строка изменяет ссылку `next` последнего узла результата. Теперь она указывает на текущий узел первого списка.

Мы повторно используем исходный узел, а не создаём его копию.

### 5.5. Перемещение исходного указателя

```java
list1 = list1.next;
```

После присоединения узла передвигаем `list1` к следующему узлу.

Аналогично для второго списка:

```java
list2 = list2.next;
```

Важно сначала присоединить узел к результату, а затем перемещать рабочую ссылку.

### 5.6. Перемещение tail

```java
tail = tail.next;
```

После добавления узла передвигаем `tail` на последний узел результата.

Если не передвигать `tail`, следующая операция присоединения будет выполняться не от конца результата.

### 5.7. Присоединение остатка

```java
if (list1 != null) {
    tail.next = list1;
}

if (list2 != null) {
    tail.next = list2;
}
```

После цикла один из списков закончился. Другой может содержать оставшиеся узлы.

Остаток можно присоединить целиком, потому что он уже отсортирован. Дополнительные сравнения не нужны.

Если один список равен `null`, соответствующий блок просто пропускается.

### 5.8. Возврат результата

```java
return dummy.next;
```

Возвращается первый настоящий узел результата.

Необходимо возвращать именно `dummy.next`, а не `dummy`, иначе вспомогательный узел со значением `-1` попадёт в ответ.

## 6. Пример 1 — пошаговое выполнение

**Входные данные:**

```text
list1 = [1, 2, 4]
list2 = [1, 3, 4]
```

В начале `dummy` и `tail` указывают на вспомогательный узел `-1`.

```text
dummy
  |
  v
[-1] -> null

list1: [1] -> [2] -> [4] -> null
list2: [1] -> [3] -> [4] -> null
```

### Итерация 1

Сравниваем первые элементы:

```java
1 <= 1 // true
```

Выбираем узел `1` из `list1`.

Выполняем:

```java
tail.next = list1;
list1 = list1.next;
tail = tail.next;
```

Результат:

```text
[-1] -> [1]
```

Рабочие ссылки:

```text
list1: [2] -> [4] -> null
list2: [1] -> [3] -> [4] -> null
```

Настоящая часть результата: `[1]`.

### Итерация 2

Сравниваем `2` и `1`:

```java
2 <= 1 // false
```

Выбираем узел `1` из `list2`.

Результат:

```text
[-1] -> [1] -> [1]
```

Рабочие ссылки:

```text
list1: [2] -> [4] -> null
list2: [3] -> [4] -> null
```

Настоящая часть результата: `[1, 1]`.

### Итерация 3

Сравниваем `2` и `3`:

```java
2 <= 3 // true
```

Выбираем узел `2` из `list1`.

Результат:

```text
[-1] -> [1] -> [1] -> [2]
```

Рабочие ссылки:

```text
list1: [4] -> null
list2: [3] -> [4] -> null
```

Настоящая часть результата: `[1, 1, 2]`.

### Итерация 4

Сравниваем `4` и `3`:

```java
4 <= 3 // false
```

Выбираем узел `3` из `list2`.

Результат:

```text
[-1] -> [1] -> [1] -> [2] -> [3]
```

Рабочие ссылки:

```text
list1: [4] -> null
list2: [4] -> null
```

Настоящая часть результата: `[1, 1, 2, 3]`.

### Итерация 5

Сравниваем `4` и `4`:

```java
4 <= 4 // true
```

Выбираем узел `4` из `list1`.

Результат:

```text
[-1] -> [1] -> [1] -> [2] -> [3] -> [4]
```

После выполнения:

```java
list1 = list1.next;
```

`list1` становится равным `null`.

Цикл завершается, поскольку условие требует, чтобы оба списка были непустыми.

### Присоединение остатка

В `list2` остался узел со значением `4`.

Условие `list2 != null` истинно, поэтому выполняется:

```java
tail.next = list2;
```

Остаток присоединяется целиком.

Итоговая структура:

```text
[-1] -> [1] -> [1] -> [2] -> [3] -> [4] -> [4] -> null
```

Вспомогательный узел `-1` не входит в ответ.

**Результат примера 1:**

```text
[1, 1, 2, 3, 4, 4]
```

### Сводная таблица вычислений

| Шаг | list1.val | list2.val | Выбранный узел | Результат |
|---:|---:|---:|---|---|
| 1 | 1 | 1 | `list1`: 1 | `[1]` |
| 2 | 2 | 1 | `list2`: 1 | `[1, 1]` |
| 3 | 2 | 3 | `list1`: 2 | `[1, 1, 2]` |
| 4 | 4 | 3 | `list2`: 3 | `[1, 1, 2, 3]` |
| 5 | 4 | 4 | `list1`: 4 | `[1, 1, 2, 3, 4]` |
| Остаток | `null` | 4 | Остаток `list2` | `[1, 1, 2, 3, 4, 4]` |

Обрати внимание: одинаковые значения не удаляются. Оба узла со значением `1` и оба узла со значением `4` сохраняются.

## 7. Пример 2 — оба списка пустые

**Входные данные:**

```text
list1 = []
list2 = []
```

В Java пустой список представлен ссылкой `null`:

```java
ListNode list1 = null;
ListNode list2 = null;
```

### Пошаговое выполнение

1. Создаётся вспомогательный узел `dummy` со значением `-1`.
2. `tail` указывает на `dummy`.
3. Проверяется условие:

   ```java
   while (list1 != null && list2 != null)
   ```

4. Поскольку `list1 == null`, условие ложно. Цикл не выполняется.
5. Проверки остатков также не присоединяют узлы, потому что обе ссылки равны `null`.
6. Выполняется:

   ```java
   return dummy.next;
   ```

7. `dummy.next` равен `null`, так как ни один узел не был присоединён.

**Результат:**

```text
[]
```

Алгоритм корректно работает с двумя пустыми списками. Для этого не нужны отдельные проверки до цикла.

## 8. Пример 3 — первый список пустой

**Входные данные:**

```text
list1 = []
list2 = [0]
```

В Java:

```java
ListNode list1 = null;
ListNode list2 = new ListNode(0);
```

### Пошаговое выполнение

1. Создаём вспомогательный узел `dummy`.
2. `tail` указывает на `dummy`.
3. Условие цикла сразу ложно, поскольку `list1 == null`.
4. Блок присоединения `list1` пропускается:

   ```java
   if (list1 != null) {
       tail.next = list1;
   }
   ```

5. Условие `list2 != null` истинно. Выполняется:

   ```java
   tail.next = list2;
   ```

6. Теперь `dummy.next` указывает на узел со значением `0`.
7. Выполняется `return dummy.next`.

Структура результата:

```text
dummy
  |
  v
[-1] -> [0] -> null
```

При возврате `dummy` пропускается.

**Результат:**

```text
[0]
```

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(-1);
        ListNode tail = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                tail.next = list1;
                list1 = list1.next;
            } else {
                tail.next = list2;
                list2 = list2.next;
            }

            tail = tail.next;
        }

        if (list1 != null) {
            tail.next = list1;
        }

        if (list2 != null) {
            tail.next = list2;
        }

        return dummy.next;
    }
}
```

Не добавляй второй класс `ListNode`, если он уже предоставлен средой LeetCode. Метод `main` для отправки решения тоже не нужен.

## 10. Анализ сложности

Обозначим:

- `m` — количество узлов в `list1`;
- `n` — количество узлов в `list2`.

### Временная сложность — `O(m + n)`

Каждый узел рассматривается не более одного раза.

На каждой итерации выполняется постоянное количество действий:

- сравнение значений;
- присоединение узла;
- перемещение ссылки исходного списка;
- перемещение `tail`.

В худшем случае нужно обработать узлы обоих списков. Поэтому временная сложность составляет `O(m + n)`.

### Дополнительная пространственная сложность — `O(1)`

Алгоритм использует фиксированное количество ссылок:

- `dummy`;
- `tail`;
- `list1`;
- `list2`.

Также создаётся один вспомогательный узел `dummy`. Новые узлы для каждого значения не создаются.

Количество дополнительной памяти не зависит от длины списков, поэтому пространственная сложность — `O(1)`.

### Сравнение с альтернативным подходом

| Подход | Временная сложность | Дополнительная память |
|---|---|---|
| Слияние двумя указателями | `O(m + n)` | `O(1)` |
| Скопировать значения в массив и отсортировать | `O((m + n) log(m + n))` | `O(m + n)` для массива |

Предложенное решение оптимально по времени и дополнительной памяти: исходные списки уже отсортированы, поэтому достаточно один раз пройти по их узлам.

## 11. Типичные ошибки

### Ошибка 1. Возвращать `dummy`, а не `dummy.next`

Неправильно:

```java
return dummy;
```

В ответ попадёт вспомогательный узел со значением `-1`.

Правильно:

```java
return dummy.next;
```

### Ошибка 2. Не перемещать исходный указатель

Если после присоединения узла не выполнить:

```java
list1 = list1.next;
```

или:

```java
list2 = list2.next;
```

алгоритм может повторно рассматривать тот же узел и не продвигаться вперёд.

### Ошибка 3. Не перемещать `tail`

После присоединения узла нужно выполнить:

```java
tail = tail.next;
```

Иначе следующая операция присоединения может изменить ссылку не того узла.

### Ошибка 4. Забыть про остаток списка

Когда один список закончился, второй может содержать ещё несколько узлов.

Поэтому после цикла нужны проверки:

```java
if (list1 != null) {
    tail.next = list1;
}

if (list2 != null) {
    tail.next = list2;
}
```

### Ошибка 5. Считать пустой список ошибкой

`null` — нормальное представление пустого связанного списка. Алгоритм должен корректно обрабатывать и два пустых списка, и ситуацию, когда пуст только один список.

### Ошибка 6. Удалять повторяющиеся значения

Задача требует объединить списки, а не оставить только уникальные значения. Если в обоих списках есть число `1`, оба узла должны сохраниться в результате.

### Ошибка 7. Создавать новые узлы для каждого элемента

В этой задаче можно повторно использовать исходные узлы, изменяя ссылки `next`. Поэтому создавать новый узел для каждого значения не требуется.

## 12. Что запомнить для собеседования

1. `dummy` упрощает создание результата и помогает избежать отдельной обработки первого узла.
2. `tail` всегда указывает на последний узел уже сформированного результата.
3. Сравниваем только текущие узлы двух отсортированных списков.
4. Присоединяем меньший узел и передвигаем соответствующий исходный указатель.
5. Когда один список заканчивается, присоединяем остаток другого списка целиком.
6. Возвращаем `dummy.next`, чтобы не включать вспомогательный узел в ответ.
7. Временная сложность — `O(m + n)`.
8. Дополнительная пространственная сложность — `O(1)`.

### Главная идея

Мы не сортируем значения заново. Поскольку оба списка уже отсортированы, на каждом шаге достаточно выбрать меньший из двух текущих элементов.

Это позволяет объединить списки за линейное время, используя постоянную дополнительную память и повторно используя узлы исходных списков.
