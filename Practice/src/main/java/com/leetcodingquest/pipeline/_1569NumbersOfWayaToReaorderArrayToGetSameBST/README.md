# LeetCode 1569. Количество способов переупорядочить массив, чтобы получить такое же бинарное дерево поиска

Ниже повторно привожу полный урок на русском языке: условие задачи, оптимальное решение на Java, подробные комментарии к коду, объяснение алгоритма и пошаговые вычисления для всех трёх примеров.

## 1. Условие задачи

Дан массив `nums`, состоящий из уникальных целых чисел от `1` до `n`.

Необходимо вставить элементы массива по порядку в изначально пустое бинарное дерево поиска (BST — Binary Search Tree).

Нужно найти количество различных перестановок массива, которые при последовательной вставке элементов создадут точно такое же бинарное дерево поиска, как исходный массив.

Поскольку ответ может быть очень большим, необходимо вернуть его по модулю \\(10^9+7\\).

Правила бинарного дерева поиска:

- Если новое число меньше значения текущего узла, идём в левое поддерево.
- Если новое число больше значения текущего узла, идём в правое поддерево.
- Если нужное место свободно, вставляем туда число.

### Пример дерева

Для массива `nums = [2, 1, 3]` получим:

2 — корень, 1 — левый потомок, 3 — правый потомок.

Массив `[2, 3, 1]` тоже создаёт такое же дерево. Но массив `[3, 2, 1]` создаст другое дерево, потому что его корнем будет `3`, а не `2`.

Важное условие: исходную перестановку нужно исключить из ответа. Поэтому в конце мы вычитаем `1`.

Примеры из условия:

| Входной массив    | Ответ | Причина                                  |
| ----------------- | ----- | ---------------------------------------- |
| `[2, 1, 3]`       | `1`   | Есть одна другая подходящая перестановка |
| `[3, 4, 5, 1, 2]` | `5`   | Есть пять других подходящих перестановок |
| `[1, 2, 3]`       | `0`   | Нет других подходящих перестановок       |

## 2. Основная идея алгоритма

Первый элемент массива всегда становится корнем дерева. Чтобы получить такое же дерево, он должен остаться первым.

Все остальные элементы делятся на две группы:

- `left` — элементы, меньшие корня;
- `right` — элементы, большие корня.

Например, для массива `[3, 4, 5, 1, 2]`:

```
root  = 3
left  = [1, 2]
right = [4, 5]
```

Сначала нужно сохранить структуру левого поддерева, затем правого. При этом элементы двух групп можно перемежать между собой.

### Как посчитать количество вариантов перемешивания?

Пусть после корня осталось \\(n-1\\) элементов, из которых \\(L\\) относятся к левому поддереву, а остальные — к правому.

Нужно выбрать \\(L\\) позиций для элементов левого поддерева. Число способов выбрать эти позиции задаётся биномиальным коэффициентом:

\\[ \binom{n-1}{L}=\frac{(n-1)!}{L!(n-1-L)!} \\]

Обозначим через \\(F(nums)\\) количество перестановок, создающих то же дерево, включая исходный порядок.

Тогда:

\\[ F(nums)= \binom{n-1}{L}\cdot F(left)\cdot F(right) \\]

Базовый случай: если в списке не больше двух элементов, подходящий порядок ровно один.

\\[ F(nums)=1,\quad |nums|\leq2 \\]

В конце исключаем исходную перестановку:

\\[ \boxed{answer=(F(nums)-1)\bmod(10^9+7)} \\]

## 3. Полный код решения на Java

Это решение использует рекурсию и предварительно вычисленную таблицу биномиальных коэффициентов по треугольнику Паскаля.

```
import java.util.ArrayList;
import java.util.List;

class Solution {
    private static final int MOD = 1_000_000_007;
    private long[][] combinations;

    public int numOfWays(int[] nums) {
        int n = nums.length;

        // Таблица биномиальных коэффициентов.
        combinations = new long[n + 1][n + 1];

        // Строим треугольник Паскаля.
        for (int i = 0; i <= n; i++) {
            combinations[i][0] = 1;
            combinations[i][i] = 1;

            for (int j = 1; j < i; j++) {
                combinations[i][j] =
                    (combinations[i - 1][j - 1]
                    + combinations[i - 1][j]) % MOD;
            }
        }

        // Преобразуем массив в список.
        List<Integer> values = new ArrayList<>();
        for (int num : nums) {
            values.add(num);
        }

        // Вычитаем исходную перестановку.
        return (int) ((countWays(values) - 1 + MOD) % MOD);
    }

    private long countWays(List<Integer> nums) {
        int n = nums.size();

        // Базовый случай рекурсии.
        if (n <= 2) {
            return 1;
        }

        // Первый элемент является корнем дерева.
        int root = nums.get(0);

        // Создаём списки для двух поддеревьев.
        List<Integer> left = new ArrayList<>();
        List<Integer> right = new ArrayList<>();

        // Распределяем числа по поддеревьям.
        for (int i = 1; i < n; i++) {
            int value = nums.get(i);

            if (value < root) {
                left.add(value);
            } else {
                right.add(value);
            }
        }

        // Считаем способы для левого и правого поддеревьев.
        long leftWays = countWays(left);
        long rightWays = countWays(right);

        // Считаем количество вариантов перемешивания групп.
        long interleavings =
            combinations[n - 1][left.size()];

        // Объединяем результаты.
        return (((interleavings * leftWays) % MOD)
                * rightWays) % MOD;
    }
}
```

## 4. Построчное объяснение кода

### 4.1. Импорт библиотек и объявление класса

```
import java.util.ArrayList;
import java.util.List;
```

- `List` — интерфейс для работы со списками.
- `ArrayList` — реализация списка, в который можно добавлять элементы.

```
class Solution {
    private static final int MOD = 1_000_000_007;
    private long[][] combinations;
```

- `Solution1` — класс, который ожидает LeetCode.
- `MOD` — модуль, по которому вычисляем ответ.
- `combinations` — двумерная таблица биномиальных коэффициентов.
- Тип `long` нужен, чтобы промежуточные результаты умножения не переполняли `int`.

### 4.2. Начало метода `numOfWays`

```
public int numOfWays(int[] nums) {
    int n = nums.length;
```

Метод принимает массив `nums` и сохраняет его длину в переменную `n`.

```
combinations = new long[n + 1][n + 1];
```

Создаём таблицу размером `(n + 1) × (n + 1)`. Она позволит обращаться к биномиальным коэффициентам по индексам.

### 4.3. Построение треугольника Паскаля

```
for (int i = 0; i <= n; i++) {
    combinations[i][0] = 1;
    combinations[i][i] = 1;
```

Внешний цикл строит строки треугольника Паскаля.

Крайние элементы каждой строки равны единице:

\\[ \binom{i}{0}=\binom{i}{i}=1 \\]

```
for (int j = 1; j < i; j++) {
    combinations[i][j] =
        (combinations[i - 1][j - 1]
        + combinations[i - 1][j]) % MOD;
}
```

Внутренний цикл вычисляет остальные значения по формуле:

\\[ \binom{i}{j}= \binom{i-1}{j-1}+\binom{i-1}{j} \\]

Например:

\\[ \binom{3}{1}=\binom{2}{0}+\binom{2}{1}=1+2=3 \\]

Первые строки таблицы:

| Номер строки | Значения    |
| ------------ | ----------- |
| 0            | `1`         |
| 1            | `1 1`       |
| 2            | `1 2 1`     |
| 3            | `1 3 3 1`   |
| 4            | `1 4 6 4 1` |

Так мы заранее вычисляем все необходимые коэффициенты. Каждый из них можно получить за \\(O(1)\\).

### 4.4. Преобразование массива в список

```
List<Integer> values = new ArrayList<>();
for (int num : nums) {
    values.add(num);
}
```

Создаём список `values` и переносим в него все числа исходного массива.

Например, массив `[2, 1, 3]` преобразуется в список `[2, 1, 3]`.

Расширенный цикл `for` последовательно перебирает элементы массива.

### 4.5. Вычисление ответа

```
return (int) ((countWays(values) - 1 + MOD) % MOD);
```

- `countWays(values)` считает все подходящие порядки, включая исходный.
- `- 1` исключает исходную перестановку.
- `+ MOD` позволяет избежать отрицательного остатка.
- `% MOD` оставляет результат по модулю.
- `(int)` преобразует итоговое значение в `int`, поскольку метод возвращает `int`.

Вычитание выполняется только здесь, а не внутри каждого рекурсивного вызова.

### 4.6. Рекурсивный метод `countWays`

```
private long countWays(List<Integer> nums) {
    int n = nums.size();

    if (n <= 2) {
        return 1;
    }
```

Сначала определяем длину списка.

Если в нём не больше двух элементов, возвращаем `1`: для такого дерева существует только один порядок вставки, сохраняющий его структуру.

```
int root = nums.get(0);
```

Первый элемент становится корнем. В любой допустимой перестановке он должен остаться первым.

```
List<Integer> left = new ArrayList<>();
List<Integer> right = new ArrayList<>();
```

Создаём два пустых списка:

- `left` — для чисел меньше корня;
- `right` — для чисел больше корня.

```
for (int i = 1; i < n; i++) {
    int value = nums.get(i);

    if (value < root) {
        left.add(value);
    } else {
        right.add(value);
    }
}
```

Перебираем элементы, начиная с индекса `1`, поскольку элемент с индексом `0` уже является корнем.

Если число меньше корня, добавляем его в `left`. Иначе — в `right`.

Например, для `[3, 4, 5, 1, 2]` получаем:

```
root  = 3
left  = [1, 2]
right = [4, 5]
```

### 4.7. Рекурсивный подсчёт поддеревьев

```
long leftWays = countWays(left);
long rightWays = countWays(right);
```

Вызываем тот же метод для левого и правого списков.

- `leftWays` — количество допустимых порядков для левого поддерева.
- `rightWays` — количество допустимых порядков для правого поддерева.

Рекурсия повторяется, пока списки не станут длины 1 или 2.

### 4.8. Подсчёт вариантов перемешивания

```
long interleavings =
    combinations[n - 1][left.size()];
```

После корня остаётся `n - 1` элементов.

Из них `left.size()` позиций должны принадлежать левой группе. Остальные займёт правая группа.

Количество способов выбрать эти позиции:

\\[ \binom{n-1}{left.size()} \\]

Мы берём готовое значение из треугольника Паскаля.

### 4.9. Объединение результатов

```
return (((interleavings * leftWays) % MOD)
        * rightWays) % MOD;
```

Перемножаем:

1. Количество способов чередовать левую и правую группы.
2. Количество способов переставить левую группу, сохранив её дерево.
3. Количество способов переставить правую группу, сохранив её дерево.

После каждого умножения берём остаток по модулю.

Именно это позволяет не перебирать все перестановки массива.

## 5. Пример 1 — `nums = [2, 1, 3]`

Ожидаемый ответ: `1`.

### Шаг 1. Разделяем массив

Первый элемент `2` — корень.

```
root  = 2
left  = [1]
right = [3]
```

### Шаг 2. Рекурсивно считаем поддеревья

Обе группы содержат по одному элементу:

```
countWays([1]) = 1
countWays([3]) = 1
```

Поэтому:

\\[ leftWays=1,\quad rightWays=1 \\]

### Шаг 3. Считаем перемешивания

После корня остаются два элемента. Нужно выбрать одну позицию из двух для левой группы:

\\[ \binom{2}{1}=\frac{2!}{1!\cdot1!}=2 \\]

Возможные порядки:

```
[2, 1, 3] — исходный
[2, 3, 1] — другой допустимый
```

Оба создают одно и то же дерево.

Следовательно:

\\[ F([2,1,3])=2\cdot1\cdot1=2 \\]

Вычитаем исходную перестановку:

\\[ answer=2-1=\boxed{1} \\]

Результат: `1`.

## 6. Пример 2 — `nums = [3, 4, 5, 1, 2]`

Ожидаемый ответ: `5`.

### Шаг 1. Разделяем массив

Первый элемент `3` становится корнем.

```
root  = 3
left  = [1, 2]
right = [4, 5]
```

### Шаг 2. Считаем способы для поддеревьев

Для левого списка `[1, 2]`:

```
countWays([1, 2]) = 1
```

Для правого списка `[4, 5]`:

```
countWays([4, 5]) = 1
```

В обоих случаях порядок должен остаться неизменным, иначе изменится структура соответствующего поддерева.

Таким образом:

\\[ leftWays=1,\quad rightWays=1 \\]

### Шаг 3. Считаем количество перемешиваний

После корня остаются четыре числа: два из левой группы и два из правой.

Количество способов выбрать две позиции из четырёх для левой группы:

\\[ \binom{4}{2}=\frac{4!}{2!\cdot2!}=6 \\]

Рассмотрим все шесть вариантов.

Здесь `L` — следующее число из списка `[1, 2]`, а `R` — следующее число из `[4, 5]`.

| Шаблон | Получившийся массив |
| ------ | ------------------- |
| `LLRR` | `[3, 1, 2, 4, 5]`   |
| `LRLR` | `[3, 1, 4, 2, 5]`   |
| `LRRL` | `[3, 1, 4, 5, 2]`   |
| `RLLR` | `[3, 4, 1, 2, 5]`   |
| `RLRL` | `[3, 4, 1, 5, 2]`   |
| `RRLL` | `[3, 4, 5, 1, 2]`   |

Каждый шаблон сохраняет порядок внутри обеих групп, но меняет их чередование.

Последний массив — исходный. Его нужно исключить.

### Шаг 4. Вычисляем ответ

\\[ F([3,4,5,1,2])=6\cdot1\cdot1=6 \\]

\\[ answer=6-1=\boxed{5} \\]

Результат: `5`.

## 7. Пример 3 — `nums = [1, 2, 3]`

Ожидаемый ответ: `0`.

### Шаг 1. Разделяем массив

Первый элемент `1` — корень.

```
root  = 1
left  = []
right = [2, 3]
```

### Шаг 2. Считаем способы

Для пустого списка срабатывает базовый случай:

```
countWays([]) = 1
```

Для списка `[2, 3]` также срабатывает базовый случай:

```
countWays([2, 3]) = 1
```

### Шаг 3. Считаем перемешивания

Все два оставшихся элемента относятся к правой группе, поэтому:

\\[ \binom{2}{0}=1 \\]

Следовательно:

\\[ F([1,2,3])=1\cdot1\cdot1=1 \\]

### Шаг 4. Исключаем исходную перестановку

\\[ answer=1-1=\boxed{0} \\]

Другого порядка, который создаст такое же дерево, нет.

Результат: `0`.

## 8. Сложность алгоритма

| Ресурс | Сложность    | Объяснение                                                                                                                     |
| ------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Время  | \\(O(n^2)\\) | Построение треугольника Паскаля занимает \\(O(n^2)\\); рекурсивное разбиение в худшем случае также занимает квадратичное время |
| Память | \\(O(n^2)\\) | Таблица биномиальных коэффициентов занимает \\(O(n^2)\\); списки и рекурсивный стек укладываются в эту оценку                  |

При ограничении `nums.length <= 1000` решение подходит для LeetCode.

## 9. Что важно запомнить

1. Первый элемент массива всегда становится корнем.
2. Числа делятся на левую и правую группы относительно корня.
3. Для каждой группы рекурсивно считаются допустимые порядки.
4. Количество вариантов перемешивания групп определяется биномиальным коэффициентом.
5. Исходная перестановка исключается один раз в самом конце.

Главная формула:

\\[ \boxed{ F(nums)= \binom{n-1}{L}\cdot F(left)\cdot F(right) } \\]

Итог:

\\[ \boxed{answer=(F(nums)-1)\bmod(10^9+7)} \\]

Главная мысль: вместо генерации всех перестановок мы используем рекурсию и комбинаторику, чтобы сразу вычислить количество подходящих порядков.
