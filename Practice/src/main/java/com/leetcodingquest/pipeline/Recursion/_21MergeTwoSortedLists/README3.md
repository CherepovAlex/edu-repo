# Merge Two Sorted Lists (LeetCode #21)

> **Язык:** Java  
> **Сложность:** Easy  
> **Временная сложность:** $O(N + M)$  
> **Пространственная сложность:** $O(1)$

## 📖 Описание задачи

Вам даны заголовки двух отсортированных связанных списков (`list1` и `list2`).  
Объедините два списка в один отсортированный список. Список должен быть создан путем объединения узлов первых двух списков.  
Верните голову объединенного связанного списка.

### Ограничения
- Количество узлов в обоих списках находится в диапазоне `[0, 50]`.
- `-100 <= Node.val <= 100`
- И `list1`, и `list2` отсортированы в неубывающем порядке.

### Примеры

**Пример 1:**
```text
Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]
```

**Пример 2:**
```text
Input: list1 = [], list2 = []
Output: []
```

**Пример 3:**
```text
Input: list1 = [], list2 = [0]
Output: [0]
```

## 🧠 Стратегия решения

Поскольку оба входных списка уже отсортированы, нам не нужно выполнять полную сортировку результата. Мы можем использовать алгоритм слияния (merge), аналогичный тому, что используется в Merge Sort.

### Алгоритм (Итеративный подход)

1. **Создание фиктивного узла (Dummy Node):**  
   Мы создаем вспомогательный узел `dummy` со значением `-1`. Это упрощает логику, так как нам не нужно отдельно обрабатывать случай, когда результирующий список пуст или когда добавляется первый элемент. Реальная голова списка будет находиться по адресу `dummy.next`.

2. **Инициализация указателя `current`:**  
   Указатель `current` инициализируется так, чтобы он указывал на `dummy`. Он будет "следовать" за последним добавленным узлом в нашем новом списке.

3. **Цикл сравнения:**  
   Пока оба списка (`list1` и `list2`) не пусты:
   - Сравниваем значения текущих узлов: `list1.val` и `list2.val`.
   - Если `list1.val <= list2.val`, присоединяем узел `list1` к `current.next` и продвигаем указатель `list1` вперед.
   - Иначе присоединяем узел `list2` к `current.next` и продвигаем указатель `list2` вперед.
   - В любом случае продвигаем `current` вперед, чтобы он указывал на только что добавленный узел.

4. **Присоединение остатка:**  
   После выхода из цикла один из списков может быть пустым, а другой — содержать оставшиеся узлы. Поскольку списки отсортированы, оставшаяся часть уже упорядочена. Мы просто присоединяем остаток непустого списка к концу текущего результата (`current.next`).

5. **Возврат результата:**  
   Возвращаем `dummy.next`, так как это начало реального объединенного списка.

### Почему это оптимально?
- **Время:** $O(N + M)$, где $N$ и $M$ — длины списков. Мы проходим по каждому узлу ровно один раз.
- **Память:** $O(1)$. Мы не создаем новые объекты узлов, а лишь переназначаем ссылки (`next`). Это требует минимального дополнительного пространства.

## 💻 Код решения

```java
/**
 * LeetCode 21: Merge Two Sorted Lists
 * 
 * Решение объединяет два отсортированных связанных списка в один отсортированный список.
 * Использует итеративный подход с фиктивным узлом (dummy node) для упрощения логики.
 */
public class Solution1 {

    /**
     * Объединяет два отсортированных связанных списка.
     *
     * @param list1 Голова первого отсортированного списка
     * @param list2 Голова второго отсортированного списка
     * @return Голова объединенного отсортированного списка
     */
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        
        // Создаем фиктивный (dummy) узел.
        // dummy.val = -1 (значение не важно, главное наличие узла)
        // Он служит "стартовой точкой" для построения нового списка.
        ListNode dummy = new ListNode(-1);
        
        // current - указатель, который всегда указывает на последний узел
        // в формирующемся результирующем списке.
        // Изначально он указывает на dummy.
        ListNode current = dummy;
        
        // Цикл продолжается, пока в обоих списках есть хотя бы один узел.
        // Как только один из списков заканчивается, цикл прерывается.
        while (list1 != null && list2 != null) {
            
            // Сравниваем значения текущих узлов обоих списков.
            if (list1.val <= list2.val) {
                // Если значение в list1 меньше или равно,
                // присоединяем узел list1 к текущему месту в результирующем списке.
                // current.next теперь ссылается на тот же объект, что и list1.
                current.next = list1;
                
                // Продвигаем указатель list1 вперед, чтобы следующий раз
                // сравнивать следующий узел этого списка.
                list1 = list1.next;
            } else {
                // Если значение в list2 меньше,
                // присоединяем узел list2 к текущему месту в результирующем списке.
                current.next = list2;
                
                // Продвигаем указатель list2 вперед.
                list2 = list2.next;
            }
            
            // После добавления узла в результат,
            // нужно продвинуть current вперед, чтобы он указывал на только что добавленный узел.
            // Это подготовит current для следующего шага вставки.
            current = current.next;
        }
        
        // После завершения цикла один из списков (list1 или list2) может быть пустым (null),
        // а другой может содержать оставшиеся узлы.
        // Так как списки отсортированы, оставшаяся часть уже отсортирована.
        // Мы просто присоединяем остаток непустого списка к концу текущего результата.
        
        if (list1 != null) {
            // Если list1 еще не пуст, присоединяем его остаток.
            current.next = list1;
        } else {
            // Если list1 пуст, то list2 не пуст (или тоже пуст),
            // присоединяем остаток list2.
            current.next = list2;
        }
        
        // Возвращаем следующий узел после dummy, так как dummy - это фиктивный элемент,
        // а реальная голова объединенного списка находится после него.
        return dummy.next;
    }

    /**
     * Метод main для тестирования решения на примерах из задачи.
     */
    public static void main(String[] args) {
        Solution1 sol = new Solution1();

        // --- Пример 1: list1 = [1,2,4], list2 = [1,3,4] ---
        // Создаем списки вручную для демонстрации
        ListNode l1 = new ListNode(1, new ListNode(2, new ListNode(4)));
        ListNode l2 = new ListNode(1, new ListNode(3, new ListNode(4)));
        
        ListNode result1 = sol.mergeTwoLists(l1, l2);
        
        System.out.println("Example 1 Result:");
        printList(result1); // Ожидается: 1 -> 1 -> 2 -> 3 -> 4 -> 4

        // --- Пример 2: list1 = [], list2 = [] ---
        ListNode l3 = null;
        ListNode l4 = null;
        ListNode result2 = sol.mergeTwoLists(l3, l4);
        
        System.out.println("\nExample 2 Result:");
        printList(result2); // Ожидается: (пусто)

        // --- Пример 3: list1 = [], list2 = [0] ---
        ListNode l5 = null;
        ListNode l6 = new ListNode(0);
        ListNode result3 = sol.mergeTwoLists(l5, l6);
        
        System.out.println("\nExample 3 Result:");
        printList(result3); // Ожидается: 0
    }

    /**
     * Вспомогательный метод для печати связанного списка в консоль.
     * @param head Голова списка
     */
    private static void printList(ListNode head) {
        ListNode current = head;
        while (current != null) {
            System.out.print(current.val);
            if (current.next != null) {
                System.out.print(" -> ");
            }
            current = current.next;
        }
        System.out.println();
    }
}

/**
 * Определение класса узла связанного списка.
 * Используется в LeetCode и других системах оценки.
 */
class ListNode {
    int val;
    ListNode next;

    // Конструкторы для удобства создания узлов
    ListNode() {
    }

    ListNode(int val) {
        this.val = val;
    }

    ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }
}
```

## 🔍 Пошаговый разбор выполнения

### Пример 1: `list1 = [1,2,4]`, `list2 = [1,3,4]`

**Инициализация:**
- `dummy` -> `[-1]`
- `current` -> `dummy`
- `list1` -> `[1] -> [2] -> [4]`
- `list2` -> `[1] -> [3] -> [4]`

| Шаг | Условие `list1.val <= list2.val` | Действие | Состояние `current.next` | Состояние `list1` | Состояние `list2` |
|-----|----------------------------------|----------|--------------------------|-------------------|-------------------|
| 1   | `1 <= 1` (True)                  | `current.next = list1`<br>`list1 = list1.next`<br>`current = current.next` | `dummy -> [1]` | `[2] -> [4]` | `[1] -> [3] -> [4]` |
| 2   | `2 <= 1` (False)                 | `current.next = list2`<br>`list2 = list2.next`<br>`current = current.next` | `... -> [1] -> [1]` | `[2] -> [4]` | `[3] -> [4]` |
| 3   | `2 <= 3` (True)                  | `current.next = list1`<br>`list1 = list1.next`<br>`current = current.next` | `... -> [1] -> [2]` | `[4]` | `[3] -> [4]` |
| 4   | `4 <= 3` (False)                 | `current.next = list2`<br>`list2 = list2.next`<br>`current = current.next` | `... -> [2] -> [3]` | `[4]` | `[4]` |
| 5   | `4 <= 4` (True)                  | `current.next = list1`<br>`list1 = list1.next`<br>`current = current.next` | `... -> [3] -> [4]` | `null` | `[4]` |

**Цикл завершается**, так как `list1 == null`.

**После цикла:**
- `list1` пуст, `list2` не пуст (`[4]`).
- `current.next = list2` -> присоединяем остаток `list2`.
- Итоговая цепочка: `dummy -> [1] -> [1] -> [2] -> [3] -> [4] -> [4] -> null`.

**Возврат:** `dummy.next` (первый узел со значением 1).

### Пример 2: `list1 = []`, `list2 = []`

**Инициализация:**
- `list1 = null`, `list2 = null`.

**Цикл:**
- Условие `while (null != null && null != null)` равно `false`.
- Цикл не выполняется.

**После цикла:**
- `if (list1 != null)` -> `false`.
- `else` -> `current.next = list2` (то есть `null`).

**Возврат:** `dummy.next` (который равен `null`).
**Результат:** `[]`.

---

### Пример 3: `list1 = []`, `list2 = [0]`

**Инициализация:**
- `list1 = null`, `list2 = [0]`.

**Цикл:**
- Условие `while (null != null && [0] != null)` равно `false`.
- Цикл не выполняется.

**После цикла:**
- `if (list1 != null)` -> `false`.
- `else` -> `current.next = list2` (присоединяем узел `[0]`).

**Возврат:** `dummy.next` (узел со значением 0).
**Результат:** `[0]`.

## 📊 Анализ сложности

| Метрика | Значение | Обоснование |
|---------|----------|-------------|
| **Время** | $O(N + M)$ | Мы проходим по каждому узлу из обоих списков ровно один раз. В худшем случае мы просматриваем все элементы обоих списков. |
| **Пространство** | $O(1)$ | Мы используем фиксированное количество переменных (`dummy`, `current`, `list1`, `list2`). Мы не создаем новые объекты узлов, а переназначаем ссылки существующих, поэтому дополнительная память не требуется. |

## 💡 Советы по реализации

1. **Используйте `dummy` узел:** Это стандартный паттерн в работе со списками. Он избавляет от необходимости писать отдельный код для обработки первого элемента списка.
2. **Проверяйте условия выхода:** Цикл `while` должен продолжаться, пока **оба** списка не пусты. Как только один заканчивается, мы просто "приклеиваем" остаток второго.
3. **Не создавайте новые узлы:** В этой задаче обычно разрешено мутировать входные списки (переназначать ссылки `next`). Если бы требовалось создать полностью новый список без изменения входных данных, сложность по памяти стала бы $O(N + M)$, но для LeetCode 21 подход с переназначением ссылок является предпочтительным и оптимальным.
